# 专利解析需求文档

模块标识：ADJ-07；对应原需求：一.1.1.1.1.2.4。  
版本：V0.1 技术评审稿；日期：2026-09-12。  
建设条件：中心主要通过 API 提供数据；国产化部署，业务关系型数据库固定为达梦 DM8。  
交付边界：对外交付服务及接口、部署和验收资料；自研前端仅供内部验证，不交付对外页面。

本文与[需求总览与通用约定](00-需求总览与通用约定.md)共同构成开发要求。字段中文名为业务契约，接口路径和英文名由详细设计统一。涉及事实的字段缺失时返回缺口，不以模型推测满足必填。当前未完成中心 API、模型或 DM8 实测。

## 1. 功能概述

解析涉案专利说明书、权利要求书及附图，提取权利要求结构和技术特征，提供原文定位与人工修订，为有效性及证据分析提供输入。复用已有专利库接入与文献解析能力，但本模块增加案件绑定、权利要求确认及解析版本。

技术特征提取不等于最终确定权利保护范围，保护期限来源信息也不等于专利始终有效。

## 2. 输入输出字段

| 字段 | 说明 |
|---|---|
| 案件编号、案件资料版本 | 可选准备阶段，进入案件分析时必填 |
| 申请号/公开号/授权公告号、专利名称 | 号码类型分开保存，不仅按标题定位 |
| 申请人、发明人、申请/授权日期 | 按源数据，不推测缺失字段 |
| 文献版本、法律状态时间、保护期限 | 来源及本次获取时间分开 |
| 权利要求书、说明书、附图 | 完整原文及可访问引用 |
| 权利要求编号、类型、引用关系 | 独立/从属及依赖链 |
| 核心技术特征 | 特征 ID、文本、对应权利要求、说明书支持位置 |
| OCR/解析状态、缺失项 | 可读性和覆盖情况 |
| 解析结果、解析版本、执行时间 | 程序/模型/规则版本 |
| 人工修订、确认人员与时间 | 原始结果与人工版本分开 |

## 3. 解析流程与规则

1. 通过中心 API 或受控文件上传获取涉案文献，确认号码类型、文献版本及材料归属。
2. 解析文本结构并保留页码、段落、权利要求编号和附图号。扫描件可 OCR，标明低质量页面和未处理内容。
3. 提取独立与从属权利要求关系，展开所选从属项实际引用的前项特征，保留原始层级。
4. 按用户选择的权利要求生成逐项技术特征，保留限定关系及必要上下文，不只摘取摘要“核心词”。
5. 人工核对后修订特征、引用关系或定位信息，生成确认版本，供后续模块选择。
6. 材料或权利要求版本变化时新建解析，原有结果标为来源已变更；不得替换下游已保存的历史输入。

权利要求无法读取时返回不完整结果，不能以摘要代替。说明书用于理解和提供支持，不把其中任意技术细节自动加为权利要求限定。保护期限按源数据及确认规则展示，缺失授权/状态记录时不得自行推算当前有效性。

外观设计使用视图、产品名称及简要说明的独立解析分支，不编造文本权利要求。后续外观分析须核验视图及对应规则能力，不能套用发明特征矩阵。

## 4. 内部验证页面

输入专利号码或上传授权文件，选择案件、文献版本和拟分析权利要求。解析结果原文与结构树并列，提供权利要求依赖展开、技术特征编辑、页码/附图定位、缺失项及 OCR 质量查看。

操作包括开始解析、进度/重试、保存修订、确认版本、查看历史及进入有效性/证据分析。显示原文来源、获取时间与资料完整性；无可用全文时不显示已完成完整解析。

## 5. 服务契约

| 服务 | 输入 | 输出 |
|---|---|---|
| 材料准备/上传 | 号码或受控文件、案件权限 | 文献候选、完整性及文件引用 |
| 创建解析 | 文献版本、所选权利要求、幂等键 | 任务 ID |
| 查询结果 | 任务/解析版本 | 结构、特征、位置及未处理内容 |
| 保存/确认修订 | 当前版本、修改、原因 | 新解析版本及确认记录 |
| 下游输入查询 | 解析版本、案件 | 已确认或明确标注未确认的结构化结果 |

文件类型和大小按确认配置校验，原文件保留哈希供完整性核对；哈希不证明文件内容真实性。错误包括文件损坏、文献歧义、依赖关系异常、OCR 不足及权限问题。禁止任意服务器路径读取。

## 6. 国产化与 DM8 要求

DM8 保存文献引用、依赖结构、长文本特征、解析任务和确认版本。验证层级关联、长文本、批量保存原子性及版本竞争。OCR、PDF 和图像组件须在中心国产环境验证，不能因数据库可用就认定解析链路可用。

## 7. 验收要求

| 编号 | 场景与预期 |
|---|---|
| PARSE-01 | 正确区分号码与文献版本，上传材料可追溯 |
| PARSE-02 | 独立/从属依赖及特征抽取与原文一致 |
| PARSE-03 | 权利要求缺失不以摘要替代，低质量 OCR 可见 |
| PARSE-04 | 人工修订和确认生成新版本，旧结果不被覆盖 |
| PARSE-05 | 外观设计走独立结构，不生成虚构权利要求 |
| PARSE-06 | 专家样本检查特征完整性、限定关系及证据定位准确性 |
| PARSE-07 | DM8 与国产解析组件验证完整链路，独立 API 可返回结构化结果 |

## 8. 依赖与交付

依赖中心专利 API/授权文件、已有专利库、OCR/解析及模型服务。交付解析与确认服务、结构/位置格式、质量状态说明和验收记录。确认文献版本覆盖、文件上限、外观材料能力及专家基准。
