# 违法线索发现需求文档

版本：V0.1 需求评审稿  
功能编号：ZF-03  
原需求条目：一.1.1.1.1.1.3  
所属智能体：知识产权执法助手

## 1. 功能概述与交付范围

对接入记录执行已发布规则，形成待核实线索并向授权业务端提供提醒。

对外交付本功能的服务接口及接口说明；内部开发验证页面用于联调、演示和验收，页面不属于对外交付内容。所有业务规则、权限与结果保存由后端服务执行。

本篇与[需求总览与通用约定](00-需求总览与通用约定.md)共同构成该功能需求；身份、分页、时间、任务、错误、版本和审核按总览执行。

已确认技术约束：按中心国产化环境适配，业务数据库使用达梦 DM8，内部验证环境同样使用 DM8；具体兼容要求及验证内容遵循总览第 1.1 节。

## 2. 数据来源与依赖

依赖 01 数据接入记录及 02 已发布规则；首版按同步批次触发，API 支持推送时再对接事件。

接入时校验资源编号、关联关系、版本和访问权限；源数据缺失与调用失败分开记录。来源字段不能由模型生成或替换。具体接入能力以实际 API 联调结果为准。

## 3. 信息字段

| 字段名称 | 必填/产生方式 | 说明 |
|---|---|---|
| 线索编号 | 生成 | 唯一标识 |
| 线索来源 | 生成 | 数据源和源记录编号 |
| 违法行为类型 | 生成 | 标为疑似类型 |
| 线索内容 | 生成 | 摘要及原记录引用 |
| 发现时间 | 生成 | 首次发现时间 |
| 匹配规则编号 | 生成 | 可多条并附版本 |
| 置信度 | 条件 | 仅模型评分时记录，附模型版本 |
| 处理状态 | 生成 | 待核实、核实中、已转处置、排除、关闭 |
| 命中说明 | 生成 | 匹配条件及证据片段 |
| 通知状态 | 生成 | 待投递、成功、失败 |

通用附加字段：创建人、创建时间、更新人、更新时间、所属机构及 request_id；详情返回相关来源与历史版本。已有来源字段和业务编号不可随意改写。

## 4. 功能与处理规则

1. 读取已启用规则及适用数据源，逐条匹配并保存输入快照、命中理由。
2. 同一源记录同一版本产生一条线索，多个命中规则合并记录；跨来源仅标记疑似重复，人工确认后关联。
3. 排除或关闭线索保留原因；源记录新版本可追加发现记录，不覆盖历史处置。
4. 线索供列表接口查询；若中心提供接收接口，按业务授权推送，失败重试且按事件编号去重。
5. 接口或模型失败标记任务失败/部分失败，不作为未发现线索。

## 5. 服务接口需求

批次发现任务提交及查询；线索列表/详情；状态变更；通知结果查询。输入数据源批次及规则范围，输出任务状态、线索编号、命中统计与失败项。

列表接口按内部页面规定支持筛选和分页；详情返回完整字段而非仅摘要。写入返回资源编号和版本。配置变更、人工修订及审核需记录操作人和前后状态；长时间操作按通用异步任务约定返回进度和结果。

关联资源不存在或无权限时拒绝操作；源接口不可用、解析失败或规则不适用时返回明确原因。部分结果必须同时附未处理项，不得伪装为完整成功。具体 URL 和英文参数名由技术统一设计，并随 OpenAPI 契约交付。

## 6. 内部验证页面

发现任务列表、线索列表与详情；按类型、来源、时间、状态筛选；详情展示命中理由和原始记录；支持人工核实与填写排除原因。

页面展示服务返回的实际数据，操作按钮调用对应后端接口；包含加载、空数据、失败与无权限状态。支持查看 request_id 以定位联调问题。列表默认按更新时间倒序；历史结果可查看其使用的数据和配置版本。

## 7. 验收要求

1. 固定样例中的规则命中项均形成线索并关联规则版本。
2. 重复执行不重复创建线索或重复通知。
3. 模型失败的记录进入失败明细而不是无命中。
4. 未授权账号不能查询或接收其他部门线索。
5. 页面操作和直接接口调用得到一致结果；直接调用不能绕过权限、字段或状态校验。
6. 错误场景返回明确原因，关联数据和历史结果未被错误覆盖。

以上场景由技术准备固定样例，记录请求、期望、实际结果和证据；涉及专业判断的期望结果由中心业务人员确认。模型效果与性能指标按总览另行试测确认，不使用模型自评分作为验收准确率。

## 8. 联调前需确认的条件

推送目的端、频率及延迟目标需约定；不默认购买或接入短信等渠道。

这些是本功能的外部依赖，未确认时可用明确标记的模拟数据开发接口和页面，但不视为真实业务联调通过。
