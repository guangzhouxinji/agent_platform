## 1. 任务边界

实现一条可运行的、仅使用合成数据的 V0 闭环：提交技术参考咨询、可选补充或必要补问、默认拒绝的授权检查、合成专利检索、回答前来源复查、带来源辅助回答。实现不接入中心 API、DM8、真实文件、真实用户、外部模型或正式人工流程。

关联原需求范围条款：

| 需求 | 本任务覆盖的关键条款 | 设计证据 |
|---|---|---|
| CON-02 专利库管理 | 来源/源 ID/文献版本定位、中心源只读、缺失/来源不可用不补造 | `docs/12`、`docs/13`、`docs/15`、`docs/16` |
| CON-04 专利相似度检索 | 技术方案输入、技术参考目的、原输入/请求快照、权限前置、候选来源与匹配依据、实际范围、有限范围披露、错误区分、撤权/失效复查 | `docs/11` 至 `docs/16` |
| CON-11 咨询意图管理 | V0 意图识别、缺失/冲突澄清、模型推测不得确认、执行前再次校验、意图不得扩大权限 | `docs/11`、`docs/13`、`docs/14` |
| CON-12 咨询对话流管理 | 会话/输入、必要补问、真实工具结果、可解析来源、对象更正产生新请求、异常区分、辅助而非正式意见、服务端会话/附件归属校验 | `docs/11` 至 `docs/16` |

下列能力在原始需求和相应 `CON-*` 台账中保留，但本任务作为合成 V0 明确不纳入：真实中心接入和全量专利库查询、号码多候选、图像检索、数值评分、相似度判断、意图/提示词/智能体/流程配置发布、完整会话生命周期、并发/取消/重连/事件流、真实人工转接、DM8、中心 SSO/权限、真实数据保留和专业效果验收。它们不能因本任务完成而升级状态。

## 2. V0 技术决定

以下是可回滚的技术决定，不是原始业务事实：

- 使用 Maven 和 Java 21 源码兼容级别建立单一后端工程；这是项目负责人于 2026-09-15 作出的 V0 技术决定，中心最终 JDK 兼容性仍待运维确认。
- 用内存仓储保存五个领域对象及其关系，仅服务本地 V0 验证；不称为持久化实现。
- 用合成专利适配器提供 `V0-SYN-PAT-001/002/003`；`003` 用于无权限或来源失效测试。
- 用受约束的回答生成器拼装已验证候选、来源和限制说明；它不是外部大模型，也不宣称完成模型接入。
- 测试授权适配器只识别测试请求者引用；未知或无法判断一律拒绝。它不代表真实角色或 DataScope。

## 3. 可执行验收

| 测试 ID | 输入 | 必须断言 |
|---|---|---|
| T-CON-V0-01 | 完整电池极片涂布技术方案，目的为技术参考，测试授权允许 | 产生两项合成候选；回答包含候选来源、版本、位置、实际范围和辅助性质；无法律结论 |
| T-CON-V0-02 | 缺少检索目的且附件来源中温度为 80/120 冲突 | 返回补问和两个来源；不创建可执行检索请求或候选；不选择任一温度 |
| T-CON-V0-03 | 完整条件但测试授权拒绝 | 返回无权限；检索端口不被调用；响应不含候选、正文或匹配片段 |
| T-CON-V0-04 | 检索后使拟采用来源失效 | 返回来源失效或降级结果；失效候选不在回答依据；不得将其表述为无结果或权利失效 |
| T-CON-V0-05 | 同幂等键提交相同和不同内容 | 相同内容不重复执行；不同内容返回冲突，不覆盖原结果 |

## 4. D 门结论

`MVP-CON-V0-01` 的范围条款已具备输入、输出、来源、权限原则、异常、AI/人工边界、API 和逻辑数据设计，并有上述合成测试映射。P0-03/04/05/10 的 V0 决策允许本任务使用合成数据、默认拒绝授权、内存实现和非外部模型回答生成。

结论：**本任务的 D 门通过，仅准许实现并验证合成数据 V0 闭环。** 该结论不等于 CON-02、CON-04、CON-11 或 CON-12 的完整 D 门通过，更不等于 DM8、真实权限、真实数据或专业验收通过。
