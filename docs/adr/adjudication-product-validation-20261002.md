# ADR：裁决01D同案产品验证（D1，2026-10-02续行）

来源：项目负责人要求01C通过后继续01D。01C已由实际Chromium/真实身份/双DM8/64前端/247三域/20专项及后verify通过，证据为adjudication-workspace-20261002/verification.md；本D只验证既有产品合同，不新增业务规则/状态/权限。

范围：保持01C真实浏览器完整生命周期，在来源撤回前的同一22版案件暂停浏览器；读取全部快照/审计/回执CLOB摘要与原文，真正关闭Spring应用并以同地址/同双DM8重启。禁止重新建库、重新填入案件或从fixture回灌快照。重启前后逐表字节SHA保持一致；原浏览器会话刷新案件、报告诊断/版本历史和原文引用仍可读，之后刷新页面重新走真实PKCE登录再读取同案历史v17的已复核非正式稿与当前失效旧稿/阻断v5。最后继续真实来源撤回，重启不能恢复失效来源用途。

实现仅改测试框架/验证脚本，恢复开关只用于测试调度，不增加产品参数/身份/路由或产品分支。文件握手只同步真实服务关闭/重启，不提供页面数据；所有页面数据仍真实01B。每次隔离schema，失败关闭进程并清理，结果写于清理后。01B既有跨案/撤权/来源漂移/并发/损坏恢复反例继续回归；逐项区分已有API证据与本轮浏览器重启证据，不冒全部异常都做过浏览器重启。

退出与边界：同案实际页面闭环及重启、历史及当前授权失败/并发/自审等原件、两域无回归、前后verify通过才有工程产品验证。专业质量/真实数据用途/岗位/法律结论与正式业务验收仍需责任方证据，不能从工程输入或本机械恢复反推通过。任务状态只在08主计划记录，父任务不自动完成。
