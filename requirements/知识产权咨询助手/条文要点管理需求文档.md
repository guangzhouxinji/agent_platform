# 条文要点管理需求文档

## 1. 功能概述

条文要点管理面向知识产权法律法规，从已完成解析的法规条文结构化数据中提取并管理核心要点，例如权利范围、侵权情形、构成要件、责任承担和处罚标准等。

系统支持对要点进行分类、标注和统一管理，建立要点与裁决场景、关联案例之间的关系，帮助裁决人员快速定位和引用法律法规中的关键内容。

条文要点数据由外部解析程序基于已完成的条文解析结果一次性生成并导入系统，系统主要负责数据接收、关联校验、列表展示、查询和维护。

## 2. 数据来源与导入

条文要点采用结构化数据一次性导入方式。导入数据应关联到法律法规和具体条文，关联关系包括法规编号、法规名称及所属条文编号。

### 2.1 导入内容

- 要点编号；
- 法规编号及法规名称；
- 所属条文编号；
- 要点内容；
- 要点类别；
- 关联场景；
- 关联案例编号；
- 提取时间；
- 更新时间。

### 2.2 导入校验

导入时应校验：

- 必填字段是否完整；
- 要点编号是否重复；
- 所属条文是否存在；
- 条文与法规的关联关系是否正确；
- 要点类别是否符合系统配置；
- 关联案例编号格式是否正确；
- 提取时间和更新时间格式是否正确。

导入完成后，应反馈成功记录数、失败记录数及失败原因。对于重复要点，可选择更新、跳过或覆盖。

## 3. 条文要点信息管理

### 3.1 信息字段

| 字段名称 | 是否必填 | 说明 |
|---|---:|---|
| 要点编号 | 是 | 要点唯一标识，不允许重复 |
| 法规编号 | 否 | 用于与法律法规库建立关联 |
| 法规名称 | 是 | 要点所属法规名称 |
| 所属条文编号 | 是 | 要点来源的具体条文编号 |
| 要点内容 | 是 | 提取出的核心法律要点 |
| 要点类别 | 是 | 权利范围、侵权情形、构成要件、处罚标准等 |
| 关联场景 | 否 | 适用的裁决或业务场景，可关联多个场景 |
| 关联案例编号 | 否 | 相关案例编号，可关联多个案例 |
| 提取时间 | 是 | 要点生成或提取时间 |
| 更新时间 | 是 | 要点最近更新时间 |
| 创建人 | 系统生成 | 数据创建人员或导入任务标识 |
| 更新人 | 系统生成 | 最近更新人员 |

### 3.2 信息维护

系统支持对导入的条文要点进行查看和编辑，维护内容包括要点内容、要点类别、关联场景及关联案例编号等。

要点编辑后应同步更新更新时间和更新人，并保留其与法规、条文的原有关联关系。原则上不允许修改要点编号；如需调整来源条文，应执行关联校验。

## 4. 条文要点列表

### 4.1 列表展示字段

列表展示以下信息：

- 要点编号；
- 法规名称；
- 所属条文编号；
- 要点内容；
- 要点类别；
- 关联场景；
- 关联案例编号；
- 提取时间；
- 更新时间；
- 操作项。

要点内容、关联场景和关联案例编号均展示完整数据，不以数量或摘要替代；内容较长时支持换行、滚动或展开查看。

### 4.2 查询与筛选

支持：

- 按要点编号、法规名称、法规编号、条文编号进行关键词检索；
- 按要点内容进行全文检索；
- 按要点类别筛选；
- 按关联场景筛选；
- 按关联案例编号筛选；
- 按提取时间、更新时间范围筛选；
- 多条件组合查询。

### 4.3 列表操作

支持：

- 分页展示；
- 按提取 时间、更新时间排序；
- 查看所属法规和条文信息；
- 编辑要点信息；
- 查看关联场景和关联案例。

默认按更新时间倒序排列。

## 5. 验收要求

1. 支持导入由条文解析结果生成的结构化条文要点数据；
2. 导入数据能够正确关联法规和所属条文；
3. 导入失败数据能够展示明确的错误原因；
4. 条文要点列表支持分页、检索、筛选和排序；
5. 列表能够直接展示要点内容、关联场景和关联案例编号的完整数据；
6. 支持维护要点内容、要点类别、关联场景和关联案例编号；
7. 支持展示提取时间和更新时间；
8. 要点编辑后，列表数据和关联关系保持一致。
