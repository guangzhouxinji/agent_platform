# 知识产权咨询意图管理需求文档

对应需求：一.1.1.1.1.3.3  
文档状态：技术评审初稿，中心 API 能力、授权范围及性能参数尚需联调确认。  
交付边界：后端服务及接口说明对外交付；前端页面用于内部开发、联调和验收，不属于对外交付内容。


## 国产化与达梦 DM8 适配要求

- 本模块面向国产化环境交付，业务关系型数据库固定使用达梦 DM8；开发联调及数据库兼容验收均须覆盖真实 DM8，不能以 MySQL、H2 等环境通过替代。
- 本模块需要持久化的业务内容包括：意图配置、槽位、正反例、路由引用、版本及授权保留的解析/评测记录。数据库采用 DM8；文件二进制可使用项目已批准的文件存储，DM8 保存受控引用及元数据，不要求把所有图片和附件存入数据库。
- 驱动、连接池、ORM/持久层、分页、建表及升级脚本按实际 DM8 小版本和实例参数适配；不得直接依赖其他数据库专有语法、JSON 类型或函数。长文本、结构化内容、编号、时间及分数应选用经目标实例验证的数据类型和访问方式。
- 本模块 DM8 专项验收覆盖：多意图/多槽位结构完整读写、中文标签匹配、版本冲突及分项评测统计。验证事务失败回滚、连接故障恢复和权限控制；接口故障不伪装成空结果。需要恢复的任务应识别中断状态，按幂等规则恢复或显式失败，不盲目重放。
- 全文、向量和图像检索能力不得因采用 DM8 就视为已经具备；优先调用中心 API，自建时按总目录的国产化与检索约束选型并验证。
- 交付本模块适用的 DM8 初始化/升级脚本、数据库配置说明和真实 DM8 验证记录；确无本地业务表时注明原因，仍须验证与共用 DM8 服务的集成。其他国产操作系统、CPU、JDK、模型及中间件的具体型号以中心环境清单为准，不预设已完成适配。

详细共用要求见[需求总目录](知识产权咨询助手需求文档总目录.md)“3.7 国产化部署与达梦 DM8 数据库”。

## 1. 功能概述

配置知识产权咨询意图，识别用户问题中的核心诉求、关键词和必要业务信息，将其路由至已授权工具或补问流程。支持多意图、信息不足和无法识别的情况，不强制把每句话归入某个业务类别。

意图管理维护标签、槽位及路由规则；实际多轮补问和上下文更新由对话流执行。意图配置不能扩大智能体或用户的工具与数据权限。

## 2. 字段设计

| 字段 | 说明 |
|---|---|
| 意图编号、标签、类别、描述 | 稳定 ID 与业务定义 |
| 正例、反例、关联问题 | 定义边界并供测试 |
| 核心关键词 | 可辅助识别，不作为唯一判断依据 |
| 必要/可选槽位 | 名称、类型、校验规则、敏感级别、追问文案引用 |
| 路由目标 | 工具或对话流稳定 ID，不允许任意 URL |
| 关联资源编号 | 被授权的资源范围引用，不代表具体检索结果 |
| 配置版本、状态、更新时间 | 草稿、已发布、已停用、已归档 |
| 咨询内容、上下文引用 | 每次解析实际输入 |
| 解析结果 | 主意图、候选意图、多意图、未知或需澄清 |
| 提取值、来源轮次、缺失项 | 槽位值须可追溯 |
| 识别置信指标、解析时间、版本 | 如有置信值须说明来源，非实测准确率 |
| 解析准确率 | 标注集评测值、样本数、时间及版本 |

## 3. 首批意图与槽位

| 意图 | 必要信息 | 路由 |
|---|---|---|
| 商标信息查询 | 注册号或明确查询条件 | 商标库查询 |
| 商标相似检索 | 名称/图样、商品或服务项目及类别确认 | 商标相似检索 |
| 商标辅助比对 | 目标、候选、商品/服务 | 商标相似度判断 |
| 专利信息查询 | 号码或明确查询条件 | 专利库查询 |
| 专利相似检索 | 技术方案/特征或号码、检索目的 | 专利相似检索 |
| 专利辅助比对 | 目标、候选、分析目的及相应材料 | 专利相似度判断 |
| 案例参考 | 具体问题或关键事实 | 相似案例检索 |
| 办理/法规咨询 | 事项、涉及地域或办理机构（影响答复时必填） | 已配置的办事指南/法规查询 |
| 无法识别/超出范围 | 无 | 澄清或能力范围说明 |

表中为首版分类建议，可配置但须保持工具契约一致。条件必填槽位由目的决定，例如新颖性辅助分析需相关日期，不能所有目的都一律索要。

## 4. 识别与管理规则

1. 读取当前问题及调用方允许的上下文，识别主诉求与候选。
2. 提取槽位值，标明来自当前输入还是某轮上下文；不将模型推测当作用户已确认事实。
3. 多意图能独立处理时返回有序意图清单，有依赖时先补齐前置项；冲突或指代不清时请求澄清。
4. 槽位齐全且路由可用时返回工具/流程标识；否则返回缺失项及补问建议。
5. 对话流执行前再次做参数及权限校验，解析成功不等于允许调用。

支持新增/编辑草稿、正反例测试、批量评测、发布、停用和归档。发布前验证标签唯一、目标存在、槽位类型匹配及回退规则。已发布版本不可改写，更新由智能体显式绑定新版。

普通停用禁止新绑定，现有版本引用保持可追溯；紧急撤销即时阻止运行并进入回退。多人编辑使用版本校验。

## 5. 内部验证页面

意图列表、标签及槽位编辑、关联路由选择、正反例维护、单句/多轮解析测试、批量评测、版本发布页。

测试区并列展示输入、候选意图、提取值、来源轮次、缺失槽位和计划路由，可填写标准答案。评测区展示整体准确率、各类精确率/召回率、槽位准确性和未知意图处理情况，不只展示一个总百分比。

## 6. 服务契约与统计

| 服务 | 输入 | 输出 |
|---|---|---|
| 配置查询/保存/发布 | 意图配置与版本 | 配置、校验结果或冲突 |
| 意图解析 | 问题、允许的上下文、固定配置版本 | 意图清单、槽位、缺口及路由建议 |
| 测试/评测任务 | 测试集、配置/模型版本 | 任务 ID、结果与逐条错误 |
| 评测查询 | 任务 ID | 样本量、分项指标、时间 |

解析准确率以人工标准答案为基准，注明多意图评价口径；置信指标不能替代准确率。评测集与用于调参的样本分开记录。未知意图样本必须纳入评测。

错误区分无效配置、路由不可用、源上下文越权、模型失败和参数不合法。识别失败允许返回澄清结果，不得伪装成工具已执行。

## 7. 验收要求

| 编号 | 场景与预期 |
|---|---|
| IM-01 | 首批意图有正反例、槽位及可用路由 |
| IM-02 | 信息不足返回缺口，不伪造用户确认值 |
| IM-03 | 多意图、未知问题、指代歧义分别处理 |
| IM-04 | 后续更正覆盖对应槽位并保留来源轮次 |
| IM-05 | 意图不能绕过工具或数据权限 |
| IM-06 | 配置发布校验、版本绑定与撤销符合统一规则 |
| IM-07 | 标注集输出分项评测及样本量，目标值试测后约定 |
| IM-08 | 无页面调用解析服务可得到结构化结果 |

## 8. 依赖与交付

依赖工具能力目录、提示词、对话流、智能体配置及模型。交付配置/解析/评测服务、槽位与路由规范及验收记录，页面内部使用。

确认中心业务分类、首批样本、条件必填规则、低置信处理标准、评测阈值和性能目标。即使模型没有可标定置信分数，也必须支持未知与澄清结果。
