# Context、Memory 与 Retrieval/RAG

依据 CON-01～08/11/12、ADJ-01/05/07/08、ENF-01/05/17；`ADR-V2-03/06/07`。知识访问只在获准主体/目的/来源内进行；本稿不假定任何现有中心 API、本地索引、向量库或图像检索可用于正式任务。

## Context 分层

| 层 | 内容、版本与有效期 | 使用边界 |
|---|---|---|
| 当前任务 | Goal、确认事实、限制、焦点对象/结果集、子任务、缺口、预算、人工决定 | 唯一业务上下文；纠正产生新版本，指代指向稳定快照 |
| 工作记忆 | 中间候选、已检索范围、查询改写、工具结果、失败、冲突、待处理项 | 只用于本任务/获准子任务；压缩必须保留事实来源与未决项 |
| 领域知识 | 专利/商标/案例/法规原文及审核派生内容、版本/效力 | 候选召回与证据定位；派生解释不能冒充原文 |
| 运行与个人偏好 | Skill/Prompt/模型/规则发布版本；允许的展示偏好 | 发布快照不等于永久授权；不保存隐含推理为业务事实 |
| 长期跨任务复用 | 仅经明确目的与数据许可的已确认资料引用 | 默认不跨用户/组织/任务继承敏感文本；读取仍重验当前权限 |

历史消息可帮助指代，但不作为事实数据库。摘要保留确认者、对象/文献版本、证据引用和不确定性；无法可靠保留关键材料就重新读取或 ASK。用户纠正事实、范围/目的变化或来源版本变更时触发依赖检查。跨任务记忆、保留/删除期限、模型训练使用 **[待确认]**。

## Retrieval 阶梯

1. **发现范围**：授权来源目录、时间/地域/程序、覆盖与可用性；无权限源不入候选，源故障不记零结果。
2. **精确/结构化**：专利各类号码、商标注册号+类别、案件 ID、法规条文版本、事件时点；需要时再关键词/语义/图像召回。搜索计划记录查询、数据源、过滤、候选数、上游截断和排序版本。
3. **证据深化**：对影响结论的候选读取权利要求、原始图样、案例原文段落、历史法规和文件定位；OCR 低质/原文缺失为阻断或降级，不让摘要补全文事实。
4. **验证与停止**：按 Goal 的关键问题检查支持/反证、漏检风险和新信息增益；必要时在确认范围内改写查询/再检索；无进展、预算或来源边界到达时停止并披露覆盖。

RAG 只是一种“召回资料提供候选上下文、生成受证据约束解释”的实现手段，不是法律规则引擎、专业判断器或产品主轴。向模型发送的上下文做权限/用途/敏感字段过滤，附来源标识但模型引用须由服务端回查实际位置。排名分数用于本次相关性，不当侵权概率、注册成功率、有效性或法律适用概率；未标定不显示伪精确百分数。有限候选重排必须写明范围。

## 索引、更新与失败

- 索引来源逐类登记授权、数据集/版本、目的、删除/撤回、刷新、权限过滤和模型通道。公开可访问不自动许可批量索引、再分发或外部模型处理。DM8 是业务关系型存储要求，不等于全文/向量/图像能力。
- 原文、派生索引和引用版本要能对账；索引落后时标记覆盖/时间，权利撤回或访问撤销必须在查询前过滤并阻断旧缓存/文件直链。来源没有变更事件时，关键动作读取时再核实；无法核实则待复核。
- 零结果、没有权限、源能力未提供、网络/解析失败、结果被截断、证据不足分别返回。部分来源失败可保留已证实部分，但不称检索穷尽。
- 专利同族不能代具体公开文献；商标类别不等商品服务类似；案例相似不预测裁判；法条“现行有效”不证明历史时点适用。以上是领域检索/解释不变量。

## 可测标准

用按任务目的分层的专家标注集评 Recall@K/排序/关键证据召回、定位正确、过期结果率、越权泄漏、问题答复支持度和实际用户查证时间；对“无结果”和“来源失败”作反例。样本、K、覆盖范围及阈值待真实数据许可和专业评审，合成测试只能验证契约。
