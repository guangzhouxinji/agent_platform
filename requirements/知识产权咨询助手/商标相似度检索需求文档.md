# 商标相似度检索需求文档

对应需求：一.1.1.1.1.2.2  
文档状态：技术评审初稿，中心 API 能力、授权范围及性能参数尚需联调确认。  
交付边界：后端服务及接口说明对外交付；前端页面用于内部开发、联调和验收，不属于对外交付内容。


## 国产化与达梦 DM8 适配要求

- 本模块面向国产化环境交付，业务关系型数据库固定使用达梦 DM8；开发联调及数据库兼容验收均须覆盖真实 DM8，不能以 MySQL、H2 等环境通过替代。
- 本模块需要持久化的业务内容包括：检索任务、输入快照、受控图样引用、候选引用、各维度评分及执行记录。数据库采用 DM8；文件二进制可使用项目已批准的文件存储，DM8 保存受控引用及元数据，不要求把所有图片和附件存入数据库。
- 驱动、连接池、ORM/持久层、分页、建表及升级脚本按实际 DM8 小版本和实例参数适配；不得直接依赖其他数据库专有语法、JSON 类型或函数。长文本、结构化内容、编号、时间及分数应选用经目标实例验证的数据类型和访问方式。
- 本模块 DM8 专项验收覆盖：中文/外文输入、图样引用关联、维度缺失值、幂等与分页排序。验证事务失败回滚、连接故障恢复和权限控制；接口故障不伪装成空结果。需要恢复的任务应识别中断状态，按幂等规则恢复或显式失败，不盲目重放。
- 全文、向量和图像检索能力不得因采用 DM8 就视为已经具备；优先调用中心 API，自建时按总目录的国产化与检索约束选型并验证。
- 交付本模块适用的 DM8 初始化/升级脚本、数据库配置说明和真实 DM8 验证记录；确无本地业务表时注明原因，仍须验证与共用 DM8 服务的集成。其他国产操作系统、CPU、JDK、模型及中间件的具体型号以中心环境清单为准，不预设已完成适配。

详细共用要求见[需求总目录](知识产权咨询助手需求文档总目录.md)“3.7 国产化部署与达梦 DM8 数据库”。

## 1. 功能概述

根据商标名称、图形或文字与图形组合，以及拟申请的商品/服务信息，从授权商标数据中召回相似候选，为商标相似度判断提供输入。候选相关度不代表注册成功率或法律上的近似结论。

文字和图形属于不同检索能力，均纳入目标范围；图形能力若上游未提供，应明确补建方案及验收条件，不能用 OCR 文字查询代替图形相似检索。

## 2. 输入输出字段

| 字段 | 规则 |
|---|---|
| 目标商标名称 | 文字检索必填；保留原始字符及标准化查询值 |
| 目标图样 | 图形检索必填；组合检索同时提供名称或可识别文字 |
| 商品/服务类别与项目 | 至少确认拟使用的类别及项目；项目不明确时追问 |
| 类似群及分类版本 | 可建议，用户确认；不确定时保留待确认状态 |
| 检索维度 | 文字、读音、含义、图形或组合；仅启用已具备能力 |
| 检索范围 | 类别、状态、地域及数据源范围 |
| 任务 ID、检索时间 | 服务端生成 |
| 候选标识、注册号、名称、图样 | 关联商标详情 |
| 类别、商品/服务、状态 | 按来源展示并带更新时间 |
| 相关度、维度依据、评分版本 | 用于候选排序 |
| 实际检索范围、返回数量 | 披露范围和截断情况 |

## 3. 检索流程与规则

1. 用户输入名称或上传图样，确认类别和商品/服务项目。
2. 系统预览标准化文字、读音候选、图像及可识别元素。OCR、拼音或含义扩展存在歧义时允许用户修正，不修改原图。
3. 调用中心检索接口或获授权的文字/图像索引，按权限及明确范围召回。
4. 按维度排序或组合排序，去重后返回候选及匹配依据。
5. 查看商标详情并选择候选，进入商标相似度判断。

类别相同不等同于商品/服务类似；若只能查同类别，应说明未覆盖其他可能相关类别。跨类别扩展须有明确规则或用户选择，并展示实际范围。状态过滤由用户明确选择，不静默排除非有效记录。

图样上传首版建议支持 JPG、PNG，单文件不超过 10 MB；后端检查实际类型、文件大小及可解码性，处理 EXIF 方向，原图保留用于核验。上述限制可配置。上传文件只允许当前用户或授权调用方访问。

默认最多返回 100 条，每页 20 条，按相关度降序及稳定 ID 排序。上游限制导致覆盖不足时明确展示。只对有限候选重排须说明候选规模。

## 4. 评分规则

分开记录文字、读音、含义、图形评分或等级。组合权重、缺失维度处理及分值映射必须版本化；未执行的维度显示“未分析”，不能记为零分。无可靠数值映射时返回排序与标签，不编造 0—100 分。

“高相关”只表示候选值得进一步比对。无结果只说明当前检索条件下未发现候选，不输出“可以注册”。

## 5. 内部验证页面

- 输入：文字、图样上传/预览、类别与项目、检索维度、范围、开始检索。
- 候选：目标与候选图样、名称、注册号、类别、状态、相关度、匹配原因、来源时间。
- 操作：查看详情、修改条件、新建检索、勾选进入比对、查询历史任务。
- 图形服务未配置时明确显示不可用；不返回伪图形得分。
- 显示真实/模拟、处理中、部分成功、无结果、错误与重试等状态。

## 6. 服务契约

| 服务 | 输入 | 输出 |
|---|---|---|
| 图样上传 | 文件、调用方身份 | 受控文件 ID、格式信息 |
| 输入解析 | 名称、图样 ID、类别项目 | 可修正文字、读音及分类建议 |
| 创建任务 | 确认输入、维度、范围、幂等键 | 任务 ID |
| 查询任务/结果 | 任务 ID、分页 | 状态、候选、评分说明和范围 |
| 取消任务 | 任务 ID | 取消结果 |

异步任务采用总目录规定的状态及幂等规则。上传无效、维度不可用、源限流、超时、无权限需有明确错误及追踪号。图像访问和历史任务访问均由后端鉴权，图样保留期限随项目文件策略确定。

## 7. 验收要求

| 编号 | 场景与预期 |
|---|---|
| TS-01 | 文字、图形、组合输入分别执行对应能力，不互相冒充 |
| TS-02 | 同音、多音字、近形文字测试体现实际支持的检索维度 |
| TS-03 | 类别及项目范围准确，扩展范围可见 |
| TS-04 | 图像格式、大小及访问权限由后端校验 |
| TS-05 | 候选及维度依据可追溯，未分析维度不记为零 |
| TS-06 | 无结果、部分成功、服务失败明确区分 |
| TS-07 | 专家相关商标标注集分别评估文字与图形 Recall@K，阈值试测后约定 |
| TS-08 | 选定候选及目标快照可通过服务传递给比对模块 |

## 8. 依赖与交付

依赖商标库管理、分类字典、文件服务、文字与图像检索能力。交付接口、维度与评分说明、范围说明和验收记录，验证页面内部留用。

联调确认：商标图样授权、类别/类似群版本、跨类别规则、图像接口或索引能力、缓存权限、并发及性能目标。
