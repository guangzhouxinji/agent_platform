# 专利有效性分析需求文档

模块标识：ADJ-08；对应原需求：一.1.1.1.1.2.5。  
版本：V0.1 技术评审稿；日期：2026-09-12。  
建设条件：中心主要通过 API 提供数据；国产化部署，业务关系型数据库固定为达梦 DM8。  
交付边界：对外交付服务及接口、部署和验收资料；自研前端仅供内部验证，不交付对外页面。

本文与[需求总览与通用约定](00-需求总览与通用约定.md)共同构成开发要求。字段中文名为业务契约，接口路径和英文名由详细设计统一。涉及事实的字段缺失时返回缺口，不以模型推测满足必填。当前未完成中心 API、模型或 DM8 实测。

## 1. 功能概述与分析边界

结合涉案专利法律状态、缴费、无效程序及技术文献，对权利基础和稳定性风险生成辅助意见。必须分开输出：

1. 指定时点可核实的法律状态及权利基础资料。
2. 基于已提供/检索材料的新颖性、创造性风险分析。

存在无效请求不等于已宣告无效；模型认为存在技术风险不能改写官方法律状态。本模块不作出无效宣告决定，也不替代有权机关程序。

## 2. 字段与输入

| 字段 | 说明 |
|---|---|
| 案件编号、资料版本、专利标识/名称 | 稳定关联 |
| 文献及解析版本、所选权利要求 | 来自 07；不能仅比较摘要 |
| 分析目的、相关日期、地域 | 当前核验或案件相关时点分别确认 |
| 法律状态、状态日期及来源 | 含获取时间；历史状态无数据时标明 |
| 缴费记录 | 费种、所属期间、缴费/记录日期、来源与缺口 |
| 无效宣告情况 | 请求、受理、决定及后续程序按来源分开 |
| 对比文献、公开日期、来源 | 专利及获授权的非专利资料，逐项验证 |
| 新颖性分析、创造性分析 | 分开报告方法、依据和不足 |
| 法律状态核验意见、稳定性风险意见 | 不合并成一个无依据的有效/无效标签 |
| 有效性综合辅助结论 | 总结可核实状态、分析范围及待核实事项 |
| 分析时间、规则/模型版本、复核状态 | 服务端记录 |

## 3. 分析流程与规则

1. 确认分析时点和权利要求版本，获取状态、缴费及无效事件的原始依据。
2. 列出来源时间、事件时间和冲突；当前状态不能自动回答过去某日的有效状态。
3. 对缴费缺失仅记录无法核实；不能仅凭缺缴费记录推断权利终止。官方状态冲突时交人工核查。
4. 获取用户指定或授权检索的对比文献，核验公开日期及与相关日期的关系；日期无法核实时不作为已确认现有技术。
5. 新颖性辅助分析按单篇文献逐要素对照，不把多篇拼接覆盖直接当作单篇公开。
6. 创造性辅助分析列明选定比较基础、区别特征、拟解决技术问题、组合启示及其来源；缺乏组合依据时标明不足，不以语义相似替代分析。
7. 生成法律状态与技术风险分栏报告，交人工复核；不自动改变案件流程或启动无效程序。

新颖性/创造性分析范围不宣称覆盖全部现有技术。仅查有限专利库时明确未覆盖的文献类型。外观设计采用适配其对象的评价流程和依据，不能套用发明/实用新型分析模板；该分支是否具备完整能力须单独确认并验收。

## 4. 内部验证页面

案件/专利选择、时点、权利要求、对比资料与范围确认。结果分为法律状态时间线、缴费、无效程序、对比文献、新颖性、创造性和综合辅助意见。

每一栏显示完成/资料不足/失败，点击可核对原文和日期。支持更换资料新建分析、失败重试、补充材料和提交人工复核。未分析部分不得折算成低风险或有效结论。

## 5. 服务契约

| 服务 | 输入 | 输出 |
|---|---|---|
| 准备核验 | 案件、专利/解析版本、时点 | 数据状态及材料缺口 |
| 创建分析 | 确认输入、对比文献、范围、幂等键 | 任务 ID |
| 查询报告 | 任务/报告版本 | 分栏意见、证据、日期及不足 |
| 更新材料/重新分析 | 新资料版本、原任务引用 | 新任务，原结果保留 |
| 提交复核 | 报告版本 | 12 模块复核任务 |

状态核验成功、技术分析失败可为部分成功，必须具体说明。外部 API 超时不能返回“未发生无效”或“已有效”。无权获取的材料不得进入模型上下文。

## 6. 国产化与 DM8 要求

DM8 保存事件快照、时点、文献关系、逐项分析、规则版本及复核引用。验证时间含义、长文及证据关联、任务幂等、部分成功与新旧版本；检索、模型和全文组件遵循国产化依赖清单。

## 7. 验收要求

| 编号 | 场景与预期 |
|---|---|
| VALID-01 | 当前与历史时点区分，无历史记录返回无法核实 |
| VALID-02 | 无效请求与决定分开，缺缴费记录不推断终止 |
| VALID-03 | 状态来源冲突可见，不用模型改写官方状态 |
| VALID-04 | 对比文献公开日期核验，范围不足明确说明 |
| VALID-05 | 新颖性单篇对照，创造性组合理由有来源 |
| VALID-06 | 未分析/失败不转换为有效或低风险，外观分支不冒充文本分析 |
| VALID-07 | 人工复核留痕，分析不自动变更案件或发起外部程序 |
| VALID-08 | 专家样本与真实 DM8 验证事实、日期、证据和版本一致性 |

## 8. 依赖与交付

依赖 04、07、中心状态/缴费/无效 API、授权检索、相关法律资料及专家。交付分栏分析服务、范围/证据规则和验收记录。确认历史状态覆盖、对比资料来源、各专利类型的分析能力和评价口径。
