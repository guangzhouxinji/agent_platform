# 专利侵权证据分析需求文档

模块标识：ADJ-09；对应原需求：一.1.1.1.1.2.6。  
版本：V0.1 技术评审稿；日期：2026-09-12。  
建设条件：中心主要通过 API 提供数据；国产化部署，业务关系型数据库固定为达梦 DM8。  
交付边界：对外交付服务及接口、部署和验收资料；自研前端仅供内部验证，不交付对外页面。

本文与[需求总览与通用约定](00-需求总览与通用约定.md)共同构成开发要求。字段中文名为业务契约，接口路径和英文名由详细设计统一。涉及事实的字段缺失时返回缺口，不以模型推测满足必填。当前未完成中心 API、模型或 DM8 实测。

## 1. 功能概述

整理涉案产品、技术资料、销售记录等证据，关联待证事实，逐项对照选定权利要求，生成证据分析报告及辅助侵权意见。证据事实、当事人主张和人工认定分开，系统不自动认定证据真实性、证明力或侵权成立。

可复用执法助手已有受控文件和证据目录组件，但裁决案件关联、证据状态及审核规则独立；不能沿用处罚结论。

## 2. 字段与资料结构

| 字段 | 说明 |
|---|---|
| 案件编号、案件资料版本 | 案件权限及输入快照 |
| 证据编号、名称、类型、证据版本 | 稳定编号；实物、照片、技术资料、销售记录等 |
| 证据内容、原文件/实物位置引用 | 实物不等于文件，照片只代表可观察内容 |
| 提供方、收集人、收集时间/方式 | 按真实记录，上传时间不能替代收集时间 |
| 完整性哈希、文件类型、访问权限 | 哈希只用于完整性核对 |
| 待证事实、争议/质证意见、人工采信状态 | 未确认内容标为待核实 |
| 涉案专利、权利要求及解析版本 | 支撑逐要素对照 |
| 技术特征、对应证据片段、差异 | 页码/图片区域/其他可靠位置 |
| 要素关系 | 对应、部分对应、缺证、无法判断等 |
| 侵权判定辅助意见、依据及未决事项 | 与人工最终认定分开 |
| 分析人/执行主体、分析时间、复核状态 | 机器和人员身份分开 |

## 3. 证据管理与分析流程

1. 从中心证据 API 或授权上传接收材料，保存版本、来源和案件关系。不可读文件进入异常清单，不能因解析失败删除原材料。
2. 提取可观察事实并关联待证事项，保留反向证据、冲突及双方意见，不只选择支持侵权的材料。
3. 用户选择被分析产品/技术方案、权利要求版本及证据集合，确认哪些事实已认定、哪些仍有争议。
4. 逐项对照权利要求全部必要技术特征；每一判断须关联具体证据位置，不只比较两个专利标题或摘要。
5. 区分产品结构、制造/销售等行为证据及主体/时间关系。销售记录可支持交易事实，不自动证明产品内部技术结构。
6. 文字对应与可能的等同问题分开展示；后者须列出技术事实、依据和待专业判断事项，不按固定相似度阈值自动认定。
7. 生成报告，列出支持、冲突、缺证、排除/抗辩待核实事项及辅助意见，交 12 人工复核。

仅照片不能确认内部结构时输出缺证。外观设计按视图及整体视觉等适用流程分析，与文本权利要求矩阵分开。方法专利与产品专利需要的证据类型不同，未具备关键材料不得生成完整结论。

重复材料可识别相同哈希并提示，仍保留不同提交来源；不能直接合并成同一证据认定。追加/替换证据生成新版本并使相关分析待更新。报告不能单凭哈希、OCR 或模型分数声称证据真实、合法且充分。

## 4. 内部验证页面

案件证据目录展示编号、类型、提供方、时间、版本、可读状态、待证事实及争议状态。支持接入/上传、详情预览、补充元数据、版本查看和选择分析材料。

分析区并列显示权利要求特征与证据位置，支持人工修正事实关联、展开反向证据、查看缺口、开始/重试任务及提交复核。实物展示保管/位置记录与关联照片，不假装系统已检查实物。

## 5. 服务契约

| 服务 | 输入 | 输出 |
|---|---|---|
| 证据接收/查询 | 案件、文件/源引用、元数据、幂等键 | 证据版本、解析状态 |
| 事实关联维护 | 证据版本、待证事实、说明 | 新关联版本 |
| 创建分析 | 案件快照、权利要求版本、证据版本集合 | 任务 ID |
| 报告查询 | 任务/报告版本 | 要素表、证据、冲突及辅助意见 |
| 提交复核 | 报告版本、补充说明 | 复核任务 |

材料访问、下载及模型输入均检查案件权限，跨案证据使用须显式授权。部分材料不可读允许输出部分分析并标明缺失，不能当作未发现侵权。文件解析只处理数据，不执行文件宏或文本中的指令。

## 6. 国产化与 DM8 要求

DM8 保存证据元数据、版本、事实关系、特征对应及报告；二进制放批准的受控存储。验证多来源同哈希记录、跨表引用、长报告、版本事务及恢复后文件对应。解析和图像组件须国产环境验证。

## 7. 验收要求

| 编号 | 场景与预期 |
|---|---|
| EVID-01 | 证据来源/收集/上传时间分开，相同内容保留不同来源 |
| EVID-02 | 不可读材料与完整性状态可见，哈希不冒充真实性结论 |
| EVID-03 | 必要技术特征逐项对照，证据位置可核验 |
| EVID-04 | 缺证和反向证据进入报告，销售记录不证明内部结构 |
| EVID-05 | 方法/产品/外观对象采用正确材料与分析分支 |
| EVID-06 | 证据更换触发新版本，旧报告和人工意见保留 |
| EVID-07 | 跨案访问与模型上下文按权限限制 |
| EVID-08 | 专家样本评估要素完整性、证据支持及缺口识别，DM8 验证关系一致性 |

## 8. 依赖与交付

依赖 04、07、08 权利状态资料、证据 API/文件服务、分析规则和专业人员。交付证据关联与分析服务、结构化报告和验收记录。确认质证/采信流程、材料类型、文件限制、外观能力及专家评测样本。
