# 三域拟真合成数据 V1 任务设计

任务：DATA-SYNTH-REALISTIC-V1。目标是让开发和演示数据在字段完整度、编号形态、时间分布、版本、状态、业务关系、相关记录、干扰记录和异常场景上接近真实系统，同时始终标记为 `SYNTHETIC_V0`。

分四批执行：一，专利与商标目录扩展到可观察分页、筛选和排序的数据量；二，执法线索与证据形成多主体、多来源、缺项、冲突和失效分布；三，裁决案件、材料、法规候选和模板形成版本化关联；四，增加数据规模、引用完整性、稳定 ID、确定性和敏感标识校验。

固定回归锚点 ID 保持不变。新增记录必须由确定性生成器产生，不能依赖当前时间或随机数。名称、编号和文本均为虚构，不映射真实个人、企业、案件或权利；页面、接口和导出继续保留合成数据标识。

D 门结论：仅准许修改合成数据夹具、生成器、展示和相关自动测试，不修改真实业务规则、权限、正式状态或验收口径。

## 实施与验证结果

- 专利目录 120 条、商标目录 120 条，稳定 ID 和业务编号均唯一，既有回归锚点保持不变。
- 执法来源包含 30 条线索和 119 份证据；线索引用的证据均存在，证据关联的线索均存在，日期顺序合法，并覆盖缺项、冲突、来源失效和内容不可解析分布。
- 裁决来源包含 20 个案件和 80 份材料；每份材料显式关联案件及案件版本，每案 4 份材料，无孤立材料，并覆盖缺项、冲突和来源不可用分布。
- 四类生成结果由固定规则产生；两个独立适配器实例的有序输出完全一致，不依赖当前时间或随机数。
- 合成中心只读 API 的执法与裁决目录版本升级为 `v2`；裁决材料列表和详情均展示材料来源、案件版本关联及材料检查数据。
- 页面和接口继续显示 `SYNTHETIC_V0` 与限制说明，不把拟真合成数据解释为真实中心记录、专业结论或业务验收证据。

验证证据（2026-09-16）：`npm test` 通过；已执行的 86 项 Java 测试零失败、零错误，32 项真实 DM8 环境测试因当前终端未配置连接凭据而按条件跳过，未构成 DM8 验证证据；浏览器 17 项全部通过；治理、计划和需求基线校验通过。新增专项测试覆盖规模、唯一性、确定性、跨记录引用、日期顺序、案件版本归属与异常分布。
