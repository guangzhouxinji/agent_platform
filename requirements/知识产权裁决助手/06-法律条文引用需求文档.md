# 法律条文引用需求文档

模块标识：ADJ-06；对应原需求：一.1.1.1.1.2.3。  
版本：V0.1 技术评审稿；日期：2026-09-12。  
建设条件：中心主要通过 API 提供数据；国产化部署，业务关系型数据库固定为达梦 DM8。  
交付边界：对外交付服务及接口、部署和验收资料；自研前端仅供内部验证，不交付对外页面。

本文与[需求总览与通用约定](00-需求总览与通用约定.md)共同构成开发要求。字段中文名为业务契约，接口路径和英文名由详细设计统一。涉及事实的字段缺失时返回缺口，不以模型推测满足必填。当前未完成中心 API、模型或 DM8 实测。

## 1. 功能概述

将人工确认的法律条文规范引用到裁决报告，保存原文、法规版本、引用用途与报告位置，支持审核追溯。可从匹配结果选取，也可由授权人员直接选择法规条文，不强制依赖算法候选。

本模块生成引用对象与格式化文本，不承担条文解析或报告整体生成。概括解释不得冒充逐字原文。

## 2. 字段设计

| 字段 | 规则 |
|---|---|
| 案件编号、案件资料版本 | 关联当前案件 |
| 引用 ID、引用版本 | 稳定身份及不可变版本 |
| 法规名称/编号/版本、条文 ID/条号/款项 | 精确到实际引用层级 |
| 条文原文、引用片段 | 保留原文快照，节引不改变原意 |
| 格式化引用文本、引用样式版本 | 使用中心规范格式 |
| 引用依据、用途 | 对应案件事实/争议及实体或程序用途 |
| 报告 ID/版本、章节/段落锚点 | 不以可变页码作为唯一位置 |
| 引用时间、操作人员、审核人 | 实际操作产生 |
| 审核/可用状态 | 待确认、已确认、待复核、撤回 |
| 来源时间、失效/变更提示 | 支持历史核验 |

## 3. 业务规则

1. 选择具体条文版本，检查原文、适用时点和来源状态。
2. 选择全文或准确的款项/片段，填写引用依据与报告用途。
3. 生成法规名、条号及必要版本说明的规范文本，原文直引与概述明确分开。
4. 创建待绑定引用对象，报告生成或编辑时绑定章节/段落锚点；未进入报告的引用不计为正式使用。
5. 报告内容或位置改变后新版本重新绑定位置，保留旧报告引用关系。
6. 人工复核时核对文本、适用版本、事实支撑和引用位置。通过记录审核人；修改引用后重新审核。

使用失效法规并非一律禁止，历史案件可引用当时适用版本，但须人工说明时点依据。原文缺失、版本无法确定、来源冲突时可以保留待核实草稿，禁止作为已确认引用进入待签发文件。

引用原文采用快照核对，不能把生成式改写写入“原文”。撤回引用不删历史；来源更新提示受影响的当前报告待复核，不自动替换所有历史法条。

## 4. 内部验证页面

案件引用列表显示法规、条号、版本、用途、报告位置、确认状态、时间及审核人。支持按案件、法规、条文、状态筛选。

引用编辑区包含条文检索/匹配选择、原文与节选预览、版本/时间说明、引用依据和目标章节。操作包括创建、预览格式、绑定/调整位置、提交复核、撤回和查看历史。点击引用可打开具体版本及条款位置。

## 5. 服务契约与一致性

| 服务 | 输入 | 输出 |
|---|---|---|
| 引用预览 | 条文版本、片段、样式、用途 | 规范文本及校验项 |
| 创建/修订 | 案件版本、条文、依据、当前引用版本 | 新引用版本 |
| 绑定位置 | 引用版本、报告版本、章节锚点 | 绑定结果或冲突 |
| 查询引用/反查使用 | 案件/报告/法规版本 | 引用列表与实际位置 |
| 审核/撤回 | 引用版本、动作及意见 | 留痕及可用状态 |

绑定报告时检查案件一致和报告版本存在；报告生成过程中可按生成批次提交草稿绑定，失败批次不得留下“已采用”的孤立引用。审核流程由 12 统一执行或调用其共用审核服务。

## 6. 国产化与 DM8 要求

DM8 保存原文快照、引用版本、报告位置与审核关联。验证长文本无改写/截断、跨表一致性、生成失败补偿和并发位置更新；引用与报告同步提交须有明确事务或补偿策略。

## 7. 验收要求

| 编号 | 场景与预期 |
|---|---|
| CITE-01 | 匹配选择与手工选择均绑定具体条文版本 |
| CITE-02 | 逐字原文、节引及概述明确区分，格式可核验 |
| CITE-03 | 无依据的历史版本引用不能直接确认 |
| CITE-04 | 报告编辑后位置正确，旧版本位置仍可追溯 |
| CITE-05 | 生成失败不产生已采用孤立引用，跨案件绑定被拒绝 |
| CITE-06 | 法规更新触发待复核，历史引用不自动改写 |
| CITE-07 | DM8 和独立 API 验证引用、反查、审核及并发一致性 |

## 8. 依赖与交付

依赖 01、04、可选 05、11 报告版本和 12 审核。交付引用格式与服务、位置锚点规范及验收记录。确认中心引用样式、节引要求和审核角色；生成与引用通过批次/稳定锚点集成，避免相互等待已发布对象。
