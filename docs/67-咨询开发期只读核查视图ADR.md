# ADR-CON-OUTCOME-READ-01：开发期只读核查视图

日期：2026-09-26  
性质：技术设计决定，不是原需求业务规则或专业验收决定

## 背景与决定

CON-12要求证据不足时保留已做事项、缺口和下一步，但候选/HTTP成功不能令任务完成。当前项目原创首任务已保存输入、合成结果/焦点、确认、纠正和内部人工事件，缺分析目的、获准专业方法、真实来源和正式成果D。选择只在owner现有开发工作面组合已获准的只读响应，作为临时核查进度；不建`AnswerRevision`、完成状态、API、迁移、下载或导出。

任务GET与工作态GET没有跨请求事务。只有taskId、修订和状态一致才组成本次视图；结果、焦点、确认及人工意见还必须与工作态/确切请求的ID、序号和输入修订相符。失败/撤权/到期、错位或来源不可用时清空上次内容并标待核实，绝不把未读当无结果。旧引用可作为获准历史，但不充当当前证据。视图只含非正文元数据和缺口，不复制目标、权项或人工意见；前端不得持久保存凭据或正文。它是“最近一次读取”，不是原子快照或持续现时授权证明。具体字段与反例见docs/61第19.1节。

## 边界与复核

此视图不评价专业关系、法律结论、证据充分性、业务完成或人工实际岗位；固定`OPINION_GAP`只表示内部测试意见。真实同一时点快照及成果发布需另有后端版本化协议与领域完成标准，本ADR不替代`ARC-CON-OUTCOME-06`或专业D8。若实施需新内容、业务状态或用户可导出文件，先回主计划另过D。C要覆盖交错、历史、源失效和零写；本机开发I在双身份/真实浏览器与DM8代理下验证，不提升真实I/B。
