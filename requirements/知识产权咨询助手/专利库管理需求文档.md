# 专利库管理需求文档

对应需求：一.1.1.1.1.1.2  
文档状态：技术评审初稿，中心 API 能力、授权范围及性能参数尚需联调确认。  
交付边界：后端服务及接口说明对外交付；前端页面用于内部开发、联调和验收，不属于对外交付内容。


## 国产化与达梦 DM8 适配要求

- 本模块面向国产化环境交付，业务关系型数据库固定使用达梦 DM8；开发联调及数据库兼容验收均须覆盖真实 DM8，不能以 MySQL、H2 等环境通过替代。
- 本模块需要持久化的业务内容包括：授权保存的专利标识映射、文献版本、解析文本与位置、事件及来源记录。数据库采用 DM8；文件二进制可使用项目已批准的文件存储，DM8 保存受控引用及元数据，不要求把所有图片和附件存入数据库。
- 驱动、连接池、ORM/持久层、分页、建表及升级脚本按实际 DM8 小版本和实例参数适配；不得直接依赖其他数据库专有语法、JSON 类型或函数。长文本、结构化内容、编号、时间及分数应选用经目标实例验证的数据类型和访问方式。
- 本模块 DM8 专项验收覆盖：不同号码类型、同申请多版本、长篇权利要求/说明书完整读写、文献与事件关联。验证事务失败回滚、连接故障恢复和权限控制；接口故障不伪装成空结果。需要恢复的任务应识别中断状态，按幂等规则恢复或显式失败，不盲目重放。
- 全文、向量和图像检索能力不得因采用 DM8 就视为已经具备；优先调用中心 API，自建时按总目录的国产化与检索约束选型并验证。
- 交付本模块适用的 DM8 初始化/升级脚本、数据库配置说明和真实 DM8 验证记录；确无本地业务表时注明原因，仍须验证与共用 DM8 服务的集成。其他国产操作系统、CPU、JDK、模型及中间件的具体型号以中心环境清单为准，不预设已完成适配。

详细共用要求见[需求总目录](知识产权咨询助手需求文档总目录.md)“3.7 国产化部署与达梦 DM8 数据库”。

## 1. 功能概述与范围

接入中心专利 API，提供专利信息分类查询、全文查看、法律状态及历史事件查询，为专利相似检索和辅助比对提供可追溯的数据。支持发明、实用新型、外观设计三类专利的基础信息管理。

本模块不生成相似度评分、新颖性或侵权判断。中心源数据的新增、修改、删除由数据提供方负责，本模块不提供对应写入按钮。

## 2. 数据来源与处理规则

- 后端对接中心 API，前端仅调用本项目服务；优先按需查询，缓存、批量同步及索引建设须取得授权。
- 申请号、公开/公告号、授权公告号分别存储，不混用为同一个“专利号”。输入号码后应识别类型，无法唯一定位时返回候选供选择。
- 以数据源、源记录 ID 和文献版本 ID 定位文献；同一申请的不同公开版本分别关联，不因标题相同合并。
- 权利要求书、说明书、摘要及附图保留来源与文献版本。权利要求按编号分段，说明书按原文段落编号关联；系统生成的定位编号须与原编号区分。
- PDF/OCR 解析失败应保留可访问的原文引用及失败状态；解析未通过质量检查时不得将不完整内容标记为完整全文。
- API 未提供的缴费、无效或其他历史信息显示“数据源未提供”，不能等同于无记录。
- 缺失信息不由模型补全。法律状态按源数据展示，不仅依据保护期限或缴费日期自行判定失效。

## 3. 信息字段

| 字段 | 说明 |
|---|---|
| 数据源、源记录 ID、文献版本 ID | 记录及文献的稳定标识 |
| 申请号、公开/公告号、授权公告号 | 字符串，保留源格式 |
| 专利名称、专利类型 | 类型为发明、实用新型、外观设计或源类型待映射 |
| 申请人、发明人、地址 | 支持多个主体；源未提供时明确标识 |
| 申请日期、公开日期、授权日期 | 分别展示，缺失时不相互替代 |
| 优先权信息 | 优先权日及关联申请，提供时展示 |
| IPC/CPC 分类、外观设计分类 | 按源数据提供，不同分类体系分开 |
| 摘要、权利要求书、说明书、附图 | 原文及可定位的解析文本 |
| 保护期限、法律状态 | 源值及可选统一映射值，保留状态日期 |
| 申请、授权、缴费、无效等事件 | 类型、业务日期、结果、来源及关联文献 |
| 来源更新时间、本次获取时间 | 两个时间分别记录 |
| 原文链接或来源引用 | 用于查看原文和后续分析取证 |

## 4. 查询与详情

### 4.1 查询规则

支持申请号/公开公告号精确查询，名称、申请人、发明人包含查询，类型、分类号、状态及申请/授权日期范围筛选。不同字段之间为“且”，同字段多选之间为“或”；分类号是否包含下级分类作为明确参数。

日期范围含端点；开始晚于结束时前后端均拒绝。默认每页 20 条，可选 10/20/50，最多 50 条。默认申请日期倒序、同日期按稳定标识排序，缺失日期置后。中心不支持的全局筛选、排序、总数须记入能力差异并解决，不得只处理当前页伪装成全库处理。仅有游标时使用上一页/下一页，不伪造总数。

### 4.2 详情与历史

详情分为基本信息、权利要求、说明书、附图、法律状态及事件记录。支持切换中心提供的文献版本，当前版本和历史版本均标明号码及日期。历史事件默认业务日期倒序，不把无效申请当作无效决定。

全文提供章节定位、展开和原文查看。外观设计若无权利要求书，应显示“该文献类型不适用/源未提供”，依据实际数据区分。各标签独立加载，局部失败不清空其他内容。

“重新获取”重新访问数据源；启用缓存时绕过缓存，失败保留旧数据并标记获取失败。源记录暂时不可用不等于权利失效。

## 5. 内部验证页面

- 查询区：各筛选项、查询、重置。
- 列表：号码、名称、类型、申请人、申请日期、法律状态、来源更新时间、查看详情。
- 详情：第 4.2 节标签、版本选择、原文入口、图像预览及重新获取。
- 联调区：真实/模拟标识、数据来源、获取时间、缓存状态、追踪号。
- 页面有加载、空结果、未提供能力、无权限、失败及重试状态；修改条件回首页，旧请求不覆盖新请求。
- 不设置源专利数据的新增、编辑、删除按钮。全文下载仅在源授权允许时开放。

## 6. 服务契约与异常

| 服务 | 输入 | 输出 |
|---|---|---|
| 专利列表 | 查询条件、页码或游标 | 记录、实际分页、来源时间 |
| 号码解析与定位 | 号码、可选号码类型 | 唯一记录或待选择候选 |
| 专利详情 | 稳定记录标识、可选文献版本 | 基本信息、可用文献及子项状态 |
| 文献内容 | 文献版本、内容类型 | 原文引用、解析文本、定位信息、解析状态 |
| 事件查询 | 稳定记录标识、事件类型、分页 | 事件及原文依据 |

按项目统一接口规范返回参数错误、记录不存在、无权限、源能力缺失、超时、限流和解析失败等错误及追踪号。凭据只在后端保存；只读重试有上限。内部登录权限及字段访问限制由后端执行。

## 7. 验收要求

| 编号 | 场景与预期 |
|---|---|
| PL-01 | 三类专利样本能按号码定位，号码类型不混淆 |
| PL-02 | 组合条件、日期边界、多页检索与全局排序符合约定 |
| PL-03 | 同一申请的不同版本可区分，引用指向实际选定版本 |
| PL-04 | 权利要求编号、说明书段落及附图与原文抽查一致 |
| PL-05 | 缺失、解析失败、不适用三种状态可区分，不生成伪全文 |
| PL-06 | 法律事件正确关联，申请与决定不混淆 |
| PL-07 | 更新失败保留旧数据并标记，不推断权利失效 |
| PL-08 | 页面与直接服务调用均通过权限及异常测试，脱离页面可调用 |

## 8. 依赖、交付与联调确认

依赖中心专利查询、文献和事件 API，以及项目认证、文件访问和日志能力。交付服务、接口及字段映射说明、文献解析规则和验收记录；验证页面内部留用。

联调确认：号码体系、文献版本关系、全文及图片授权、事件覆盖、日期含义、检索语义、分页排序、缓存/索引权限、限流及性能目标。无法提供的数据能力逐项形成补齐或范围调整结论，不默认为已实现。
