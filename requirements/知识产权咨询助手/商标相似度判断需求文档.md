# 商标相似度判断需求文档

对应需求：一.1.1.1.1.2.4  
文档状态：技术评审初稿，中心 API 能力、授权范围及性能参数尚需联调确认。  
交付边界：后端服务及接口说明对外交付；前端页面用于内部开发、联调和验收，不属于对外交付内容。


## 国产化与达梦 DM8 适配要求

- 本模块面向国产化环境交付，业务关系型数据库固定使用达梦 DM8；开发联调及数据库兼容验收均须覆盖真实 DM8，不能以 MySQL、H2 等环境通过替代。
- 本模块需要持久化的业务内容包括：分析任务、目标/候选快照、维度意见、依据引用、报告及复核版本。数据库采用 DM8；文件二进制可使用项目已批准的文件存储，DM8 保存受控引用及元数据，不要求把所有图片和附件存入数据库。
- 驱动、连接池、ORM/持久层、分页、建表及升级脚本按实际 DM8 小版本和实例参数适配；不得直接依赖其他数据库专有语法、JSON 类型或函数。长文本、结构化内容、编号、时间及分数应选用经目标实例验证的数据类型和访问方式。
- 本模块 DM8 专项验收覆盖：多维意见完整读写、图样引用、未分析与空值区分、版本冲突和审核留痕。验证事务失败回滚、连接故障恢复和权限控制；接口故障不伪装成空结果。需要恢复的任务应识别中断状态，按幂等规则恢复或显式失败，不盲目重放。
- 全文、向量和图像检索能力不得因采用 DM8 就视为已经具备；优先调用中心 API，自建时按总目录的国产化与检索约束选型并验证。
- 交付本模块适用的 DM8 初始化/升级脚本、数据库配置说明和真实 DM8 验证记录；确无本地业务表时注明原因，仍须验证与共用 DM8 服务的集成。其他国产操作系统、CPU、JDK、模型及中间件的具体型号以中心环境清单为准，不预设已完成适配。

详细共用要求见[需求总目录](知识产权咨询助手需求文档总目录.md)“3.7 国产化部署与达梦 DM8 数据库”。

## 1. 功能概述

对目标商标与选定候选商标按文字、读音、含义、图形、整体视觉及商品/服务关系进行辅助比对，形成可追溯的分析意见。与商标相似度检索分开，支持从检索进入或直接选择对象。

输出为辅助意见，不将检索相关度转换为注册成功率，不自动形成正式审查或裁决结论。

## 2. 输入输出字段

| 字段 | 说明 |
|---|---|
| 目标商标名称、图样 | 至少有一项；按所选维度检查输入是否充分 |
| 目标商品/服务、类别、类似群 | 保留用户确认值和分类版本 |
| 候选商标标识、图样及来源快照 | 一个或多个，分别出报告 |
| 分析目的、地域、相关时间 | 决定依据范围，缺失时追问 |
| 分析维度 | 文字、读音、含义、图形、整体视觉、商品/服务关系 |
| 各维度比对内容、证据、意见 | 分开记录，不适用与未分析区分 |
| 综合辅助意见、判断依据 | 包含支持理由、差异及信息缺口 |
| 使用标准及版本 | 指向实际检索到的依据和条款 |
| 分析时间、任务/报告 ID、审核状态 | 服务端生成 |

## 3. 分析流程与规则

1. 接收目标和候选，对候选重新验证访问权限并获取名称、图样、商品/服务及状态。
2. 确认用户的商品/服务项目与分析目的；类别不明确时先补问。
3. 预览 OCR、读音与含义识别结果，歧义项允许用户修正。
4. 对每个候选逐维度对照，再结合商品/服务关系形成综合辅助意见。
5. 返回报告及依据，支持内部专业复核、添加意见和新版本分析。

文字比对保留字形、顺序、组成等可观察差异。读音对多音字、外文读法无法确认时标注不确定。含义分析区分材料可支持的含义与模型推测。图形与整体视觉须实际访问图样，不能只依据名称生成图像结论。

商品/服务类似关系须说明参考的项目、类似群及分类/标准版本，不能仅凭同类别判为类似，也不能仅凭不同类别排除关联。

综合意见采用“存在需重点复核的相似因素”“已分析维度差异较明显”“材料不足，无法形成综合意见”等描述，并给出具体理由。不能根据简单多数投票或任意阈值直接得出法律近似结论。

## 4. 报告与复核

报告含目标及候选快照、商品/服务、维度表、原图并列、文字证据、依据条款、综合意见、未分析维度、数据时间和模型/规则版本。

每个维度显示已分析、不适用或材料不足。原需求未要求本模块输出数字评分，首版以有依据的维度意见为主；如后续新增分数须独立定义标尺，不复用检索分数。

报告初始为未复核，专业人员可提交复核意见；原始生成内容不被覆盖。需正式采用时由中心完成专业审核。源状态或依据更新后再次分析生成新版本，旧报告保留当时数据时间。

## 5. 内部验证页面

- 目标信息、图样及商品/服务输入区。
- 候选选择及详情预览，选择分析维度、目的和时间。
- 开始分析、任务进度、逐候选状态、失败重试。
- 目标与候选并列展示，各维度展开查看、原图放大、依据定位。
- 复核意见区、历史报告版本、真实/模拟标识。
- 缺图、缺项目或缺依据时明确提示缺口，不展示完整分析已完成。

## 6. 服务契约

| 服务 | 输入 | 输出 |
|---|---|---|
| 分析准备 | 目标、候选、目的 | 资料完整性、待确认项目 |
| 创建分析 | 确认输入、候选快照、维度、幂等键 | 任务 ID |
| 查询任务/报告 | 任务或报告 ID | 状态、维度意见、依据及综合意见 |
| 提交复核 | 报告版本、意见及动作 | 审核记录或冲突 |
| 取消任务 | 任务 ID | 取消结果 |

任务使用总目录中的异步规则。凭据、图像和报告通过后端权限校验；错误区分图像失效、资料不足、来源故障、依据未提供、模型失败及无权限。缺少依据时可展示已完成的可观察差异，但不能编造标准条款。

## 7. 验收要求

| 编号 | 场景与预期 |
|---|---|
| TC-01 | 检索跳转和直接选择均正确绑定目标、候选与商品/服务 |
| TC-02 | 文字、读音、图形等维度分别有事实支持 |
| TC-03 | 缺失图样不生成图形/整体视觉完整意见 |
| TC-04 | 商品/服务判断不简单等同于类别一致与否 |
| TC-05 | 引用的标准版本及条款可核验，缺依据不编造 |
| TC-06 | 未分析维度明确，综合意见反映材料缺口 |
| TC-07 | 复核与重新分析保留历史版本，未授权用户无法查看 |
| TC-08 | 专家按维度评估事实准确性、依据支持度和综合意见合理性 |
| TC-09 | 报告可通过独立接口获取，页面不是服务运行前提 |

## 8. 依赖与交付

依赖商标库、相似检索（可选入口）、文件及图像分析、分类与审查标准、专业复核。交付比对接口、报告结构、依据及版本规则、验收记录；页面仅内部验证。

确认图形能力、标准与分类资源、商品/服务关系口径、相关时间含义、专家人员、任务规模和性能目标。
