# 相似案例检索需求文档

对应需求：一.1.1.1.1.2.5  
文档状态：技术评审初稿，中心 API 能力、授权范围及性能参数尚需联调确认。  
交付边界：后端服务及接口说明对外交付；前端页面用于内部开发、联调和验收，不属于对外交付内容。


## 国产化与达梦 DM8 适配要求

- 本模块面向国产化环境交付，业务关系型数据库固定使用达梦 DM8；开发联调及数据库兼容验收均须覆盖真实 DM8，不能以 MySQL、H2 等环境通过替代。
- 本模块需要持久化的业务内容包括：检索任务、问题快照、候选文书引用、参考点/差异及排序信息。数据库采用 DM8；文件二进制可使用项目已批准的文件存储，DM8 保存受控引用及元数据，不要求把所有图片和附件存入数据库。
- 驱动、连接池、ORM/持久层、分页、建表及升级脚本按实际 DM8 小版本和实例参数适配；不得直接依赖其他数据库专有语法、JSON 类型或函数。长文本、结构化内容、编号、时间及分数应选用经目标实例验证的数据类型和访问方式。
- 本模块 DM8 专项验收覆盖：长咨询文本、文书版本关联、证据内容、任务幂等及稳定分页。验证事务失败回滚、连接故障恢复和权限控制；接口故障不伪装成空结果。需要恢复的任务应识别中断状态，按幂等规则恢复或显式失败，不盲目重放。
- 全文、向量和图像检索能力不得因采用 DM8 就视为已经具备；优先调用中心 API，自建时按总目录的国产化与检索约束选型并验证。
- 交付本模块适用的 DM8 初始化/升级脚本、数据库配置说明和真实 DM8 验证记录；确无本地业务表时注明原因，仍须验证与共用 DM8 服务的集成。其他国产操作系统、CPU、JDK、模型及中间件的具体型号以中心环境清单为准，不预设已完成适配。

详细共用要求见[需求总目录](知识产权咨询助手需求文档总目录.md)“3.7 国产化部署与达梦 DM8 数据库”。

## 1. 功能概述

根据用户的知识产权问题和补充事实检索相关案例，输出案情、争议焦点及法律问题方面的可参考点和关键差异，供咨询智能体引用。相关案例仅作为参考，不将他案结果直接当作当前问题处理结果。

本模块调用案例库，不承担源案例编辑、派生标注审核或最终咨询回答。

## 2. 输入输出字段

| 字段 | 说明 |
|---|---|
| 咨询问题、补充事实 | 保留原文及本次检索快照 |
| 知识产权类型、争议类型 | 系统建议，允许用户确认修改 |
| 检索关键词、关键事实、法律问题 | 用于召回和解释 |
| 检索范围 | 机构、程序、裁判日期、案例类型及授权数据范围 |
| 任务 ID、检索时间 | 服务端记录 |
| 案例标识、编号、名称 | 关联具体文书/版本 |
| 相关程度、排序依据 | 案情、争议焦点等维度，不代表结果预测 |
| 裁判结果、参考点、关键差异 | 原文或已审核派生信息支持 |
| 原文证据、关联法条 | 文献/版本/段落引用 |
| 实际范围、结果数量 | 区分返回数和可靠总数 |

## 3. 流程与检索规则

1. 解析咨询问题，提取关键事实和争议焦点。仅有“商标问题”等宽泛描述时返回补问信息，不伪造事实。
2. 用户确认后创建检索任务；咨询智能体调用时可直接传入已确认条件。
3. 在权限范围内按关键词、争议焦点及语义召回候选，使用已发布标注提升检索质量。
4. 对候选按法律问题、关键事实及程序等相关程度排序，逐条解释可参考点及差异。
5. 用户查看原文，选择参考案例或调整条件发起新任务。

原文可独立检索，未经审核的派生要点不作为已校核依据输出。使用原文临时生成解释时明确是本次生成内容，并提供证据。相同纠纷的不同审级/程序可聚合展示但不得合并裁判结果；只在可靠关联关系下聚合。

默认相关度降序及稳定 ID 排序，最多返回 50 条，页面每页 10 条，配置可调整。中心只返回有限候选时披露范围；语义能力不足时不能把普通关键词查询标为已完成语义检索。

不同年代案例的适用法规版本分别保留；不默认历史案例结论适用当前事实。查不到结果返回范围说明和建议补充条件，不生成虚构案例。

## 4. 评分与引用

相关度用于检索排序；数值输出须有固定算法/映射和版本，未完成标定时使用排序与标签。案情相似度不等于裁判结果发生概率。

每个结果至少包含来源标识、可用原文引用和排序理由。证据指向案件事实、争议或裁判段落；无证据的生成解释不能作为确定裁判要点。调用报告时按当前权限重新检查引用可访问性。

## 5. 内部验证页面

输入咨询问题、补充事实及范围，展示可编辑的关键词和争议标签，支持开始检索、重置、新建任务。结果卡片展示案例名称、类型、机构、日期、裁判结果、相关度、参考点和差异。

详情支持原文定位、关联法条与版本查看、选择供咨询引用。显示真实/模拟模式、实际范围、任务状态、部分失败和无结果。修改问题后保留旧任务并创建新任务。

## 6. 服务契约

| 服务 | 输入 | 输出 |
|---|---|---|
| 问题解析 | 咨询问题、补充事实 | 检索要素或需补问信息 |
| 创建检索 | 确认要素、范围、幂等键 | 任务 ID |
| 查询任务/结果 | 任务 ID、分页 | 状态、候选、证据、参考点和差异 |
| 取消任务 | 任务 ID | 取消结果 |

遵循总目录异步任务、权限和错误规范。没有记录、能力未提供、源接口故障分别返回；受限案例不得进入未经授权的模型上下文、日志或响应。

## 7. 验收要求

| 编号 | 场景与预期 |
|---|---|
| CS-01 | 宽泛问题触发补问，明确问题能形成检索任务 |
| CS-02 | 范围和权限在召回阶段生效，结果不泄露内部案件 |
| CS-03 | 候选与原文、日期、程序及结果对应 |
| CS-04 | 不同程序裁判结果不混并，历史法规版本不被替换为现行版 |
| CS-05 | 参考点和关键差异有证据，未审核标注不冒充已校核要点 |
| CS-06 | 无结果、部分失败和候选截断被正确展示 |
| CS-07 | 专家标注集评估 Recall@K、排序质量及解释证据准确性，目标试测约定 |
| CS-08 | 独立接口支持检索及向咨询传递案例版本与引用 |

## 8. 依赖与交付

依赖案例库、中心检索 API 或授权索引、法规版本资源及模型。交付检索与解释服务、接口、评分口径和验收记录，验证页面内部留用。

确认案例全文及标注质量、索引授权、机构/程序字典、分类映射、专家样本、结果上限及性能目标。
