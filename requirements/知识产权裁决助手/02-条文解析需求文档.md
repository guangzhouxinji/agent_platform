# 条文解析需求文档

模块标识：ADJ-02；对应原需求：一.1.1.1.1.1.2。  
版本：V0.1 技术评审稿；日期：2026-09-12。  
建设条件：中心主要通过 API 提供数据；国产化部署，业务关系型数据库固定为达梦 DM8。  
交付边界：对外交付服务及接口、部署和验收资料；自研前端仅供内部验证，不交付对外页面。

本文与[需求总览与通用约定](00-需求总览与通用约定.md)共同构成开发要求。字段中文名为业务契约，接口路径和英文名由详细设计统一。涉及事实的字段缺失时返回缺口，不以模型推测满足必填。当前未完成中心 API、模型或 DM8 实测。

## 1. 功能概述与既有规则

管理知识产权条文的核心含义、适用范围、构成要件及场景解析，为裁决人员理解条文提供辅助。承接根目录[条文解析管理需求文档](../../../条文解析管理需求文档.md)的外部一次性解析导入、编辑维护、完整内容列表和独立审核页面。

解析计算由外部解析程序或中心解析服务承担，本模块接收结构化结果。需由本服务发起解析时，通过已配置的解析适配器提交任务并按相同格式接收结果；这不意味着默认在法规更新时自动重算。外部解析通道属于交付依赖，只有导入界面不能证明端到端智能解析能力已验证。

## 2. 字段与关联

| 字段 | 说明 |
|---|---|
| 解析记录 ID、解析版本 | 服务生成，支持追溯 |
| 法规编号、名称、法规版本、条文 ID/条号 | 唯一关联具体原文；名称仅辅助定位 |
| 条文内容 | 原文快照及位置，不随解析编辑修改 |
| 解析内容、核心含义 | 通俗解释，并关联原文依据 |
| 适用范围、构成要件、例外条件 | 结构化项目；未涉及不编造 |
| 适用场景、关联案例 | 支持多值，案例关联具体文书版本 |
| 解析人/执行主体、模型或程序版本 | 人员和机器执行分开记录 |
| 解析时间、导入时间 | 不相互替代 |
| 审核状态、审核人、审核时间、意见 | 实际审核动作产生 |
| 创建/更新时间、修改人 | 系统记录 |

## 3. 功能与审核流程

1. 接收结构化批次或解析任务结果，检查法规版本、条文内容摘要及条号层级一致性。
2. 同一条文不同版本不得覆盖；无法唯一关联、内容不一致或案例不存在时反馈错误/缺口。
3. 新结果默认待审核，即使外部数据携带“已审核”也不能冒用本系统审核人的身份。
4. 维护人员可修改解释、范围、要件、场景和案例，保留原始生成结果及修改记录。
5. 独立审核页面支持通过、驳回、退回修改；后两者必须填写原因，修改后重新待审核。
6. 只有已审核且来源版本有效的解析作为已校核知识输出；草稿或待复核结果仅供授权内部查看。
7. 法规正文变化不自动重算或覆盖旧解析；受影响的解析增加“来源已变更/待复核”标识，旧版本仍可追溯，重新解析通过新任务或再次导入完成。

重复导入可跳过或创建新修订，更新/覆盖策略仅作用于未审核草稿；已审核内容修改产生新版本并重新审核。审核人及时间不能在普通编辑接口任意填写为已通过。

## 4. 内部验证页面

解析列表与审核列表分开。均展示条文编号、法规名称、条文全文、解析全文、适用场景、关联案例、解析人、解析时间和审核信息；内容可换行、滚动或展开，不用数量或摘要替代完整数据。

支持法规/条号、原文/解析内容检索，场景、人员、状态及时间范围筛选，默认解析时间倒序与稳定 ID 排序。

详情原文与解析并列，支持关联案例查看、编辑草稿、提交/审核、导入记录及版本比较。解析适配器启用时提供发起任务与进度入口，未接通明确说明。

## 5. 服务契约

| 服务 | 输入 | 输出 |
|---|---|---|
| 结果导入 | 批次、来源版本、幂等键 | 任务及逐条结果 |
| 发起解析（适配器模式） | 条文版本、解析配置 | 任务 ID 或依赖不可用 |
| 查询/详情 | 条件、分页或记录版本 | 全文解析、关联及审核状态 |
| 保存/提交 | 草稿版本、内容 | 新版本或冲突 |
| 审核 | 解析版本、动作及意见 | 审核事件和生效状态 |

任务状态与审核状态分开。错误包括版本不匹配、原文缺失、解析依赖故障、无权限及并发冲突；不将外部计算失败写为解析成功。

## 6. 国产化与 DM8 要求

DM8 保存解析文本、要件/场景/案例关联、导入任务和审核历史。验证长文本、条款复合关联、重复导入幂等及审核事务。外部解析程序及模型亦须符合中心国产化和数据处理要求，不能只验收数据库。

## 7. 验收要求

| 编号 | 场景与预期 |
|---|---|
| ART-01 | 批量导入或外部解析结果正确关联具体法规条文版本 |
| ART-02 | 外部生成结果默认待审核，审核时间按真实动作记录 |
| ART-03 | 列表及独立审核页可查看完整内容及案例 |
| ART-04 | 通过、驳回、退回修改与重提完整留痕 |
| ART-05 | 法规变化不覆盖旧结果，已变更来源触发待复核 |
| ART-06 | 已审核版本不能被覆盖导入或普通编辑直接替换 |
| ART-07 | 端到端样本覆盖条文含义、要件及证据核验，指标由专家试测确认 |
| ART-08 | 独立 API 与真实 DM8 验证导入、长文本、关联和并发审核 |
