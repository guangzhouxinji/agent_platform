# 专利相似度检索需求文档

对应需求：一.1.1.1.1.2.1  
文档状态：技术评审初稿，中心 API 能力、授权范围及性能参数尚需联调确认。  
交付边界：后端服务及接口说明对外交付；前端页面用于内部开发、联调和验收，不属于对外交付内容。


## 国产化与达梦 DM8 适配要求

- 本模块面向国产化环境交付，业务关系型数据库固定使用达梦 DM8；开发联调及数据库兼容验收均须覆盖真实 DM8，不能以 MySQL、H2 等环境通过替代。
- 本模块需要持久化的业务内容包括：检索任务、输入快照、候选引用、评分/规则版本和执行状态。数据库采用 DM8；文件二进制可使用项目已批准的文件存储，DM8 保存受控引用及元数据，不要求把所有图片和附件存入数据库。
- 驱动、连接池、ORM/持久层、分页、建表及升级脚本按实际 DM8 小版本和实例参数适配；不得直接依赖其他数据库专有语法、JSON 类型或函数。长文本、结构化内容、编号、时间及分数应选用经目标实例验证的数据类型和访问方式。
- 本模块 DM8 专项验收覆盖：任务幂等、候选稳定排序、分数精度、取消与迟到结果竞争及重启后状态恢复。验证事务失败回滚、连接故障恢复和权限控制；接口故障不伪装成空结果。需要恢复的任务应识别中断状态，按幂等规则恢复或显式失败，不盲目重放。
- 全文、向量和图像检索能力不得因采用 DM8 就视为已经具备；优先调用中心 API，自建时按总目录的国产化与检索约束选型并验证。
- 交付本模块适用的 DM8 初始化/升级脚本、数据库配置说明和真实 DM8 验证记录；确无本地业务表时注明原因，仍须验证与共用 DM8 服务的集成。其他国产操作系统、CPU、JDK、模型及中间件的具体型号以中心环境清单为准，不预设已完成适配。

详细共用要求见[需求总目录](知识产权咨询助手需求文档总目录.md)“3.7 国产化部署与达梦 DM8 数据库”。

## 1. 功能概述

根据技术方案、核心技术特征或专利号码检索相关专利，返回可追溯的候选结果及排序依据，供用户选择后进入“专利相似度判断”。本模块的分数表示检索相关程度，不代表侵权概率、新颖性结论或授权成功率。

发明及实用新型按技术文本检索。外观设计的名称/分类查询可复用专利库；外观图片相似检索需中心接口或独立图像能力，不能用文本检索冒充。

## 2. 输入输出字段

| 字段 | 规则 |
|---|---|
| 输入方式 | 技术方案、核心特征、专利号码三选一；可补充其他信息 |
| 技术方案/核心特征 | 用户提供的原文，不能为空 |
| 专利号码 | 解析到具体文献版本，多候选时先选择 |
| 检索目的 | 技术参考、新颖性辅助准备、侵权风险辅助准备 |
| 检索范围 | 专利类型、地域、分类、申请/公开日期范围；以实际数据能力为限 |
| 相关日期 | 新颖性辅助准备时须确认拟分析的相关日期及依据，不能默认今天 |
| 查询特征、关键词 | 提取或用户修正后的检索内容，保留原输入 |
| 检索任务 ID、状态 | 任务追踪 |
| 候选专利标识、号码、名称、版本 | 可打开详情及传递比对模块 |
| 相关度评分、评分版本 | 有可解释标尺时返回；不同算法版本不可直接比较 |
| 匹配特征、证据片段 | 指向候选文献具体位置 |
| 检索时间、实际范围、结果数量 | 区分返回条数、候选数量与全库总量 |

## 3. 检索流程与规则

1. 校验输入及范围；专利号码方式先获取指定版本的摘要和权利要求，全文不可用时说明实际使用内容。
2. 提取检索关键词和技术特征，用户可在提交前修改；修改后保存为本次任务的输入快照。
3. 按权限和检索范围召回候选。优先使用中心检索接口；需自建关键词、语义索引时必须获得数据授权。
4. 对候选进行去重及排序，生成匹配片段。默认按相关度降序，同分按稳定 ID 排序。
5. 返回结果，用户可查看原文、修改条件重新检索、勾选候选进入比对。

新颖性辅助检索不默认只查有效专利；失效文献仍可能具有参考价值。公开日期筛选必须与申请日期区分，仅有专利库不能宣称穷尽全部现有技术。同族聚合仅在关系可靠时启用，聚合后仍可展开具体文献版本。

如只能在中心返回的有限候选内重排，应标注“在本次返回的候选范围内排序”及候选数。不得称为全库语义检索。未查到结果不等于不存在相关技术。

建议任务结果最多返回 100 条、页面每页 20 条，此为初版产品默认值，需在配置中可调整。上游限制更小时显示实际截断情况。

## 4. 评分与证据

- 同一检索任务使用同一排序版本。若使用 0—100 分，必须有固定映射规则及标尺说明；不得由大模型随意编造精确分数。
- 无稳定评分时返回排序和相关程度标签，并将数值评分列为需补齐能力。
- 关键词命中、语义相关等依据分开展示，缺少依据时不伪造原文。
- 评分仅用于本次检索排序，不与专利比对评分混用。

## 5. 内部验证页面

输入区包括输入方式、文本/号码、目的、范围、特征预览与编辑、开始检索。结果区展示任务状态、实际范围、候选列表、相关度、匹配片段、查看原文及“加入比对”。

提供历史任务查看、重新检索、失败重试。新任务不覆盖旧任务；模拟模式醒目标识。跳转比对携带目标输入快照和选中文献版本，后端重新校验访问权限。

## 6. 服务契约与异常

| 服务 | 输入 | 输出 |
|---|---|---|
| 检索输入解析 | 输入方式、内容 | 号码候选或技术特征建议 |
| 创建检索任务 | 确认输入、范围、目的、幂等键 | 任务 ID |
| 任务/结果查询 | 任务 ID、分页 | 状态、结果、范围、评分版本、证据 |
| 取消任务 | 任务 ID | 取消请求结果 |

状态为排队、处理中、成功、部分成功、失败、取消；部分成功必须说明哪些数据源或步骤失败。取消后不再发布迟到的成功结果。重复幂等键及相同请求返回同任务，不同请求返回冲突。

源超时、限流、文献不可用、权限不足、索引不可用分别返回错误和追踪号；任务由服务端执行，关闭页面不影响。API 凭据不暴露前端。

## 7. 验收要求

| 编号 | 场景与预期 |
|---|---|
| PS-01 | 三种输入均能形成可追溯检索任务，号码多候选须选择 |
| PS-02 | 修改特征后实际检索使用修改值并保留输入快照 |
| PS-03 | 专利类型、日期及权限过滤正确，未仅对当前页过滤 |
| PS-04 | 结果与原文版本、匹配片段对应，排序稳定 |
| PS-05 | 有限候选、部分失败和结果截断明确披露 |
| PS-06 | 重复提交、取消、失败重试及页面关闭符合任务规则 |
| PS-07 | 专家标注集计算 Recall@K、排序质量，冻结样本与算法版本；目标值试测后约定 |
| PS-08 | 独立调用服务可获取结果并传递比对模块，不依赖页面 |

## 8. 依赖与交付

依赖专利库管理、中心检索 API 或授权索引、模型/排序能力。交付任务与检索服务、评分说明、接口说明、测试集口径和验收记录；内部页面不交付。

确认全文覆盖、检索接口语义、同族关系、相关日期输入口径、图像能力、索引授权、数据量及响应时间目标。未确认的图像能力不能标记为已实现。
