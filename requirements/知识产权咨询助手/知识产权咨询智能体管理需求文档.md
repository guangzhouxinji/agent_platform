# 知识产权咨询智能体管理需求文档

对应需求：一.1.1.1.1.3.1  
文档状态：技术评审初稿，中心 API 能力、授权范围及性能参数尚需联调确认。  
交付边界：后端服务及接口说明对外交付；前端页面用于内部开发、联调和验收，不属于对外交付内容。


## 国产化与达梦 DM8 适配要求

- 本模块面向国产化环境交付，业务关系型数据库固定使用达梦 DM8；开发联调及数据库兼容验收均须覆盖真实 DM8，不能以 MySQL、H2 等环境通过替代。
- 本模块需要持久化的业务内容包括：智能体配置、不可变版本、依赖绑定、发布/回滚记录、统计与评测记录。数据库采用 DM8；文件二进制可使用项目已批准的文件存储，DM8 保存受控引用及元数据，不要求把所有图片和附件存入数据库。
- 驱动、连接池、ORM/持久层、分页、建表及升级脚本按实际 DM8 小版本和实例参数适配；不得直接依赖其他数据库专有语法、JSON 类型或函数。长文本、结构化内容、编号、时间及分数应选用经目标实例验证的数据类型和访问方式。
- 本模块 DM8 专项验收覆盖：发布原子切换、并发版本校验、依赖完整性、时间区间聚合及统计分母。验证事务失败回滚、连接故障恢复和权限控制；接口故障不伪装成空结果。需要恢复的任务应识别中断状态，按幂等规则恢复或显式失败，不盲目重放。
- 全文、向量和图像检索能力不得因采用 DM8 就视为已经具备；优先调用中心 API，自建时按总目录的国产化与检索约束选型并验证。
- 交付本模块适用的 DM8 初始化/升级脚本、数据库配置说明和真实 DM8 验证记录；确无本地业务表时注明原因，仍须验证与共用 DM8 服务的集成。其他国产操作系统、CPU、JDK、模型及中间件的具体型号以中心环境清单为准，不预设已完成适配。

详细共用要求见[需求总目录](知识产权咨询助手需求文档总目录.md)“3.7 国产化部署与达梦 DM8 数据库”。

## 1. 功能概述与范围

管理知识产权咨询智能体的场景、可调用能力、回复规则、发布版本、服务状态及效果监控。默认建设一个咨询入口，按场景调用不同服务，不要求为每个功能建立独立智能体。

本模块负责能力编排配置和运行管理；提示词正文、意图及槽位、对话状态分别由对应模块管理，避免重复维护。中心 API 凭据和模型密钥复用后端配置，不在页面明文展示。

## 2. 配置与统计字段

| 字段 | 说明 |
|---|---|
| 智能体编号、名称、描述 | 编号唯一，创建后不可修改 |
| 适用用户、咨询场景 | 监管人员、企业、公众等授权范围 |
| 模型配置引用 | 引用后端模型配置，不含密钥 |
| 工具能力清单 | 商标/专利查询、检索、比对、案例、法规查询等 |
| 提示词版本、意图版本、对话流版本 | 发布时固定具体版本 |
| 知识资源与数据范围 | 授权数据源及可用资源 |
| 回复规则 | 引用、追问、资料不足处理、人工复核/转接等 |
| 配置状态、版本、配置时间 | 草稿、校验通过、已发布、已归档 |
| 服务状态 | 未启用、运行中、暂停、故障/降级，区分人工设置与探测结果 |
| 咨询量、调用量、失败量、响应耗时 | 按统计周期和口径计算 |
| 回复准确率 | 专家评测值及样本量、时间、评测版本 |
| 优化记录 | 变更说明、操作者、时间、评测及发布关联 |

## 3. 配置及发布流程

1. 创建智能体草稿，选择场景、模型、工具和数据权限。
2. 引用已发布的提示词、意图与对话流版本，配置回复规则。
3. 执行校验：引用存在、工具可用、数据权限合法、流程入口及回退存在。
4. 在内部试运行区按草稿配置测试，试运行会话与正式统计隔离。
5. 有发布权限的人员填写变更说明，发布不可变配置版本。
6. 新会话使用新版本；既有会话固定原版本。权限撤回与服务暂停即时生效，不受版本固定影响。
7. 支持回滚到历史版本，但必须重新校验依赖与权限；被撤销或存在安全问题的版本不得重新启用。

停用服务后拒绝新咨询；执行中的任务停止进一步工具调用，并以可识别的暂停状态结束，已经完成的历史记录按权限保留。故障降级时只允许明确配置的可用能力，不编造失败工具的结果。

已发布配置不可原地修改；修改复制为新草稿。草稿可删除，已发布版本只归档，不能破坏历史会话引用。

## 4. 运行监控与评测

- 咨询量定义为用户已提交首条有效问题的正式会话数；另列用户消息数、工具调用数、成功/失败数，不混为一个指标。
- 统计按 Asia/Shanghai 自然日及可选日期区间汇总；测试会话单独标记并默认排除。
- 响应耗时区分首响应与最终完成；失败率注明分母，源 API 故障与生成失败可分项查看。
- 回复准确率来自标注测试集或人工抽检，记录正确条数、有效评测条数、评测时间及配置版本；无评测时显示“未评测”。
- 用户点赞率仅作为反馈指标，不叫准确率；模型自评分也不能替代人工评测。
- 优化记录可关联错误样例、改动版本和复测结果，不自动通过线上反馈修改生产配置。

## 5. 内部验证页面

智能体列表支持编号/名称、服务状态及场景筛选。详情分为基础配置、工具资源、回复规则、版本、试运行、监控、优化记录。

操作包括创建草稿、编辑草稿、校验、试运行、发布、暂停/启用、回滚、归档。发布/回滚展示待生效版本及依赖摘要，操作留痕。监控页展示样本量、统计时间及数据延迟，未评测不显示 0% 准确率。

## 6. 服务契约与权限

| 服务 | 输入 | 输出 |
|---|---|---|
| 配置查询/保存 | 编号、配置、当前草稿版本 | 配置或版本冲突 |
| 校验/试运行 | 草稿版本、测试问题 | 校验错误或测试会话 ID |
| 发布/回滚 | 版本、变更说明、并发校验版本 | 新生效版本及依赖快照 |
| 启用/暂停 | 智能体编号、操作原因 | 服务状态 |
| 监控/评测查询 | 编号、版本、时间范围 | 指标、分母、样本和时间 |
| 优化记录管理 | 关联版本、问题与改动说明 | 留痕记录 |

配置查看、编辑、发布和运行控制分权，后端校验。发布原子切换，失败保持原版本；多人编辑不静默覆盖。接口故障、无权限、配置缺失和依赖无效返回不同错误。

## 7. 验收要求

| 编号 | 场景与预期 |
|---|---|
| AM-01 | 缺少依赖或越权工具配置不能通过发布校验 |
| AM-02 | 草稿试运行不影响正式会话及正式咨询量 |
| AM-03 | 发布后新会话使用新版本，旧会话可追溯原版本 |
| AM-04 | 回滚重新校验依赖，失败不改变当前版本 |
| AM-05 | 暂停拒绝新请求并阻止在途后续工具调用 |
| AM-06 | 咨询量、消息量、工具量口径分开，无评测显示未评测 |
| AM-07 | 编辑冲突、发布权限和密钥不下发由后端保证 |
| AM-08 | 无页面时仍可配置、发布及查询运行状态 |

## 8. 依赖与交付

依赖提示词、意图、对话流、各工具服务及认证日志。交付配置与发布服务、统计口径、接口说明和验收记录；管理页面内部使用。

确认模型可用范围、工具清单、人员权限、指标保留期限、可用性/并发/响应目标、专家评测样本和降级策略。基础运行日志和核心计数为首版要求，不默认引入复杂可视化流程平台。

## 9. 产品范围与质量治理补充（2026-09-22）

1. 咨询智能体主要面向内部知识产权业务人员、检索/分析人员和专业复核人员，通过内部工作台或授权系统提供服务；管理人员负责监督和治理。
2. 首段任务型闭环聚焦专利资料查询、专利检索、专利技术对照及一个复合场景；商标、案例、法规和更广泛复合咨询继续保留为完整产品目标。
3. 运行配置不得把固定一次工具序列、单一意图、固定技术参考目的、仅历史问题文本或开发数据源固化为完整产品限制。
4. 质量评价至少包含任务完成率、必要追问质量、纠正恢复、检索召回、排序质量、证据支持率、来源可核验率、无依据回答率、失败解释质量和多轮连续性。
5. 任务完成率以达到业务完成定义的有效任务为口径，部分完成单列；证据支持率以实质回答陈述为单位；来源可核验率以用户在权限范围内实际定位依据为准。
6. 专利、商标和案例分别建立专业标注集；不得以模型自评、关键词命中分数、sourceId 存在、HTTP 成功或页面可操作代替专业效果。
7. 项目负责人承担最终批准责任并组织样本、标注和分歧裁决记录；具体专业指标数值、目标值和通过线必须由真实标注与评审证据确定。
8. 正式业务只使用获批准的数据源和模型通道；开发适配器、公开试点或合成数据不得作为正式业务验收证据。
