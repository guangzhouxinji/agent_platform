# ADR-0045：对外调用方 API Key 鉴权

- 状态：已接受
- 日期：2026-09-18
- 决策来源：用户确认智能体项目以对外接口服务为主，并明确按 API Key 识别调用方

## 决策

对外调用首先识别调用方应用，不在智能体平台内建设企业用户体系。首个实现切片保护咨询服务 `/api/v0/consultations/**`：

- 使用 `Authorization: Bearer xj_<keyId>.<secret>` 识别调用方。
- 服务端只保存 Key ID 和密钥 SHA-256 摘要，用常量时间比较校验，不记录明文 Key。
- Key 绑定 `clientId`、可信业务主体、scope、状态、到期时间和分钟/日调用上限。
- 咨询写入、读取和来源读取分别使用 `consultation:submit`、`consultation:read`、`source:read` scope。
- 客户端传入的 `X-V0-Requester` 不作为身份证据；鉴权层用 Key 绑定的可信主体覆盖该头。
- 记录不含请求正文、Key 或模型密钥的调用审计：调用方、Key ID、请求号、方法、路径、结果、HTTP 状态和耗时。
- 开发内部页面不嵌入 Key。鉴权开关默认关闭；对外部署必须显式开启并提供合法凭据配置。

## 边界

本决策实现应用级调用方认证和咨询接口 scope 授权，不声明已具备统一身份中心、最终用户认证、企业成员管理、生产 API 网关、分布式限流或动态 Key 发放审批。未来接入统一网关时，保持调用方与 scope 语义，替换入站认证适配层。
