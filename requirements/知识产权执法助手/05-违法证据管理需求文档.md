# 违法证据管理需求文档

版本：V0.1 需求评审稿  
功能编号：ZF-05  
原需求条目：一.1.1.1.1.2.1  
所属智能体：知识产权执法助手

## 1. 功能概述与交付范围

接收和管理案件相关证据材料及其来源、版本、访问权限，支持后续分析。系统记录完整性信息，合法性、真实性由业务审核确认。

对外交付本功能的服务接口及接口说明；内部开发验证页面用于联调、演示和验收，页面不属于对外交付内容。所有业务规则、权限与结果保存由后端服务执行。

本篇与[需求总览与通用约定](00-需求总览与通用约定.md)共同构成该功能需求；身份、分页、时间、任务、错误、版本和审核按总览执行。

已确认技术约束：按中心国产化环境适配，业务数据库使用达梦 DM8，内部验证环境同样使用 DM8；具体兼容要求及验证内容遵循总览第 1.1 节。

## 2. 数据来源与依赖

中心证据 API 或授权人员上传；依赖中心案件/线索标识与账号权限，不另建完整案件办理系统。

接入时校验资源编号、关联关系、版本和访问权限；源数据缺失与调用失败分开记录。来源字段不能由模型生成或替换。具体接入能力以实际 API 联调结果为准。

## 3. 信息字段

| 字段名称 | 必填/产生方式 | 说明 |
|---|---|---|
| 证据编号 | 生成 | 唯一标识 |
| 证据名称 | 是 | 材料标题 |
| 证据类型 | 是 | 书证、物证、电子数据、视听资料等 |
| 证据内容 | 是 | 文件或中心受控资源引用 |
| 收集人 | 条件 | 未知须记录原因，不自动设为上传人 |
| 收集时间 | 条件 | 未知须记录原因 |
| 关联案件编号 | 条件 | 案件或线索至少关联一项 |
| 关联线索编号 | 条件 | 同上 |
| 存储位置 | 生成 | 内部资源标识，不暴露真实磁盘路径 |
| 证据状态 | 生成 | 待核验、已核验、已排除、已归档 |
| 来源信息 | 是 | 来源系统或上传渠道 |
| 文件摘要 | 条件 | 取得文件字节后计算 |
| 版本 | 生成 | 原件与派生件关联 |

通用附加字段：创建人、创建时间、更新人、更新时间、所属机构及 request_id；详情返回相关来源与历史版本。已有来源字段和业务编号不可随意改写。

## 4. 功能与处理规则

1. 支持接入、上传、列表、详情、受控下载及预览；文件类型和大小限额可配置。
2. 物证只管理描述、照片及保管信息，不能以电子附件代替实物管理。
3. 保留原始文件，OCR文本、转码件及摘要作为派生版本；修改元数据保留审计记录。
4. 相同摘要可提示重复，但不自动合并不同收集过程；文件摘要只用于校验字节完整性。
5. 案件权限校验覆盖预览和下载；访问日志记录操作者及时间；被引用证据不得物理删除，只能标记排除。

## 5. 服务接口需求

证据登记/上传/接入、元数据维护、关联案件或线索、列表详情、授权预览下载、核验状态变更；输出证据编号、版本与校验结果。

列表接口按内部页面规定支持筛选和分页；详情返回完整字段而非仅摘要。写入返回资源编号和版本。配置变更、人工修订及审核需记录操作人和前后状态；长时间操作按通用异步任务约定返回进度和结果。

关联资源不存在或无权限时拒绝操作；源接口不可用、解析失败或规则不适用时返回明确原因。部分结果必须同时附未处理项，不得伪装为完整成功。具体 URL 和英文参数名由技术统一设计，并随 OpenAPI 契约交付。

## 6. 内部验证页面

证据列表、上传或引用表单、预览面板、来源及版本记录；按案件、类型、状态筛选；展示原件与派生件区别。

页面展示服务返回的实际数据，操作按钮调用对应后端接口；包含加载、空数据、失败与无权限状态。支持查看 request_id 以定位联调问题。列表默认按更新时间倒序；历史结果可查看其使用的数据和配置版本。

## 7. 验收要求

1. 原件更新不得覆盖已有字节和历史引用。
2. 无案件权限的账号直接调用下载接口也被拒绝。
3. 无法预览的格式仍可在授权后下载，并显示原因。
4. 被分析结果引用的证据不可物理删除。
5. 页面操作和直接接口调用得到一致结果；直接调用不能绕过权限、字段或状态校验。
6. 错误场景返回明确原因，关联数据和历史结果未被错误覆盖。

以上场景由技术准备固定样例，记录请求、期望、实际结果和证据；涉及专业判断的期望结果由中心业务人员确认。模型效果与性能指标按总览另行试测确认，不使用模型自评分作为验收准确率。

## 8. 联调前需确认的条件

文件类型、大小、保留期限、中心资源链接有效期及原件存储位置须在接入时配置。

这些是本功能的外部依赖，未确认时可用明确标记的模拟数据开发接口和页面，但不视为真实业务联调通过。
