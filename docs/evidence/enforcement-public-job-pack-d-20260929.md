# 执法公开来源采集与候选任务组包窄 D

日期：2026-09-29  
具名技术责任：Codex  
适用任务：`CR-ENF-JOB-PACK-PUBLIC-01`、`ARC-ENF-PUBLIC-JOB-COLLECT-D-01`、`IMP-ENF-PUBLIC-JOB-COLLECT-01`

> 历史状态说明：本文件中的独立许可证/`WAITING_LICENSE`门禁已由`ARC-ENF-PUBLIC-COLLECTION-ALLOW-D-02`和`docs/02`第51节覆盖；原始采集证据与公开/内部事实分层继续有效。

## 1. 目标与边界

本切片主动采集官方公开网络材料，生成可审计的执法真实公开候选任务。它只改变`DATA-ENF-JOB-PACK-01`的输入准备方式，不改变已冻结ENF-01～11实现、现有六组最终事实、异人核验和`NEXT-V2-INT-ENF-01`触发条件。

公开页面、文书或公告本身是真实来源材料；项目生成的任务结构、场景标签和缺口清单是派生技术数据，不冒充原机关任务或结论。

## 2. 事实类型

- `PUBLIC_SOURCE_FACT`：原始URL、发布机构、页面标题、公开日期、抓取时间、HTTP状态和响应元数据、原始文件、字节数、SHA-256、来源信任等级、可定位文本及公开结果。
- `BUSINESS_REALITY_FACT`：本项目当前操作者、岗位、组织授权、内部审批、实际人工批准、正式人工回执和内部业务评价。公开材料不得填充这些字段。

公开材料可以为TASK提供事实来源和原件，但不能把文书中的执法人员或机关名称映射为本项目当前操作者/岗位。

## 3. 采集合同

采集目录必须保存版本化catalog和manifest。每个目标包含稳定ID、HTTPS官方URL、官方机构、来源类型、预期内容类型、信任等级和任务映射；运行记录查询关键词/策略、发现入口、开始/结束时间、成功与失败。采集器最多跟随同源重定向，拒绝跨源跳转、非2xx、空响应、超限、内容类型不符和HTML错误页伪装附件。

每次成功保存原始响应字节并重读SHA-256；解析只抽取标题、公开日期、正文纯文本和链接定位，不推断缺失案情、证据、权利状态或法律结论。相同SHA标为重复引用而不复制成不同事实；同URL摘要变化产生新版本或`SOURCE_CONTENT_DRIFT`，不得静默覆盖。

## 4. 许可与状态

来源状态包括`WAITING_LICENSE`和`LICENSE_VERIFIED`。公开GET成功、官方域名或官方发布均不能单独产生`LICENSE_VERIFIED`；必须存在明确许可原文/条款URL、版本、适用用途和核验摘要。没有该证据时，候选只允许保存审计快照、解析和技术映射，禁止业务工作流导入、外部模型、自动采信和正式结论。

候选状态机：

`COLLECTING -> WAITING_LICENSE / PUBLIC_DATA_READY -> WAITING_REAL_BUSINESS_FACTS -> READY -> RUNNING -> PASSED / FAILED`

- 原始字节、元数据、解析和任务映射完整但许可未知：`WAITING_LICENSE`；
- 公开事实与用途许可均可核：`PUBLIC_DATA_READY`；
- 进入现有任务包后，岗位、批准、回执或评价缺失：`WAITING_REAL_BUSINESS_FACTS`；
- 现有六组最终事实全部通过异人核验才可`READY`并自动触发真实集成。

## 5. 任务筛选和映射

候选至少覆盖正常、异常和边界三类，以及公开证据较完整和明确不完整两类。分类来自可审计的来源形态：完整正文/附件、只有索引或标题、缺底层证据、规则/程序文书而非案件。系统不得为了凑齐分类添加原文没有的案情。

ENF映射只声明可验证输入覆盖：来源/线索/解析/材料/证据关系/程序事件/行为事实/文书/处罚/引用。缺少案件底层证据、历史权利、程序事件、适用规则或内部决定时列为缺口，不得宣称对应能力已具业务结论输入。

## 6. 验收与失败

专项验收必须验证：真实在线HTTP成功、原始字节重读摘要、标题/日期定位、来源白名单、同源重定向、去重、版本、任务分类、许可失败关闭、公开/内部事实字段隔离和零正式触发。固定反例包括跨域URL、HTML错误页、摘要篡改、重复摘要、无许可却改为`PUBLIC_DATA_READY`、网络主体填入当前岗位、缺原件仍标完整及搜索摘要冒充原始来源。

D结论：合同完整且保持真实性与权限边界，`ARC-ENF-PUBLIC-JOB-COLLECT-D-01`通过，只允许实现公开候选采集器、校验器和数据包。它不使任何来源获得许可，不改变`DATA-ENF-JOB-PACK-01`当前阻塞状态，也不触发后继任务。
