# 法律法规管理需求文档

模块标识：ADJ-01；对应原需求：一.1.1.1.1.1.1。  
版本：V0.1 技术评审稿；日期：2026-09-12。  
建设条件：中心主要通过 API 提供数据；国产化部署，业务关系型数据库固定为达梦 DM8。  
交付边界：对外交付服务及接口、部署和验收资料；自研前端仅供内部验证，不交付对外页面。

本文与[需求总览与通用约定](00-需求总览与通用约定.md)共同构成开发要求。字段中文名为业务契约，接口路径和英文名由详细设计统一。涉及事实的字段缺失时返回缺口，不以模型推测满足必填。当前未完成中心 API、模型或 DM8 实测。

## 1. 功能概述与已有需求关系

接入、导入和维护知识产权法规、规章、司法解释等，提供按版本查询、修订历史、效力状态、条款定位及引用基础。复用已有法规服务，不为裁决助手重复建设另一套源库。

承接根目录[法律法规管理需求文档](../../../法律法规管理需求文档.md)的批量导入、新增编辑、修订弹窗和历史原文规则；本篇补充裁决适用时间、稳定版本及 DM8。中心 API 原始数据只读，人工维护写入本地校核版本；保存来源与差异，不回写中心。

## 2. 字段与数据规则

| 字段 | 规则 |
|---|---|
| 法规编号、法规名称 | 编号稳定唯一；名称不可作为唯一关联键 |
| 发布部门、发布时间、实施时间 | 发布与生效时间分别记录 |
| 法规类别、业务领域、适用地域 | 按中心字典，多领域可多选 |
| 法规全文、版本 ID、原文来源 | 长文本及不可变版本；保留源 ID 和获取时间 |
| 生效/失效区间、效力状态 | 未生效、现行有效、已失效、已废止及无法核实；以来源为依据 |
| 条文结构 | 稳定条文 ID、条号及款项层级、原文位置 |
| 修订记录 | 修订日期、类型、说明、依据、修订前原文、对应新版本 |
| 创建/更新人员和时间 | 系统记录；与来源更新时间分开 |

## 3. 接入与维护流程

1. 通过 API 获取或批量导入法规、全文及修订记录；人工新增走本地记录入口。
2. 校验必填字段、日期、类型、来源关联和版本；未能关联的记录进入失败清单，不猜测归属。
3. 导入预览说明新增、更新、跳过数量。相同源版本重复导入幂等；正文变化创建新版本，不能覆盖已引用的原文。
4. 人工编辑保留修改前值、理由和人员；来源冲突标为待核实，待核实内容不能自动确认为裁决依据。
5. 查询可选择当前版本或指定时点候选版本。业务人员仍需核实过渡条款、适用地域及案件时间，不仅凭日期自动认定适用。
6. 修订记录按日期倒序查看，支持新增、编辑及删除错误记录；已被引用的记录只能标记撤回并留痕，不能物理删除破坏引用。

修订时原文保持“本次修订前全文”语义，同时明确它属于哪个旧版本。当前正文修改不改变历史快照。存在多版本或编号歧义时返回候选供确认。

## 4. 内部验证页面

法规列表支持编号精确、名称包含、发布部门、类别、领域、状态和发布日期范围组合查询。默认更新时间倒序及稳定 ID 排序，分页遵循总览约定。

列表显示法规编号、名称、部门、发布时间、实施时间、类别、状态、更新时间；提供导入、导入结果、人工新增、编辑本地版本、详情及修订记录入口。

详情展示全文、条款树、版本和来源。修订弹窗显示全部历史及“查看修订前原文”，支持授权维护和错误撤回。未提供原文、源服务失败与无记录区分，当前/历史版本明确标注。

## 5. 服务契约与权限

| 服务 | 输入 | 输出 |
|---|---|---|
| 导入/接入任务 | 源引用或批次、重复处理策略、幂等键 | 任务 ID、成功/失败行及原因 |
| 查询/详情 | 条件、分页；法规和版本 ID | 元数据、全文、结构及效力来源 |
| 保存本地版本 | 原版本、修改内容、理由 | 新版本或并发冲突 |
| 修订维护 | 法规、修订记录、动作及理由 | 记录及版本关联 |
| 时点版本查询 | 法规、相关日期、地域 | 候选版本、效力区间及待核实项 |

查询、维护、导入权限分开。错误区分原文缺失、重复冲突、无法关联、无权限和中心故障。条文匹配及引用服务使用稳定 ID 与具体版本，不依赖名称关联。

## 6. 国产化与 DM8 要求

DM8 保存授权法规、本地版本、条款层级、修订和操作记录；文件可使用批准的存储。验证长篇法规完整读写、中文查询、复合唯一性、日期区间及批量事务；不得使用未经 DM8 验证的其他数据库 JSON/分页语法。交付初始化/升级脚本与真实 DM8 测试记录。

## 7. 验收要求

| 编号 | 场景与预期 |
|---|---|
| LAW-01 | API 与批量导入按来源规则入库，逐行反馈失败原因 |
| LAW-02 | 重复版本不重复新增，正文更新产生新版本 |
| LAW-03 | 人工新增和编辑可用，不改写中心原始记录 |
| LAW-04 | 修订弹窗及修订前原文与历史版本对应 |
| LAW-05 | 按时点返回候选，缺少过渡规则不自动认定适用 |
| LAW-06 | 已引用记录撤回仍保留追溯，历史原文不被覆盖 |
| LAW-07 | 页面及独立 API 在真实 DM8 完成查询、长文本、升级与并发验证 |

## 8. 依赖与交付

依赖中心法规接口/导入文件、法规版本与效力字典。交付服务、导入规范、来源与版本说明及验收记录。确认历史版本完整度、条款结构、人工校核角色和源数据授权；不存在的 API 能力不视为已实现。
