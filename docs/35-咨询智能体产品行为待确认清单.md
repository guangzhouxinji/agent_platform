## 1. 决策效力与保留项

本文件是咨询智能体产品行为的负责人基线。负责人有权决定的产品范围、交互、任务行为、AI/人工边界和评价维度，自本次确认起不再以“不存在的专家确认”作为设计前置条件。

下列事项仍须取得对应外部证据，本文件不代替其责任方作结论：

- 具体数据源授权、全文/权利要求存储与模型使用授权；
- 生产身份、组织、角色和 DataScope 规则；
- 数据保留期限、删除和审计期限；
- 专业评测集、指标数值、K 值、目标值和通过线；
- 具体人工接收岗位、服务时间和组织流程；
- 生产模型、数据出域、供应商与安全批准。

核心原则：**完整产品能力不能被当前 V0 限制反向定义。** V0 继续作为历史技术验证材料，不是最终产品边界。

## 12. 负责人产品原则

| ID | 原则 |
| --- | --- |
| P-01 | 用户表达业务目标，不要求用户理解内部模块。 |
| P-02 | 授权范围内的低风险、只读、可恢复能力，智能体可以主动执行。 |
| P-03 | 智能体不是一问一答工具，可以根据中间结果继续处理、检索和深化证据。 |
| P-04 | 智能体可以优化方法，但不能擅自扩大用户明确限定的业务范围、权限或风险边界。 |
| P-05 | 用户纠正事实后，只使受影响的下游结果失效，并保留历史版本。 |
| P-06 | 结果存在不等于任务完成；任务完成必须同时考虑用户目标和证据。 |
| P-07 | 引用存在不等于证据充分；实质回答陈述必须能够追溯到足够证据。 |
| P-08 | 无结果、证据不足、无权限、来源失效、模型失败、工具失败和系统故障必须区别表达。 |
| P-09 | AI 负责理解、抽取、检索、归纳、辅助分析和草拟；正式专业、法律或业务决定由授权人员完成。 |
| P-10 | V0 可为技术验证缩小范围，但任何 V0 限制都不能自动成为最终产品限制。 |

## 13. 首段任务型闭环

```text
用户自然语言目标
-> 理解目标
-> 必要追问
-> 提取并确认关键事实
-> 专利资料查询/检索
-> 判断结果是否足够
-> 必要时继续检索或深化证据
-> 候选解释
-> 技术特征逐项对照
-> 证据引用
-> 形成辅助回答
-> 接受用户纠正或追问
-> 在同一任务中继续处理
-> 完成 / 部分完成 / 证据不足 / 需要人工复核 / 技术失败 / 用户取消
```

该闭环是完整产品目标的首段实现路线，不是新的 V0，也不删除商标、案例、法规或更广泛复合咨询目标。
