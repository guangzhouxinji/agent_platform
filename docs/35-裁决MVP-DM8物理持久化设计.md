# 裁决 MVP DM8 物理持久化设计

版本：V0.2  
日期：2026-09-16  
关联任务：`ARC-10-ADJ-PHYSICAL`  
前置：`docs/33-裁决MVP逻辑持久化设计.md`、`MVP-ADJ-V0-02`、本机 DM8 JDBC 验证。  
设计性质：只映射合成 V0 到本机隔离 DM8；不表示中心 DM8、真实数据保存授权、真实模板/文件、备份恢复、性能或业务验收通过。

## 1. 物理对象与唯一归属

| DM8 表 | 逻辑记录 | 关键约束 | 明确不保存 |
|---|---|---|---|
| `adj_work_item` | 本地合成裁决工作 | 案件来源、可信所有者、`SYNTHETIC_V0`、版本 | 中心案件状态、正式案件号、受理/办结状态。 |
| `adj_source_locator` | 合成案件、材料、法规、模板的定位 | 来源系统/对象/版本/位置唯一 | 正文、文件、凭据、永久访问链接。 |
| `adj_work_input` | 工作创建时固定的材料输入 | 工作、来源、输入顺序唯一 | 可变化的“最新材料”引用。 |
| `adj_material_inspection` / `adj_inspection_item` | 材料检查版本与主张、待核实、缺项、冲突 | 工作内版本唯一；类型/顺序受限；可回链输入来源 | 已认定事实、自动化法律结论。 |
| `adj_legal_candidate_set` / `adj_legal_candidate` | 法规候选集与确切版本/位置/疑点 | 关联确切检查版本；候选顺序唯一 | 已适用条文或法律适用状态。 |
| `adj_citation` | 选择、修订、移除的版本化引用 | 工作内版本唯一；动作和理由受限；前序版本自关联 | 正式采纳、裁决依据结论。 |
| `adj_draft` / `adj_draft_section` | 草稿版本、固定输入、章节与来源映射 | 工作内版本唯一；固定检查/模板；章节锚点/顺序唯一；`is_draft='Y'` | 正式文书、签章、文号、送达、办结。 |
| `adj_test_review` | 绑定确切草稿版本的测试复核 | 只允许 `CONFIRM/RETURN`；理由必填；强制 `SYNTHETIC_PROCESS_TEST`、非正式 | 专业审核、签发或裁决状态。 |
| `adj_idempotency_record` | 写操作的幂等绑定和精确重放引用 | 主体/操作/键唯一，回指工作与结果版本 | 原始请求正文、身份凭据或授权快照。 |

表按领域私有语义拆分。来源定位、版本和幂等虽与其他域相似，但本期不创建共享表、跨域外键或泛化 `Evidence/Review/Task/Runtime` 模型。

## 2. 必须由数据库保证的边界

- 工作、输入、检查、候选、引用、草稿和复核不产生孤立记录；所有有序集合均有显式顺序列。
- 工作内材料检查、候选集、引用和草稿版本唯一；前序版本以同表外键关联，不允许物理覆盖历史。
- `scope_code` 只能为 `SYNTHETIC_V0`；草稿只能为 `is_draft='Y'`；测试复核只能为非正式测试范围。
- 引用动作仅为 `SELECT/REVISE/REMOVE`；测试复核动作仅为 `CONFIRM/RETURN`，理由不能为空。
- 幂等键只能绑定同一个可信主体与操作；写入领域数据和幂等绑定必须在一个事务中完成。

数据库不能判断当前用户权限、材料或法规真实性、法律适用、模板合法性、专业复核资格或来源失效在外部系统的传播。这些继续由授权端口、领域代码、集成测试和业务验收负责。

## 3. 初始化、回滚与样例验证

- 初始化脚本：`db/dm8/V003__adjudication_mvp_v0.sql`；回滚脚本：`db/dm8/U003__adjudication_mvp_v0.sql`，只以依赖逆序删除 `adj_*` 表。
- 结构测试：`AdjudicationDm8SchemaTest` 已在本机隔离 DM8 初始化后写入正常、缺项/冲突记录，校验版本、外键、幂等唯一、草稿和非正式复核约束；随后回滚并二次初始化/回滚。
- 仅使用 `V0-SYN-ADJ-*` 数据。无权情形不写入业务表；失效情形保留旧草稿/复核并阻止新的确认，由后续仓储集成测试验证。

实际验证使用 Java 21、本机 `agent-platform-dm8` 容器和 `admin` 应用账户；密码只从容器环境注入测试进程，未输出或写入仓库。裁决结构专项测试零失败、零跳过；包含咨询、专利检索、商标和执法的完整 Java/真实 DM8 回归共 99 项，零失败、零错误、零跳过。本次不证明中心环境、连接中断恢复、并发仓储、备份恢复或性能。

## 4. 查询与安全边界

按 `(work_item_id, version)` 查询检查、候选、引用和草稿；按 `(draft_id, section_order)` 查询章节；按 `(work_item_id, acted_at)` 查询测试复核；幂等键使用复合主键。当前不建立全文、向量、正文、文件、归档或跨域索引。

真实案件、材料正文、法规库、模板文件、中心凭据、权限策略、人员身份、模型隐含推理、签章、文号、送达、办结和归档均不允许落入 `adj_*` 表。删除、保留、加密、脱敏、备份恢复和真实权限撤销仍等待 P0/后续任务。

结论：14 张领域私有 `adj_*` 表、约束、索引和可逆脚本已在本地 DM8 执行通过，能够承载合成 V0 的工作、版本、来源、草稿和测试复核边界。该结论完成 `ARC-10-ADJ-PHYSICAL`；仍须通过 `MVP-ADJ-V0-03-DESIGN` 才能实现仓储或 HTTP。
