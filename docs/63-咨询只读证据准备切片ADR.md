# 咨询只读证据准备切片 ADR

决定编号：ADR-CON-EVIDENCE-READ-01。日期：2026-09-24。性质：项目自造合成开发输入上的可逆技术切片，不修改原需求、真实来源许可或专业判断规则。状态与任务准入只见docs/08。

## 决定

在完整逐项技术对照尚缺具名用户确认的特征版本和获批专业方法时，先从已验证V023任务消息与V024固定结果集读取确切成员、历史输入修订及当前可展示的权项来源，形成当次无持久副作用的来源/缺口投影。业务数据服务负责当前授权与来源校验；Agent不能借此输出技术对应、评分、法律或正式结论。详细字段、路由、事务边界和C/I反例见docs/61第16节。

## 取舍

不复用Fixture的预填F1～F3作为用户确认，不以P1/P2短文本的字面命中作为对应关系。只读投影没有新表、文件、索引或备份对象，不继承文件/备份物理D的实施许可；但仍必须证明读取与取消/撤权竞争时不泄正文。旧结果集的输入修订不得被最新消息覆盖。真实专利、专业方法、特征确认/修订、逐项对照与报告均在各自门禁后实施。

## 共同输入预览的后续窄切片（2026-09-26）

既有V023/V024/V025和新包显式H确认允许仅在同一任务行锁中按调用方明确的特征序号与焦点序号核当前输入修订、确切集合成员及双来源用途。另设默认关闭的只读H入口，不建立对照表/回执或“最新确认”自动选择；返回可核查目标、特征和权项以及未选目的/未有专业方法的缺口。新包`COMPARE_INPUT`只授权其自身字段作为开发期输入，不授权关系输出；旧P1/P2结果的DISPLAY必须和新包权项用途同时满足。详情与反例见docs/61第15.6节，完整D8仍另判。
