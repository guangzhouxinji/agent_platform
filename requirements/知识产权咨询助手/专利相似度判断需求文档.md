# 专利相似度判断需求文档

对应需求：一.1.1.1.1.2.3  
文档状态：技术评审初稿，中心 API 能力、授权范围及性能参数尚需联调确认。  
交付边界：后端服务及接口说明对外交付；前端页面用于内部开发、联调和验收，不属于对外交付内容。


## 国产化与达梦 DM8 适配要求

- 本模块面向国产化环境交付，业务关系型数据库固定使用达梦 DM8；开发联调及数据库兼容验收均须覆盖真实 DM8，不能以 MySQL、H2 等环境通过替代。
- 本模块需要持久化的业务内容包括：分析任务、技术特征、文献引用、逐项对照、报告版本和专业复核记录。数据库采用 DM8；文件二进制可使用项目已批准的文件存储，DM8 保存受控引用及元数据，不要求把所有图片和附件存入数据库。
- 驱动、连接池、ORM/持久层、分页、建表及升级脚本按实际 DM8 小版本和实例参数适配；不得直接依赖其他数据库专有语法、JSON 类型或函数。长文本、结构化内容、编号、时间及分数应选用经目标实例验证的数据类型和访问方式。
- 本模块 DM8 专项验收覆盖：长报告及嵌套特征无截断、证据定位、评分精度、报告版本和复核事务一致性。验证事务失败回滚、连接故障恢复和权限控制；接口故障不伪装成空结果。需要恢复的任务应识别中断状态，按幂等规则恢复或显式失败，不盲目重放。
- 全文、向量和图像检索能力不得因采用 DM8 就视为已经具备；优先调用中心 API，自建时按总目录的国产化与检索约束选型并验证。
- 交付本模块适用的 DM8 初始化/升级脚本、数据库配置说明和真实 DM8 验证记录；确无本地业务表时注明原因，仍须验证与共用 DM8 服务的集成。其他国产操作系统、CPU、JDK、模型及中间件的具体型号以中心环境清单为准，不预设已完成适配。

详细共用要求见[需求总目录](知识产权咨询助手需求文档总目录.md)“3.7 国产化部署与达梦 DM8 数据库”。

## 1. 功能概述与边界

对目标技术方案或目标专利与选定专利文献进行逐项技术特征比对，输出证据、差异和辅助分析意见。与检索模块分开：检索负责找到候选，本模块负责解释选定对象的具体关系。

支持两项基础任务：技术相似辅助比对、权利要求与产品/技术方案对照。新颖性辅助分析须具备相关日期及合适的对比文献；资料不足时仅输出已完成的技术对照及缺口，不生成确定法律结论。

发明、实用新型与外观设计使用不同分析流程。外观设计比对需具备可比视图、图像分析能力及独立评价规则，不能复用文本技术特征分数；该能力作为单独子流程联调验收。

## 2. 字段与输入校验

| 字段 | 说明 |
|---|---|
| 分析目的、技术对象类型 | 技术相似、新颖性辅助、权利要求对照或外观设计辅助比对 |
| 目标技术方案/专利标识 | 两者至少一种；侵权风险相关对照须提供实际产品/技术方案 |
| 目标文献版本、选定权利要求 | 使用具体版本，支持独立及从属权利要求引用关系 |
| 对比专利及文献版本 | 一次任务可含多个对象，逐对出结果 |
| 相关日期、地域 | 涉及法律问题时确认，不默认当前日期及法域 |
| 技术特征列表 | 特征 ID、原文、依赖关系、来源定位、用户修订 |
| 对应内容、关系标签 | 对应、部分对应、未找到、无法判断 |
| 技术对照评分、规则版本 | 非法律概率；不与检索相关度共用 |
| 辅助意见、依据、缺失信息 | 事实、技术对照、法律适用问题分别表述 |
| 分析时间、任务/报告 ID、审核状态 | 服务端生成并追踪 |

## 3. 分析流程

1. 接收检索结果或用户直接指定对象，重新校验记录权限与文献版本。
2. 获取全文并显示可用性；必要正文缺失或 OCR 质量不足时提示补充，不以摘要冒充权利要求。
3. 提取技术特征，展开所选从属权利要求引用的前项特征，保留层级与原文。
4. 用户确认或修订特征后发起分析，保存不可变输入快照。
5. 对每个候选逐项生成原文对应、差异及无法判断的原因，输出辅助意见。
6. 内部人员可审核报告并添加意见；算法原始结果保留，人工意见单独留痕。

新颖性辅助分析须逐篇对照，不把多篇文献拼接覆盖的特征直接当作单篇已公开。未找到对应内容只表示在已分析材料中未找到。权利要求对照须逐要素呈现，技术文本相似不能直接等同于落入保护范围。

外观设计子流程要求目标和候选具有相应视图，列出缺失视图，按实际可见内容给出整体及局部差异；视图不足时不能生成完整比对结论。

## 4. 输出与评分

报告包括输入及版本、资料完整性、特征对照表、相同点与差异、证据引用、辅助意见、待核实问题、实际数据范围、模型/规则版本和审核记录。

数值评分仅用于技术对照统计。技术设计应明确分母、特征权重、部分对应及缺失项处理，并经业务确认。不能把“未分析”计为不相似，也不能让大模型直接猜百分数。评分未完成标定时输出维度标签及对照表，数值评分作为未完成能力记录。

正式采用的意见须经中心指定人员复核；普通辅助报告标为“未复核”。审核状态不把辅助报告变成自动裁决结果。

## 5. 内部验证页面

目标/候选选择区、分析目的及日期、原文版本选择、特征确认编辑区、开始分析、任务进度、并列对照表、证据定位、报告查看和审核区。

每个候选有独立完成状态；一个失败不掩盖其他成功结果。支持修改输入后新建任务、重试失败对象。无权限或源文献撤回时阻止重新打开内容；历史报告引用按当前权限控制。

## 6. 服务契约与异常

| 服务 | 输入 | 输出 |
|---|---|---|
| 分析准备 | 目标、候选、目的 | 文献状态、待补信息、技术特征建议 |
| 创建分析 | 确认特征、版本、参数、幂等键 | 任务 ID |
| 任务/报告查询 | 任务或报告 ID | 状态、逐对结果、证据、规则版本 |
| 人工复核 | 报告版本、意见、复核动作 | 审核记录或版本冲突 |
| 取消 | 任务 ID | 取消结果 |

异步任务遵循总目录状态规则。错误包括权利要求缺失、依赖关系解析失败、视图不足、数据源不可用、权限不足和模型失败。重要材料不足时允许返回不完整报告但必须列明未执行项目，不能伪装成分析成功完成。

## 7. 验收要求

| 编号 | 场景与预期 |
|---|---|
| PC-01 | 直接输入及检索跳转都正确绑定对象和文献版本 |
| PC-02 | 从属权利要求引用的特征不遗漏，人工修订有记录 |
| PC-03 | 逐项对应原文可核对，未找到与无法判断分开 |
| PC-04 | 不以摘要替代缺失权利要求，不把多篇拼接当作单篇公开 |
| PC-05 | 数值分数符合固定规则，检索分数不替代对照分数 |
| PC-06 | 外观子流程检查视图完整性；未具备能力时明确阻断 |
| PC-07 | 部分失败、重试、复核及版本冲突按规则处理 |
| PC-08 | 专家样本评估特征完整性、证据准确性及意见合理性，分别确定阈值 |
| PC-09 | 独立接口可查询报告，访问权限贯穿输入、原文及报告 |

## 8. 依赖与交付

依赖专利库、专利检索（可选入口）、法规/审查资料、模型、任务及复核能力。交付分析服务、报告数据结构、评分及证据规则、接口说明和验收记录；内部验证页面不交付。

确认权利要求全文质量、外观视图及模型能力、法律依据资源版本、专家复核安排、单任务对象上限与性能指标。资料不足不能通过提示词补足事实。
