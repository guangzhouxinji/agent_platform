# 知识产权咨询对话流管理需求文档

对应需求：一.1.1.1.1.3.4  
文档状态：技术评审初稿，中心 API 能力、授权范围及性能参数尚需联调确认。  
交付边界：后端服务及接口说明对外交付；前端页面用于内部开发、联调和验收，不属于对外交付内容。


## 国产化与达梦 DM8 适配要求

- 本模块面向国产化环境交付，业务关系型数据库固定使用达梦 DM8；开发联调及数据库兼容验收均须覆盖真实 DM8，不能以 MySQL、H2 等环境通过替代。
- 本模块需要持久化的业务内容包括：会话、消息、上下文快照、事件序号、任务引用、流程配置版本和结束记录。数据库采用 DM8；文件二进制可使用项目已批准的文件存储，DM8 保存受控引用及元数据，不要求把所有图片和附件存入数据库。
- 驱动、连接池、ORM/持久层、分页、建表及升级脚本按实际 DM8 小版本和实例参数适配；不得直接依赖其他数据库专有语法、JSON 类型或函数。长文本、结构化内容、编号、时间及分数应选用经目标实例验证的数据类型和访问方式。
- 本模块 DM8 专项验收覆盖：长消息与上下文不截断、同会话并发控制、幂等、事件顺序及断线/服务重启后的状态恢复。验证事务失败回滚、连接故障恢复和权限控制；接口故障不伪装成空结果。需要恢复的任务应识别中断状态，按幂等规则恢复或显式失败，不盲目重放。
- 全文、向量和图像检索能力不得因采用 DM8 就视为已经具备；优先调用中心 API，自建时按总目录的国产化与检索约束选型并验证。
- 交付本模块适用的 DM8 初始化/升级脚本、数据库配置说明和真实 DM8 验证记录；确无本地业务表时注明原因，仍须验证与共用 DM8 服务的集成。其他国产操作系统、CPU、JDK、模型及中间件的具体型号以中心环境清单为准，不预设已完成适配。

详细共用要求见[需求总目录](知识产权咨询助手需求文档总目录.md)“3.7 国产化部署与达梦 DM8 数据库”。

## 1. 功能概述

提供知识产权多轮咨询服务，管理会话、消息、当前分析对象、补问状态、工具执行、回复引用和结束流程。内部页面用于完整对话验证，对外交付会话与消息接口，不交付聊天页面。

首版使用可配置的固定流程和场景分支，不要求通用拖拽流程设计器。模型不直接任意访问数据源，只能调用当前配置允许的工具。

## 2. 数据字段

| 字段 | 说明 |
|---|---|
| 对话编号、用户标识、显示名称 | 不以可重名的用户名做归属判断 |
| 智能体及配置版本、对话流版本 | 会话创建时固定，权限与撤销策略实时检查 |
| 会话状态 | 进行中、已结束、已过期 |
| 当前阶段 | 意图识别、待补充、检索中、分析中、待复核/转接、可继续 |
| 消息 ID、角色、内容、顺序号 | 用户、助手、工具及系统事件分开 |
| 咨询/回复内容、创建时间 | 保留原始消息与状态 |
| 对话轮次 | 一条接受成功的用户消息计一轮，工具消息不另计 |
| 上下文 | 已确认槽位、当前对象/版本、历史引用、摘要及来源消息 |
| 请求/工具任务 ID、执行状态 | 支持幂等、重连与追踪 |
| 引用信息 | 资源 ID、版本、段落/页码、来源时间 |
| 开始/结束时间、结束原因 | 用户结束、到期或管理处理等 |
| 流程配置 | 节点、条件、工具映射、超时/回退及版本 |

## 3. 标准对话流程

1. 校验身份、智能体状态和权限，创建会话并绑定发布版本。
2. 接收用户消息并识别意图，检查必要信息。
3. 缺失或指代不清时追问；已确认信息不无故重复索要。
4. 信息齐全后调用相应查询、检索或比对服务，记录实际输入与任务 ID。
5. 依据真实结果生成答复，区分检索发现、辅助意见及待核实事项，并附可解析引用。
6. 后续提问沿用当前对象；更换对象或更正关键事实时更新相关槽位，使不再适用的旧分析失效。
7. 用户结束或会话到期后关闭输入，历史仍按权限查看。继续咨询应新建会话，可显式选择允许继承的资料。

“第二个商标”等指代表达必须绑定上一轮实际展示的结果集及顺序；有多个可能对象时追问，不能凭当前列表变化重新解释。

法规/办事答复需要已配置的有效资料及适用版本。没有依据时说明资料缺口，不生成虚构法条、案例或办理要求。

## 4. 状态、并发与上下文规则

- 消息处理状态为已接收、处理中、完成、失败、取消。首版同一会话只允许一条用户消息处理中，重复提交幂等返回，其他新消息返回忙碌提示。
- 幂等键与用户、会话、请求内容绑定；相同键不同内容返回冲突，避免重复执行工具。
- 网络断开不默认取消服务端任务；重连按消息 ID 获取最新状态及已完成内容，不能重复计轮次。
- 流式输出须提供事件顺序或可恢复标识；中断未完成内容标为未完成，最终回复只落一条完成记录。
- 用户取消后停止后续步骤；迟到工具结果可记录审计，但不作为本轮新完成答复发布。
- 上下文达到容量限制时生成摘要，保留已确认事实、对象版本和证据来源；无法可靠保留的关键材料重新获取或请用户确认。
- 用户数据、文献内容中的指令作为数据处理，不能覆盖系统权限或诱导调用未授权工具。
- 同一用户不同会话默认隔离；不同用户、组织的数据隔离在检索和消息读取阶段执行。
- 会话有效期、消息及附件保留期限配置化，按中心批准策略执行；过期不等于自动删除，删除策略另行配置。

## 5. 异常、复核与转接

工具无结果、工具故障、资料不足分别答复。部分工具成功时可返回有依据的部分内容，但标明未完成部分；不能将源失败解释为“没有相关权利/案例”。

需要正式采用的判断进入复核提示或已配置的复核工作流。人工转接能力未接通时，只展示中心配置的办理指引，不显示“已转人工”。真实转接成功须返回受理编号及状态；不默认发送外部通知。

智能体暂停或依赖紧急撤销时阻止继续调用，返回可识别状态。失败重试新建消息处理尝试并关联原轮次，不重复记录用户提问。

## 6. 流程配置与内部验证页面

流程草稿支持场景入口、补问、工具调用、回复、异常回退及结束节点配置。发布校验入口唯一、节点可达、必要异常出口存在、循环有次数上限、引用版本有效。已发布流程不可原地编辑，由智能体显式绑定新版。

内部页面包括会话列表、聊天验证区、当前对象/槽位区、工具执行记录、来源引用、配置版本、结束/取消/重试操作，以及流程配置与测试页。

会话列表支持编号、授权范围内用户、状态、时间筛选。聊天区明确正在处理、未完成、失败及真实/模拟状态；调试区仅管理权限可看，不展示密钥或模型隐含推理。

## 7. 服务契约

| 服务 | 输入 | 输出 |
|---|---|---|
| 创建会话 | 智能体 ID、身份上下文 | 会话 ID、绑定版本 |
| 发送消息 | 会话 ID、消息内容、受控附件引用、幂等键 | 消息 ID、处理状态 |
| 接收事件/查询消息 | 会话/消息 ID、事件位置 | 有序事件或最终回复、引用 |
| 查询历史 | 会话 ID、分页 | 授权消息及当前状态 |
| 取消/结束 | 会话/消息 ID、动作 | 新状态 |
| 流程保存/校验/发布 | 流程版本、配置、动作 | 校验结果或新版本 |

后端对每个会话和附件引用校验归属，不能仅凭 ID 放行。模型错误、工具失败、忙碌、过期、暂停、参数错误及越权分别返回错误和追踪号。

## 8. 验收要求

| 编号 | 场景与预期 |
|---|---|
| DF-01 | 缺信息补问，补齐后调用正确工具，不重复索要已确认项 |
| DF-02 | 连续追问、对象切换和更正事实正确更新上下文 |
| DF-03 | “第二个”等指代绑定实际结果集，歧义触发追问 |
| DF-04 | 回复引用可定位且支持结论，源故障不冒充无结果 |
| DF-05 | 重复提交、并发消息、取消和重连不重复执行或计轮 |
| DF-06 | 上下文压缩保留关键对象与来源，不跨会话串数据 |
| DF-07 | 暂停、紧急撤销、会话结束与到期均按规则限制调用 |
| DF-08 | 转接未接通不声称已受理，接通后有真实受理状态 |
| DF-09 | 流程死循环、缺出口及无效引用不能发布 |
| DF-10 | 独立客户端调用可完成多轮、事件恢复和历史查询 |

## 9. 依赖与交付

依赖智能体、提示词、意图、工具服务、任务、权限及可选人工受理系统。交付会话/消息/流程服务、事件协议、状态及幂等说明、验收记录；聊天和流程配置页面内部留用。

确认首批场景、模型上下文预算、各流程超时与循环上限、会话/数据保留策略、人工受理接口、并发及首响应/完成时间目标。
