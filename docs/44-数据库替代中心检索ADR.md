# ADR-0044：开发期用 DM8 替代中心专利检索

- 状态：已接受
- 日期：2026-09-18
- 决策来源：用户明确要求“中心检索用数据库代替”

## 决策

在真实中心检索 API 和获授权索引未确定期间，咨询助手使用 DM8 `KB_*` 表中的 `PUBLIC_LOCAL` 专利记录完成只读检索。运行时以 `consultation.search.provider=database` 显式选择，并要求 `knowledge-base.provider=dm8`。

检索结果必须返回来源 ID、来源版本、命中依据、实际数据范围和限制说明。无结果和数据库故障必须区分，不得静默回退到合成或 HTTP 模拟中心。

## 边界

该决策是可替换的开发期技术决策，不是原始需求中已确认的中心接口，也不证明数据生产授权、检索完备性、Recall@K、专业结论或业务验收。未来接入真实中心时，仅替换出站适配器，不改变咨询领域模型。
