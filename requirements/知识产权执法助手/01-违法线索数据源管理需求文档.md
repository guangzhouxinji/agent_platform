# 违法线索数据源管理需求文档

版本：V0.1 需求评审稿  
功能编号：ZF-01  
原需求条目：一.1.1.1.1.1.1  
所属智能体：知识产权执法助手

## 1. 功能概述与交付范围

统一配置中心提供的违法线索 API，管理连接、同步和运行状态。首版不自行抓取电商或社交平台。

对外交付本功能的服务接口及接口说明；内部开发验证页面用于联调、演示和验收，页面不属于对外交付内容。所有业务规则、权限与结果保存由后端服务执行。

本篇与[需求总览与通用约定](00-需求总览与通用约定.md)共同构成该功能需求；身份、分页、时间、任务、错误、版本和审核按总览执行。

已确认技术约束：按中心国产化环境适配，业务数据库使用达梦 DM8，内部验证环境同样使用 DM8；具体兼容要求及验证内容遵循总览第 1.1 节。

## 2. 数据来源与依赖

中心 API 文档、凭证引用及样例；中心确认数据授权、覆盖范围和更新条件。

接入时校验资源编号、关联关系、版本和访问权限；源数据缺失与调用失败分开记录。来源字段不能由模型生成或替换。具体接入能力以实际 API 联调结果为准。

## 3. 信息字段

| 字段名称 | 必填/产生方式 | 说明 |
|---|---|---|
| 数据源编号 | 生成 | 唯一标识 |
| 数据源名称 | 是 | 用于列表展示 |
| 数据类型 | 是 | 投诉举报、电商、社交媒体、监管监测等 |
| 接入方式 | 是 | 首版 API |
| 接口地址 | 是 | 受控服务地址 |
| 认证配置引用 | 是 | 仅存凭证引用，查询不返回密钥 |
| 字段映射 | 是 | 源字段与标准字段的对应 |
| 数据同步周期 | 条件 | 定时模式必填，注明分钟或小时 |
| 状态 | 生成 | 启用、停用与连接健康分别记录 |
| 负责人 | 是 | 中心或运维联系人 |
| 接入时间 | 生成 | 首次保存时间 |
| 同步游标 | 生成 | 最近成功位置 |
| 最近成功时间 | 生成 | 允许为空 |

通用附加字段：创建人、创建时间、更新人、更新时间、所属机构及 request_id；详情返回相关来源与历史版本。已有来源字段和业务编号不可随意改写。

## 4. 功能与处理规则

1. 新增配置并测试连接，校验认证、分页方式、时间字段、唯一键及返回结构。
2. 支持编辑、启停、手动同步与定时同步；同一数据源不并发执行重复同步。
3. 按源记录 ID 与源版本幂等接入，失败记录独立记录原因，不静默跳过后推进游标。
4. 中心 API 无增量能力时按约定窗口重拉并去重；同步频率不得突破限流。
5. 源记录更新保留旧快照及更新时间；删除或撤回按接口能力标记，不能推断为不存在。

## 5. 服务接口需求

配置保存/查询/启停；连接测试；创建同步任务；同步任务及失败明细查询。输入数据源编号及配置，输出配置版本、任务编号、计数与错误原因。

列表接口按内部页面规定支持筛选和分页；详情返回完整字段而非仅摘要。写入返回资源编号和版本。配置变更、人工修订及审核需记录操作人和前后状态；长时间操作按通用异步任务约定返回进度和结果。

关联资源不存在或无权限时拒绝操作；源接口不可用、解析失败或规则不适用时返回明确原因。部分结果必须同时附未处理项，不得伪装为完整成功。具体 URL 和英文参数名由技术统一设计，并随 OpenAPI 契约交付。

## 6. 内部验证页面

数据源列表按名称、类型、启用状态和健康状态筛选；配置表单、连接测试结果、同步任务详情及失败明细页面；凭证始终脱敏。

页面展示服务返回的实际数据，操作按钮调用对应后端接口；包含加载、空数据、失败与无权限状态。支持查看 request_id 以定位联调问题。列表默认按更新时间倒序；历史结果可查看其使用的数据和配置版本。

## 7. 验收要求

1. 同一批数据同步两次不重复建记录。
2. 模拟限流或超时后可重试，成功游标不越过未处理数据。
3. 停用后不再产生定时任务，运行中任务状态明确。
4. 页面能区分认证失败、接口不可用、成功但无数据。
5. 页面操作和直接接口调用得到一致结果；直接调用不能绕过权限、字段或状态校验。
6. 错误场景返回明确原因，关联数据和历史结果未被错误覆盖。

以上场景由技术准备固定样例，记录请求、期望、实际结果和证据；涉及专业判断的期望结果由中心业务人员确认。模型效果与性能指标按总览另行试测确认，不使用模型自评分作为验收准确率。

## 8. 联调前需确认的条件

中心具体接口协议、分页及增量方式、限流、附件访问方式和数据撤回机制需在联调前落实。

这些是本功能的外部依赖，未确认时可用明确标记的模拟数据开发接口和页面，但不视为真实业务联调通过。
