## 阅读顺序

后续 Codex 每次只需按当前任务读取：总开发计划 -> 对应原需求与关键契约 -> 当前 MVP -> 领域边界 -> 必要的待确认项。不得为了通过治理检查而先扩写 Runtime、API、数据模型或派生报告。
