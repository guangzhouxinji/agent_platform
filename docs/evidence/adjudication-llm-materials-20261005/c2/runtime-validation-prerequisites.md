# 03B真实运行验证最小准备清单

2026-10-05；仅验证准备，不是另一个任务/状态台账。状态唯一总计划。

1. 一个获准且现时可读的案件：案件/材料确切版本、原文SHA、原文定位、提供方、去敏及用途证据均在正式来源链。历史撤源案件不得复活，不能只加新材料绕过全历史来源守卫。
2. 与上述当前inputVersion一致且仍在原截止前的COMMITTED模型候选run；候选应能由03A正式读取门取得。不得以测试端口输出/组件输入/另案manifest冒本案合法候选；不换case/approval key重置预算。若现有许可不覆盖新的输入，必须走原受控流程，不自行改旧政策或回执。
3. 当前可信JWT及确切ADJ案件READ/WRITE/MODEL_EXECUTE权限、当前来源READ/MODEL/SAVE/ANALYZE许可；不借CON授权，不新增HUMAN_REVIEW或代专业签名。本轮测试身份不替代真实人员操作。
4. 受控、可用的独立primary DM8和authority环境；V093正向、空库逆向、非空拒逆及SQL/锁行为实测。不要启动事故库/旧服务/其他域卷。
5. 独立的新人工派生key根与父模型key根，最早期限继承；备份/恢复不携裸key，不让旧备份回灌逃过当前授权/来源/截止/一致性校验。缺钥、损坏、到期拒读及保留既有旧案历史分别验证。
6. 指定实际操作人逐条核查原文并采用/修改/拒绝，记录实际API、DM8落库、应用重启、物理恢复与事务失败对账；材料整理不等于事实采信或专业业务验收。

本轮不连接实际产品库、不新增付费调用，不反复探Docker，不创建定时续行。旧案最后已核撤源/stale只保持拒绝；本轮没有冒当前库新鲜可用性。环境和合法当前候选只限制真实I，并未阻止已准入的C2产品代码及机械验证。03B整体、03C页面、03D价值验证与专业A不凭本清单升级。
