# ADR-0046 咨询模型持久化后台管理

日期：2026-09-20

## 决定

咨询智能体的开发期模型配置由 DM8 持久化管理。浏览器仅在创建或替换密钥时发送模型 API Key；服务端使用 `MODEL_CONFIG_MASTER_KEY` 提供的 32 字节 Base64 主密钥，以 AES-GCM 加密后保存。读取 API、日志、审计和前端均不得返回密钥、主密钥、认证头或完整上游响应。

初版只接受 OpenAI Chat Completions 兼容端点，且仅能用于 `PUBLIC_LOCAL`、公开、合成或获准脱敏输入。模型配置操作由 `MODEL_CONFIG_ADMIN_REQUESTER` 指定的开发期可信主体执行；默认值为 `v0-authorized-user`。这不构成生产 SSO 或正式供应商批准。

## 后果

- 后端可在不重新构建前端的情况下维护多个模型、启停状态与调用优先级。
- 未配置或错误配置主密钥时，管理 API 保持脱敏只读，拒绝保存密钥、启用和连接测试。
- 连接测试只发送固定无业务数据的请求；模型输出仍只可生成辅助草稿，不能改变授权、审核或正式状态。
- 生产角色映射、密钥轮换、供应商批准、数据出域、审计保留期和真实数据模型使用保持待确认。
