# 裁决 MVP V0 最小领域模型

版本：V0.1  
日期：2026-09-16  
关联任务：\`ARC-05-ADJ\`  
输入基线：\`docs/29-裁决MVP-V0产品样例基线.md\`  
边界：本模型只覆盖开发期合成案件材料到报告草稿和测试复核记录。它不拥有中心案件、法规、模板、身份、权限、签发回执或正式裁决状态。

## 1. 最小对象

| 对象 | 责任 | 必须保留 | 明确不拥有 |
|---|---|---|---|
| 裁决工作记录 | 聚合一次本地合成 V0 工作及冻结输入清单 | 本地 ID、数据模式、案件/材料版本、当前授权结果、追踪号 | 中心案件编号、受理/办结/归档状态 |
| 案件材料版本 | 表达当事人主张、待核实事实和合成材料定位 | 来源、稳定标识、版本、定位、可用性、事实状态 | 自动确认事实、证据采信 |
| 条文匹配与引用版本 | 保留候选、人工选择、具体条文版本、理由和草稿锚点 | 候选/确认状态、来源版本、适用疑点、调整理由 | 法律适用结论、法定规则 |
| 报告草稿版本 | 保存结构化草稿、输入清单、来源映射、完整性和修订差异 | 草稿版本、章节锚点、缺项、辅助内容标识、依赖摘要 | 正式文号、签章、正式裁决文件 |
| 测试复核记录 | 指向确切草稿版本，留存测试身份动作和理由 | 被审版本、动作、理由、时间、依赖版本清单 | 专业确认、签发、案件状态推进 |

对象之间只通过版本化引用关联：工作记录固定材料、匹配/引用和草稿版本；草稿固定采用的引用及材料版本；复核只作用于确切草稿版本。重建或修订生成新版本，不改写历史版本或历史复核记录。

## 2. 行为与不变量

1. 创建合成工作记录前，所有输入必须有 \`SYNTHETIC\` 标记、稳定标识、版本和当前测试授权结果。
2. 材料缺失、冲突、无权限、来源失效和真实无结果分别记录；任何一类不得静默转化为“完整”或“不适用”。
3. 条文匹配只产生候选；人工选择具体版本和理由后才形成可供草稿使用的引用版本，仍不等于法律适用结论。
4. 报告只能生成草稿。确定性字段只能来自冻结输入；辅助文字必须关联依据并明确其辅助性质，缺项不得由模型补造。
5. 完整性、复核、签发和异步执行状态分别表达。V0 仅允许草稿、不完整草稿、待复核和测试复核记录；不建模已签发、已裁决、已送达、已办结或已归档转换。
6. 复核前必须检查草稿版本、依赖版本和当前测试授权；修改草稿或任一输入会生成新草稿版本并使旧复核记录不再适用于新版本。
7. 无权或失效来源不能进入新的匹配、引用、草稿或复核输入；历史记录只保留不泄露正文的最小追踪信息。
8. 测试身份的复核动作只改变本地测试复核记录，不授予权限、不确认案件事实、不改变正式状态。

## 3. 责任边界

| 决定 | 所有者 | V0 行为 |
|---|---|---|
| 候选关键词、摘要和草稿解释 | AI/确定性测试替身 | 只能产生候选或辅助草稿，保留来源和版本。 |
| 完整性、版本一致、授权拒绝、状态/并发校验 | 领域规则 | 拒绝不满足不变量的操作，返回明确缺项或冲突。 |
| 选择条文、修订草稿、测试复核 | 测试人工身份 | 记录动作和理由，不构成专业/正式结论。 |
| 正式案件、权限、法规、模板、签发和回执 | 中心/授权责任方 | V0 不接入；缺失时保留边界，不作推定。 |

## 4. 排除项

- 不纳入 ADJ-07/08/09 的专利解析、有效性或侵权证据分析。
- 不定义 HTTP、DM8 表、文件格式、模型、提示词、正式模板、真实角色或中心接口。
- 不合并为跨域 \`Evidence\`、\`Review\`、\`Task\`、\`Runtime\` 或统一案件模型。
- 不产生受理、裁决、签发、送达、办结、归档、通知或中心写回。

## 5. 样例复核

正常样例需要五个对象保存完整输入、候选/引用、草稿和测试复核；资料不足样例通过材料版本、引用和草稿的缺项/冲突状态保留不确定性；无权限/来源失效样例通过当前授权结果及不可用来源阻止新版本采用。三个样例均停在本地草稿/测试复核记录，未出现正式状态。

结论：该模型满足 \`ARC-05-ADJ\` 的合成 V0 最小对象、关系和不变量设计输出。后续可设计用例与端口，不代表 ADJ 需求的完整 D/V/A 或真实业务验证。
