# 执法 MVP V0 实现任务设计

版本：V0.1  
日期：2026-09-15  
关联任务：`MVP-ENF-V0-01`  
目标实现任务：`MVP-ENF-V0-02`  
设计输入：`docs/20` 至 `docs/25`、`ENF-04/05/07/11` 需求契约。  
设计性质：只为合成、内存、纯 Java 的执法 V0 应用闭环申请窄范围 D 门；不批准 HTTP、DM8、真实中心 API、真实文件、真实模型、专业规则或正式流程实现。

## 1. 本次实现范围

本次只实现并自动测试以下闭环：

```text
合成线索固定版本
  → 当前授权检查
  → 线索候选解析（多主体/来源/缺失/冲突）
  → 测试身份核实记录
  → 合成证据引用
  → 候选关系集（支持/反对/冲突/缺失）
  → 受限辅助分析（事实/陈述/推断分离）
  → 测试身份确认/退回记录
  → 来源失效后新结果拒绝使用、旧结果保留需复核
```

所有输入和输出使用 `V0-SYN-*`。应用启动和测试不依赖网络、真实文件、模型服务或数据库。测试身份只验证可信上下文、版本和审计机制。

## 6. 退出和完成判定

`MVP-ENF-V0-02` 只有同时满足以下条件才能标记“已完成”：

1. 上述纳入范围的代码存在，包依赖符合端口/适配器方向。
2. T01 至 T12 自动测试通过，且咨询现有 22 项非环境 Java 测试继续通过。
3. 没有 DM8、中心 SDK、模型 SDK、HTTP、文件系统或 Spring Web 依赖进入执法领域/应用核心。
4. 不存在 `isIllegal`、`officialDecision`、`penalty`、`officialCaseStatus` 等正式决定字段或写入口。
5. `node scripts/verify-all.mjs` 通过，未覆盖 MUST、MUST_NOT 违规、无来源行为和失效证据链接均为 0（仅针对本任务纳入条款）。
6. 结果明确标记为合成/内存代码测试，不升级 ENF-04/05/07/11 整体实现、验证或验收状态。
