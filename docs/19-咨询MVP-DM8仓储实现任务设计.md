# 咨询 MVP V0 DM8 仓储实现任务设计

任务：MVP-CON-V0-02  
版本：V0.2  
日期：2026-09-15  
前置：[V0 实现任务](17-咨询MVP-V0实现任务设计.md)、[DM8 物理持久化设计](18-咨询MVP-DM8物理持久化设计.md)。

## 1. 实现范围

将当前合成咨询闭环的本地工作记录持久化到已验证的 DM8 表，并保留合成检索、默认拒绝授权和受约束回答生成。领域服务只依赖 `ConsultationStore` 端口；DM8 JDBC 适配器负责 SQL、事务和记录映射。

本任务不接入中心 API、真实专利、真实身份权限、外部模型、文件、人工复核或前端；不把 SQL 约束提升为授权或专业业务规则。

## 2. 最小端口与事务

| 操作 | 输入/输出 | 事务边界 | 保证 |
|---|---|---|---|
| `findByIdempotency` | 请求者、幂等键 → 首次写入的确切回答 | 只读 | 同键同内容返回原 `answer_id`；不同内容由服务判冲突，不返回会话最新回答 |
| `save` | 新会话及首轮输入、未决项/检索、候选、回答、来源、幂等记录 | 单一事务 | 成功时完整保存；失败时不留下半成品回答或幂等记录 |
| `saveSupplement` | 既有会话、补充原文、新回答版本及本次幂等记录 | 单一事务 | 追加输入和回答版本，不覆盖原问题或旧回答；迟发幂等冲突时整体回滚 |
| `findByConsultationId` / `findByAnswerId` | 会话或确切回答引用 → 最小结果 | 只读 | 仓储恢复历史事实；当前授权和来源复查仍由服务负责 |
| `saveRefresh` | 已有会话的新检索/候选/回答版本 | 单一事务 | 追加回答版本，不覆盖历史；仅作为内部来源重检能力，不公开为 V0 HTTP 端点 |

首次提交和补充输入均按“来源定位、会话/输入/未决项、检索/候选、回答/关联、幂等记录”持久化；发生异常整个事务回滚。补充请求的幂等记录绑定本次新增回答，不绑定会话最新视图。当前 V0 没有并发会话更新、异步任务或完整会话状态机，不为其增加锁字段或通用运行记录。

## 3. 实现映射与测试

| V0 场景 | 仓储写入 | 必须验证 |
|---|---|---|
| 正常 | 输入、允许检索、候选/来源、回答、回答关联、幂等 | 重新读取能恢复候选来源与限制；相同幂等键不重复写入 |
| 补问/冲突 | 输入、未决项、补问回答 | 不写检索请求、候选或来源正文 |
| 补充后完成 | 保留原输入/补问回答，追加补充输入、新候选和回答版本、本次幂等记录 | 旧回答仍可按 `answer_id` 读取；相同补充重放返回同一回答；冲突不留下半成品 |
| 无权限 | 输入、拒绝检索、拒绝回答、幂等 | 不写候选、回答候选关联或受限正文 |
| 来源失效 | 新的降级回答版本及有效关联 | 失效候选不能成为新回答依据；历史定位仅作追溯 |

验证采用本地 Docker DM8、合成数据和环境变量连接。测试通过仅证明本地适配器行为，不证明中心 API、真实数据授权、专业正确性或生产可用性。

## 4. D 门结论

本任务具备稳定的 V0 样例、领域/用例/API/逻辑及物理持久化证据，且 P0-03/04/05 的 V0 决策允许合成数据、本地 DM8 和默认拒绝授权。因此 **D 门仅对 `MVP-CON-V0-02` 的上述合成 DM8 仓储范围通过**。

该结论不扩展 `CON-02/04/11/12` 的完成状态，也不允许真实中心数据或权限接入。
