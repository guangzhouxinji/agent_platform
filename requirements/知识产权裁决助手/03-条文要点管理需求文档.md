# 条文要点管理需求文档

模块标识：ADJ-03；对应原需求：一.1.1.1.1.1.3。  
版本：V0.1 技术评审稿；日期：2026-09-12。  
建设条件：中心主要通过 API 提供数据；国产化部署，业务关系型数据库固定为达梦 DM8。  
交付边界：对外交付服务及接口、部署和验收资料；自研前端仅供内部验证，不交付对外页面。

本文与[需求总览与通用约定](00-需求总览与通用约定.md)共同构成开发要求。字段中文名为业务契约，接口路径和英文名由详细设计统一。涉及事实的字段缺失时返回缺口，不以模型推测满足必填。当前未完成中心 API、模型或 DM8 实测。

## 1. 功能概述

从已解析条文生成的结构化数据中接收并管理核心要点，关联裁决场景与案例，为匹配和报告提供索引提示。要点不是法规原文，正式法律引用仍须回到具体条文及版本。

承接根目录[条文要点管理需求文档](../../../条文要点管理需求文档.md)的外部一次性生成导入、关联校验、完整列表及编辑规则。外部生成通道与条文解析服务衔接，不默认每次条文编辑自动重新生成。

## 2. 字段与内容约束

| 字段 | 说明 |
|---|---|
| 要点编号、要点版本 | 编号唯一且不因编辑改变 |
| 法规编号/名称/版本、所属条文 ID/条号 | 指向具体原文 |
| 来源解析 ID、解析版本 | 记录提取基础 |
| 要点内容、要点类别 | 权利范围、侵权情形、构成要件、责任、处罚标准等中心字典 |
| 关联场景、程序类型 | 行政裁决、行政处罚等分别标识 |
| 关联案例编号/版本 | 多值，验证实际引用 |
| 提取主体、提取时间、导入时间 | 区分外部生成与导入 |
| 更新人、更新时间、变更原因 | 操作留痕 |
| 可用状态 | 待核实、可用、停用、来源已变更 |

处罚标准仅在来源存在且适用程序匹配时保存和展示，不能因要点中含处罚内容就把它自动用于行政裁决报告。要点缺少原文支持时标为待核实。

## 3. 导入与维护规则

1. 外部程序基于条文解析结果生成要点，经批量文件或接口接收。
2. 校验编号、来源解析版本、条文存在性、类别、案例及日期；未能关联的记录逐项反馈。
3. 重复记录可跳过、更新草稿或创建新版本；已被引用的版本不得破坏性覆盖。
4. 已审核解析且来源一致的要点可经校核标记可用；依据未审核或已变更的解析不能直接成为可用知识。
5. 维护内容、类别、场景和案例时保留变更记录；改变来源条文必须重新校验并生成新版本。
6. 来源解析或法规变更后标记待核实，旧要点保留供历史追溯；新检索不得将其当作当前可用要点。
7. 支持停用错误要点，保留历史引用；外部更新不能重新启用人工停用内容而不留确认记录。

## 4. 内部验证页面

列表展示编号、法规、条文、完整要点、类别、场景、案例、提取及更新时间、可用状态。内容可展开完整查看，不以数量替代场景和案例。

支持编号、法规、条文、要点内容、类别、场景、案例及日期筛选，默认更新时间倒序和稳定编号排序。操作包括导入/查看结果、详情、编辑、校核可用、停用、查看原文/解析/案例和版本记录。

输入错误、关联不存在、来源已变更及源不可用均有独立提示。手工校核只操作派生要点，不修改法规原文。

## 5. 服务契约

| 服务 | 输入 | 输出 |
|---|---|---|
| 批量接收 | 结构化要点、源版本、幂等键 | 成功/失败项及原因 |
| 查询/详情 | 条件、分页或要点版本 | 内容、来源及可用状态 |
| 保存/校核/停用 | 版本、动作、内容/原因 | 新版本或冲突 |
| 来源变更处理 | 来源稳定 ID 及版本 | 受影响要点、待核实标识 |

查询与维护权限分开，运行时过滤不可用和越权内容。缺失关联、错误类别、版本冲突及外部故障返回不同错误与追踪号。

## 6. 国产化与 DM8 要求

DM8 保存要点、版本、来源及多值关系。验证长文本完整性、多对多关联、幂等、中文条件组合及来源变更批量处理的事务一致性；不依赖其他数据库专有数组/JSON 运算。交付真实 DM8 测试证据。

## 7. 验收要求

| 编号 | 场景与预期 |
|---|---|
| KEY-01 | 外部生成导入正确关联解析、条文和法规版本 |
| KEY-02 | 重复导入按策略处理，失败原因逐项可见 |
| KEY-03 | 要点、场景、案例完整可查看并可编辑 |
| KEY-04 | 来源更改重新校验，原有引用仍可追溯 |
| KEY-05 | 未审核或来源变更的要点不能作为已校核知识 |
| KEY-06 | 裁决/处罚程序范围被区分，处罚要点不误用 |
| KEY-07 | 真实 DM8 验证多值关联、版本与组合查询，独立 API 可完成维护 |

## 8. 依赖与交付

依赖 01 法规、02 条文解析、外部要点程序和案例资源。交付接收、维护及来源追踪服务、导入规范和验收记录。确认要点类别与场景字典、校核人员、外部生成通道和性能规模。
