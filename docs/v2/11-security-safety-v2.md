# 安全、权限与 AI Safety

依据三域总览的来源/权限约束、CON-09/10/12、ENF-05/14/16、ADJ-09/12；`ADR-V2-04/07/13`。产品的可信边界是当前人员/用途、来源许可、规则发布和正式系统回执，不是 Prompt 声称的“谨慎”。

## 数据与授权

- 身份由可信服务端上下文提供；用户文本、前端传入审核人、模型、工具服务身份不能冒充授权人员。资源授权在召回前、原文读取、模型上下文构造、历史产物/附件、导出、分享、跨域复用与人工交接时逐次重验。历史运行记录只说明当时使用了何种权限，不授予今天的访问。
- 数据集按来源、所有者、用途、分类、可存储/索引/入模/出域/共享/保留、撤回方式和批准版本登记；缺证据默认拒绝真实数据处理。公开访问不等于允许批量索引、外部模型或正式案件使用。派生摘要、引用和报告权限不得宽于输入源与任务范围；权限收紧时缓存、索引、导出与旧链接同步阻断，保留最小受控审计摘要仍受策略。
- 原件与解析文本分开；文件扫描/格式校验、大小与类型、预览/下载受控，OCR 失败不得丢原件。哈希仅证字节完整性，不能证明取证合法性。日志/事件不存密钥、隐含推理、完整敏感材料；必要内容使用受控引用与脱敏。

## Agent 与模型防线

- Agent 只调用发布白名单 Tool 和被许可的 Skill，服务端强制目的、范围、资源与动作。检索内容、上传文档、案例判词、模板变量等不可信文本只作为数据，不能修改系统指令、开放任意 URL/SQL/路径、发布规则、调用权威写回或改变预算。
- 模型输出结构化校验：引用回查来源、关键事实对照、法条原文逐字核对、数字由确定性规则、缺项/冲突强制呈现。违法/侵权/无效/处罚/裁决只可作为辅助候选、风险或待核实，不输出被误认为机关正式决定的文号、签章、受理/送达状态。
- 高影响动作（范围扩大、外部数据处理、人工采信、规则/模板发布、正式状态）需明确授权/确认并在领域服务校验；Agent 不能通过“重复请求”“把决策写进草稿”规避。

## 威胁与必测反例

| 威胁 | 控制 | 反例验收 |
|---|---|---|
| 文献提示注入指示读取他案或改规则 | 工具白名单、数据/指令分离、服务端授权 | 注入文本只被引用/忽略，不触发越权工具 |
| 旧链接/缓存/导出泄漏撤权资料 | 每次授权、撤销传播、短期受控链接 | 失权后任务、引用片段、文件、索引均不可读 |
| 检索无结果/源失败混同 | 类型化结果与 provenance | 限流/超时不输出“无相关权利/无违法” |
| 法条时点错用、数值幻觉 | 具体版本与规则计算、人工复核 | 历史法不自动套现行；缺公式不产生金额 |
| 重试/并发产生重复决定 | 幂等、版本 CAS、权威回执对账 | 重放/迟到不改取消、复核或正式状态 |
| 复核人/签发人冒名 | 可信身份与职责分离、对象版本锁 | 前端传他人姓名或服务账号决定被拒 |
| 草稿误当正式文件 | 状态隔离、显著标注、出口审批 | 仅模型生成/内容审核不能发布正式文件 |

安全事件必须有停止、隔离、通知/处置负责人、恢复与复盘路径。具体组织/DataScope、数据级别、留存/删除、密钥及国产密码规范、模型供应商许可、备份恢复、审计查询权限 **[待确认]**；没有这些证据不能承诺正式接入。结构检测只证明特定约束，不证明法律/业务正确。
