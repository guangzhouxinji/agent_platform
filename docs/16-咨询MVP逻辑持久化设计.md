# 咨询 MVP 逻辑持久化设计

版本：V0.1  
日期：2026-09-15  
关联任务：ARC-10-CON-LOGICAL  
前置：[最小领域模型](12-咨询MVP最小领域模型.md)、[用例与服务](14-咨询MVP用例与服务设计.md)、[最小 API](15-咨询MVP最小API设计.md)。

本文件只表达需要持久化的逻辑记录及关系，不是 DM8 表设计、字段类型、索引、SQL、迁移或 ORM 方案。真实 DM8 适配仍受 P0-05 和 SPK-01 阻塞。

> 2026-09-22 定位更新：本文件只保留为历史 V0 逻辑持久化设计。负责人确认后的产品行为还需要表达用户目标、确认事实版本、稳定结果集快照、对象/目标分支、工具结果、证据充分性、迭代检索、技术对照、子任务状态和人工交接。具体记录、关系、保留期限和 DM8 设计须在数据授权、保留政策及新详细设计 D 门完成后确定；本轮不设计表或迁移。

## 1. 必须保存的逻辑记录

| 逻辑记录 | 保存的最小事实 | 所属领域对象 | 保留原因 |
|---|---|---|---|
| 咨询会话记录 | 会话标识、请求者不透明引用、创建时间、V0 范围标识 | 咨询会话 | 区分会话归属与当前 MVP 范围 |
| 用户输入记录 | 原始问题/补充、提交顺序、时间、受控附件来源定位 | 咨询会话的 `userInputs` | 保留原始输入及其来源，支持补问、冲突和追溯 |
| 未决项记录 | 缺失/歧义/冲突类型、说明、关联输入来源、后续确认来源 | 咨询会话的 `informationIssues` | 防止模型推测覆盖用户事实；可说明为何未检索 |
| 检索请求快照 | 请求标识、会话关系、确认输入、目的、用户请求范围、创建时间 | 检索请求 | 记录本次实际使用条件；关键更正创建新快照 |
| 授权结果引用 | 允许/拒绝/不可判定结果、权威判定引用、检查时间 | 检索请求 | 解释是否允许执行；不复制角色、策略或 DataScope |
| 检索执行结果 | 执行结果类别、实际范围、限制/失败类别、执行时间 | 检索请求 | 区分无权限、无结果、部分结果、来源不可用和工具故障 |
| 检索候选记录 | 候选标识、检索请求关系、可展示摘要、排序/匹配依据、当前使用结果 | 检索候选 | 只保存候选与本次检索和回答的关系，不拥有专利主数据 |
| 来源定位记录 | 来源种类、来源系统、对象标识、版本/摘要引用、位置、获取时间 | 来源定位 | 让输入、授权依据、候选和回答回到确切来源 |
| 回答版本记录 | 回答标识/版本、会话和检索请求关系、正文、结果类型、限制、复核提示 | 辅助回答 | 保留用户实际看到的辅助回答，不以新回答覆盖旧回答 |
| 回答-候选/来源关联 | 回答关键内容对应的采用候选和来源定位 | 辅助回答的 `candidateRefs` / `sourceLinks` | 证明回答依据；支持来源失效后排除失效候选 |

“来源定位”可被多个记录引用。同一来源对象、版本和位置只保留一份逻辑事实；回答、候选和输入通过关联使用它，避免复制版本和位置。

## 2. 关系与历史边界

```text
咨询会话
  ├── 用户输入记录 1..N
  ├── 未决项记录 0..N
  ├── 检索请求快照 0..N
  │     ├── 授权结果引用 1
  │     ├── 检索执行结果 0..1
  │     └── 检索候选 0..N
  └── 回答版本记录 0..N
        └── 回答-候选/来源关联 0..N

来源定位记录 ← 用户输入 / 未决项 / 授权引用 / 候选 / 回答关联
```

- 用户输入、检索请求快照和回答版本追加保存；用户更正或重新检索不覆盖历史。
- 候选的“当前可使用/来源不可用”是回答前的检查结果；来源定位本身保持其身份、版本和位置，不把可用性混入来源事实。
- 当前访问授权与历史授权结果分开：历史结果仅解释当时为何允许/拒绝，读取和来源解析始终重新执行当前授权检查。
- 中心专利源记录保持只读；本地记录只保存工作关系、允许展示的摘要和来源定位，不回写或冒充中心主数据。

## 3. 三样例的数据落点

| 样例 | 必须保存 | 不得保存或产生 |
|---|---|---|
| 正常 | 原问题、确认检索快照、允许授权引用、实际范围、候选匹配依据、文献版本定位、回答版本及回答-来源关联 | 完整中心专利副本、模型隐含推理、未经授权全文缓存 |
| 资料不足/冲突 | 原问题、附件 A/B 定位、缺失目的和冲突温度的未决项、补问回答版本 | 可执行检索结果、模型选择的温度、伪造候选或来源 |
| 无权限 | 原问题、拒绝授权引用、拒绝结果和回答说明 | 受限候选、正文、匹配片段、由受限内容生成的答案 |
| 来源失效 | 原检索请求、原候选及其来源定位、来源不可用结果、降级回答及剩余有效引用 | 已失效来源的缓存正文、将失效候选继续关联为回答依据 |

## 4. 不进入当前逻辑数据模型的内容

- 中心专利全文、图片、OCR、向量、索引、未采用候选全文和缓存键。
- 模型隐含推理、原始模型响应、Token、温度、耗时、重试、网络日志和追踪日志；这些属于后续技术审计元数据。
- 角色、组织、DataScope、权限策略和授权规则；只保存权威判定引用。
- 完整任务/尝试/步骤、事件流、取消、重试、并发恢复、会话到期和保留清理机制。
- 人工复核对象、人员、决定、签发、正式状态或中心回写。
- DM8 类型、主键策略、规范化方案、表名、索引、事务、迁移和备份恢复方案。

## 5. 物理实现前仍需满足的条件

- P0-05：获得真实 DM8 小版本、驱动、实例参数、账号和测试库，并完成 SPK-01。
- P0-03/P0-07：确认真实来源内容、附件和本地保留的授权范围；V0 只使用合成或获准数据。
- P0-04：确认真实身份与授权接入；V0 只消费默认拒绝的授权结果。

在这些条件未满足前，可以验证领域逻辑和 API 合约，但不得标记持久化适配、迁移、DM8 验证或真实数据保留完成。
