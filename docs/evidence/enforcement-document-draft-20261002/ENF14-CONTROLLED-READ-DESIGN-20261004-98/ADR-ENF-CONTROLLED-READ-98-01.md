# ADR-ENF-CONTROLLED-READ-98-01：受控读取使用执法专属部署入口白名单

日期2026-10-04。本ADR是最小D提案的技术选择，批准状态只在docs/08；未实施、未实测。

问题：正常OAuth登录必须写授权/会话，但事故恢复阶段禁止ENF业务写；当前Grant可能合法含写权限，不能改Grant或假称scope/loopback足够。

选择：在正式执法应用显式接线部署过滤器，先于原身份和领域请求处理，精确method/path/query对象白名单，其余默认拒绝；保留原OAuth/PKCE/CSRF、JWT、现时授权及SHA门禁。配置是部署范围，不是新业务只读状态。

拒绝替代：只改前端按钮无法挡直连；只用反向代理但公开后端不能证明无绕过；数据库全局只读会破坏正常登录；创建新只读角色/回滚Grant改变权限且未授权；产品Controller内插只读分支修改冻结领域；任意GET放行可能放出未核副作用和导出。

影响范围：仅执法启动上下文显式import、新部署过滤器/manifest验证、必要启动参数传递及隔离测试。其它应用不能因package扫描自动装配该过滤器，需隔离兼容验证。不修改任何领域模型/API/状态/专业决定。

证明要求：不是配置存在即通过，必须真实隔离DM8/HTTPS浏览器正常PKCE及精确读取允许、业务写/直连/编码/forward拒绝、后台0业务副作用、只有批准OAuth/session变化；然后现时原库只读核验与条件式启动对账。具体入口及发行边界见controlled-read-design.md。

替代/撤销：保留原发行物，异常仅停本轮精确PID，不自动回灌或删历史；解除受控部署配置不是本轮授权，不因此释放本案业务写。
