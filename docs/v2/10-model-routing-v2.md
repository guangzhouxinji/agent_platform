# Model Routing 与降级策略

依据 CON-09/10/11、三域模型使用/来源安全条款；`ADR-V2-13`。模型只在数据许可与任务能力交集内选用，不能因为模型可用就把案件、证据或图片送往外部服务。

## 路由合同

`ModelProfile {modelId/version, deployment/region, approvedDataClasses, purposes, retention/trainingPolicy, modalities, contextLimit, structuredOutputSupport, measuredQualityByTask, latency, cost, health, approvalRef, expiry}`。运行请求声明 Skill、数据类别、用途、输出结构、质量/时限/预算与所需证据；策略先拒绝不符合授权/有效期/驻留条件的通道，再在批准集合内按独立评测选。隐含推理和系统模板不向普通用户展示；保存必要输入/输出摘要与版本，不把模型内部思维链当业务依据。

| 工作 | 优先能力 | 校验和降级 |
|---|---|---|
| 目标理解/补问 | 结构化抽取、多意图/未知处理 | 来源轮次与关键事实确认；失败转显式表单/人工，不伪造槽位 |
| 检索准备/排序 | 技术特征、语义/多模态召回 | 检索范围/评分版本；图像未获准时只运行文字并列缺口 |
| 法规/证据抽取 | 长文/OCR 后结构化定位 | 原文校验、低质页标记；外部解析失败不能称已审核解析 |
| 逐项分析/草稿 | 按领域输出要素/来源/未知 | 服务端验证引用、数值由 Rule；缺证则受限草稿/复核 |

同一任务关键步骤固定模型/Prompt 版本供重放；受控切换产生新尝试并记录差异，不能悄悄把旧人工批准绑定新模型输出。模型超时可重试或在同许可范围内降级；没有获批备选则技术失败或人工接管，绝不自动切外部云。低成本模型不能在未达专业安全指标时承担高风险分析。

正式模型通道、数据分类、出域/训练/保留政策、批准有效期、真实效果和成本上限均 **[待确认]**。合成数据试跑只证明接口/结构/负向边界，不证明法律分析质量。每次发布比较质量、安全、任务工时、成本和延迟；路由本身也要在失败/越权挑战集评测。
