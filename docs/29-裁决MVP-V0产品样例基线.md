# 裁决 MVP V0 产品样例基线

版本：V0.1  
日期：2026-09-16  
关联任务：\`ARC-04-ADJ-V0-SAMPLE\`  
基线性质：依据 ADJ 原需求、已通过的需求契约和 V0 临时产品决策形成的合成产品样例。它只定义开发期产品行为、异常边界和后续最小领域设计输入，不替代真实案件、法规、专利、证据、模板、专业复核、正式裁决或业务验收。

## 1. 共用边界

三个样例只使用固定版本的 \`V0-SYN-ADJ-*\` 数据。合成案件号、主体、材料、法规片段和模板均不是真实中心记录、正式文号或中心认可模板。所有结果显示 \`SYNTHETIC\` 和“仅供内部流程验证”；机器结果只能是候选、缺项说明或报告草稿。

测试身份可以保存修订、退回或“通过复核”的本地记录，以验证版本、职责分离和审计路径；该动作不是专业结论，也不会产生受理、裁决、签发、送达、办结、归档或中心写回。未知专业规则、法定期限、管辖、适用结论和正式模板均不推定。

## 2. 三个产品样例

### 2.1 正常：合成材料完整，停在内部草稿（禁止签发）

| 项目 | V0 产品样例 |
|---|---|
| 输入 | \`V0-SYN-ADJ-CASE-001@v1\`，含合成申请人、被申请人、争议描述和两个合成材料引用；合成法规候选 \`V0-SYN-LAW-001@v1\` 与其条文片段；内部草稿结构 \`V0-SYN-ADJ-TPL-001@v1\`。所有输入均有来源、版本、当前测试授权和 \`SYNTHETIC\` 标记。 |
| 处理 | 固定案件和材料版本，区分当事人主张、待核实事实与测试人工确认项；仅在合成法规候选中展示条文版本、片段、事实对应和适用疑点；测试身份选择具体条文版本并填写引用理由；按内部草稿结构生成可回溯的结构化报告草稿；另一测试身份对确切草稿版本留下复核记录。 |
| 期望输出 | 本地工作记录、材料/法规/引用清单、引用版本及章节锚点、带来源映射的草稿版本、完整性状态、复核记录和“内部草稿（非正式，禁止签发）”标记。草稿不得出现正式案号、裁决结论、签章、送达或办结表述。 |
| 人工控制点 | 测试身份选择/移除法规候选、修订草稿和复核确切版本；正式适用、案件事实、签发和办结均不在 V0 内。 |
| 禁止行为 | 不把候选条文称为已适用法律依据；不把草稿称为裁决文书；不生成当事人未提供的调查、质证、日期、事实认定、签章或文号。 |
| 需求来源 | \`ADJ-04-MUST-002/004/007/014\`、\`ADJ-04-MUST_NOT-001/002/004\`；\`ADJ-05-MUST-*\` 的候选与人工确认边界；\`ADJ-06-MUST-*\` 的版本化引用；\`ADJ-11-MUST-*\`、\`ADJ-12-MUST-*\`。 |

### 2.2 资料不足或冲突：保留缺项，生成不完整草稿

| 项目 | V0 产品样例 |
|---|---|
| 输入 | \`V0-SYN-ADJ-CASE-002@v1\` 的两份合成材料对发生日期描述冲突；一份材料没有来源版本；地域和程序信息缺失；法规候选仅有标题，原文片段不可读。 |
| 处理 | 分别保存冲突值及定位，不选择其中之一覆盖另一项；将无版本材料、程序/地域缺失和不可读条文分别标为缺项、冲突或来源不可用；只形成有限候选及依据；草稿显式列出缺项和未处理项，不能提交为正式复核。 |
| 期望输出 | 资料不足/冲突/来源不可用的分项清单、部分候选、引用待核实状态和“不完整草稿”。不返回“无争议”“不适用”或任何正式结论。 |
| 人工控制点 | 人工决定补充何种材料、处理冲突或标记不适用；重新输入产生新版本并使旧草稿/复核记录待复核，不覆盖历史。 |
| 禁止行为 | 不补造日期、地域、程序、材料版本、条文原文或适用结论；不把资料不足、无结果、无权限和上游故障混同；不以计划日期计算法定期限。 |
| 需求来源 | \`ADJ-04-MUST-010/014\`、\`ADJ-04-MUST_NOT-006/007\`；\`ADJ-05\` 的时间/程序缺口与人工调整要求；\`ADJ-06\` 的原文/版本待核实要求；\`ADJ-11\` 的不完整草稿与输入快照要求；\`ADJ-12\` 的关键缺项阻止复核要求。 |

### 2.3 无权限或来源失效：默认拒绝且不泄露

| 项目 | V0 产品样例 |
|---|---|
| 输入 | \`V0-SYN-ADJ-CASE-003@v1\` 关联一份被测试授权适配器拒绝的材料；另一份在草稿准备后、读取前转为来源失效。 |
| 处理 | 每次读取案件、材料、法规片段、草稿历史或导出前重新检查当前测试授权；无权时拒绝且不返回正文、片段或资源存在性细节；来源失效时停止将其用于新草稿，保留最小追踪记录并标记受影响版本待复核。 |
| 期望输出 | 稳定拒绝或部分失败、追踪标识、受影响对象和不泄露内容的缺项说明；现有草稿不升级状态，历史元数据可追溯但正文仍受实时授权控制。 |
| 人工控制点 | 权限恢复、来源补充、是否重建草稿和正式处置均由权威授权系统或授权人员决定。 |
| 禁止行为 | 不从缓存、旧链接、历史报告或模型上下文泄露内容；不让 Agent/模型决定权限；不把来源失效说成无证据、无争议或处理完成。 |
| 需求来源 | \`ADJ-04\` 当前权限与来源规则；\`ADJ-05\` 权限/依赖故障分离；\`ADJ-06\` 来源状态限制；\`ADJ-11-MUST-016/MUST_NOT-004\`；\`ADJ-12\` 审核权限及依赖失效规则。 |

## 3. 最小 V0 流程

\`\`\`text
合成案件与固定材料版本
  -> 当前授权检查
  -> 候选法规/引用与缺项说明
  -> 合成内部草稿（来源映射、版本、完整性）
  -> 测试身份复核确切草稿版本
  -> 结束：内部草稿（禁止签发），不进入正式裁决或中心状态
\`\`\`

| 对象 | V0 最小责任 |
|---|---|
| 裁决工作记录 | 引用合成案件、材料和版本，不拥有或冒充中心案件。 |
| 条文匹配/引用版本 | 保存候选、人工选择、具体条文版本、依据和报告锚点；候选与确认分开。 |
| 报告草稿版本 | 固定输入清单、结构化正文、来源映射、缺项和修订；不是正式文书。 |
| 复核记录 | 指向确切草稿版本，保存测试身份动作、理由和时间；不改变签发或案件正式状态。 |

## 4. 第一阶段范围与排除项

纳入：合成案件/材料/法规/模板夹具，版本与来源定位，缺项/冲突/无权/失效分支，条文候选和引用，结构化草稿，测试身份复核记录，以及浏览器到本地 DM8 的后续技术验证。

排除：ADJ-07、ADJ-08、ADJ-09 的专利解析、有效性和侵权证据分析；真实模板和 DOCX/PDF 渲染；真实身份、案件/法规/文件 API；法定期限、受理、裁决、签发、送达、办结、归档、通知和中心写回；模型专业效果、Recall@K 或法律正确性。

不预建跨域 \`Evidence\`、\`Review\`、\`Task\` 或 \`Runtime\` 公共业务模型。后续对象和边界仅由 \`ARC-05-ADJ\` 根据本文件决定。
