# ENF14 内置模板与生成内容配置 ADR

日期：2026-10-02。性质：依据用户本轮指令作出的工程决定，不是新增法律规范、正式业务批准或重新开启产品 D。

## 决定

当前三类项目内置内容直接作为最终产品开发基线，分类 NON_OFFICIAL。不存在 Dev/内部正式/Prod 三套模板引擎。内置资源与未来提供方导入资源都由同一 DocumentProfileCatalog/DocumentProfileEngine 处理。该资源不包含案件、人员、批准或正式业务事实。

Template / TemplateVersion 的存储、导入及 DRAFT/PUBLISHED/DISABLED 生命周期仍由已冻结 ENF-12 负责；RuleVersion、映射发布和历史仍由 ENF-13 负责。ENF-14 的 Profile 是对确切模板内容的配置描述，不复制上述领域 Service、API 或状态存储。

FieldDefinition 定义标签、类型、重复、项目内部审核完整性及可编辑文本。FieldMapping 与其分离：内置 defaultMappings 只是导入规则的基线建议，绝不等于 ACTIVE/PUBLISHED 规则。生成处理器必须显式获得已发布的 RuleVersion，不能偷偷使用这些建议绕过规则发布。SourceDatum 保留原对象、版本、SHA、定位和确认状态；未知内容保留缺项，不让模型补造日期、金额、身份或法律原文。

## 版本与历史绑定

输入对象、模板文件 SHA、规则、Profile 内容及适用配置进入准备摘要；生成内容 schemaVersion=1 同时保存 Profile 和实际 Rule 快照、字段来源、条件输入与缺项。Profile/Rule 替换只作用于新准备及新文书，不重写已有文书内容。历史读取检查当前读取授权与旧版本原件完整性，不把新模板的最新头适用条件冒充历史读取权限；新生成/重跑仍须完整现时适用性检查。现时授权与独立水位不能靠旧业务备份恢复。

人工修订、重生成候选/差异、显式采用、审核版本和导出原件继续遵守既有 ENF-14 D：原始来源和机器输出保留，人工变更有独立版本/操作者；新修订不继承旧审核；候选不覆盖人工版本；导出绑定同一审核版内容/模板/规则/渲染器与文件 SHA。尚未实施的部分仍计未完成，不能用本次字段 C 验证代替它们。

## 作用域与条件

effectiveFrom 包含起点，effectiveUntil 不包含终点，仅控制产品配置对新文书的生效窗口，不冒法定生效日期。地区/阶段是产品适用配置，不推定法律适用；受限范围缺输入时返回明确缺口。

条件仅允许 ALWAYS/PRESENT/EQUALS，不执行脚本。确认的空值可表示不显示；缺失或未确认条件保持 UNKNOWN，并保留待复核说明，不能默认为不适用。系统仍需依据实际来源、权限、案件关联、确切法律引用及按类型所需 ENF-11/16 状态判定可消费性。

## 当前数据边界

基线共三类：事实记录、行为复核、处罚输入复核。字段必填表示项目内部审核完整性，不声称法定必填。地区/业务差异通过字段、映射、章节条件和范围配置表达；不提供政府正式文号、签名、签章、签发或送达字段。

参考材料为实际抓取的 CNIPA 2016 表格页面和原始 ZIP、2020 指南说明页；仅提炼结构实践，不宣称历史文件具有当前法律效力。官方原件来源、HTTP、发布时间依据及 SHA 保存在基线资源和采集目录；403/404未计为采集成功。用户批准的是项目工程模板基线，不是对案件的人工业务批准。

## 当前实施事实

三类配置、泛化字段/条件/时间处理已接入唯一草稿服务；07轮增加同一结构内容内的corrections及新修订，原SourceDatum与输入manifest不重写，人工文本不消除缺来源诊断。corrections是兼容可选字段，旧结构无该属性时读取为空列表；新修订不继承审核。C与真实DM8存储历史结果见 execution evidence，不能替代产品I。生产API/UI、运行对象导入/发布、实际案件材料链、候选/采用/审核/导出、浏览器与共同恢复未收口。正式业务验收继续 NEXT-V2-INT-ENF-01 Pending，不阻塞工程工作。
