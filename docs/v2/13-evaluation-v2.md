# V2 任务级 Evaluation 与安全门

依据三域总览及各单篇验收场景：专利/商标/案例检索需专家标注召回，执法规则/金额/日期要固定边界样例，裁决事实/法条/证据/报告要专业审核。`ADR-V2-11`。本文件定义评测方法，**不填未经专家/真实任务确定的样本量、通过率、法定阈值**。

## 评测单位与数据集

每条样本是 `任务目标 + 使用者/用途 + 输入/来源版本 + 权限范围 + 预期产物与证据 + 关键缺口/禁止动作 + 专家判定依据 + 允许差异`；所有分母包含失败、拒答和部分完成。开发集、调参集、冻结盲测集、真实受控任务与高损失挑战集分离。来源许可、脱敏、标注者资格、分歧裁决和版次有记录；模拟通路只做技术契约，不计专业成绩。

## 评测矩阵

| 层 | 指标/测法 | 负向反证 |
|---|---|---|
| Task outcome | 按预注册 Goal/Completion，专家判完成/部分/未完成；成果采用率、总工时（含人工复核）、首次可用成果时间 | 只答容易子问题、错误目标也标完成、靠人工大量重做 |
| Agent 行为 | 必要追问召回与多余追问率、受限范围内自主步骤、无进展停止、预算命中、纠错局部恢复 | 少问漏关键日期/类别；少检索漏重要文献；无限查 |
| Retrieval | 专利/商标文字/图像/案例/法条分开 Recall@K、排序和范围/截断披露 | 同族混版本、摘要假权利要求、图像能力伪装、现行法套旧案 |
| Evidence | 以关键陈述为分母的直接支持/反证识别/未支持率、定位可打开率、组合覆盖、来源失效传播 | 有引用但不支持、哈希当真实性、只挑支持材料 |
| Rule/Domain | 已批准规则边界样例确定性、适用范围/时点/例外、人工决定隔离 | 缺金额按零、规则冲突擅自选更重、复核通过当签发 |
| Human/UX | 真实岗位处理时间、交接包可用、修订距离、拒绝/接管回流、找证据操作次数 | “已转人工”但未受理、修改覆盖人工版 |
| Safety/Runtime | 越权读取/入模/导出、Prompt 注入、取消迟到、幂等/重启/撤回传播、数据留存 | 成功回答泄密、故障当无结果、旧批准签新内容 |

## 场景覆盖

- 咨询：专利技术参考常规/全文缺失/相关日期不明/范围变化/版本切换/指代歧义/用户纠正；商标文字、图样缺失、商品服务冲突；案例不同程序/历史法，复合任务部分完成。专家样本按目标和难度分层，不能只选检索成功实例。
- 执法：多来源疑似重复、线索源失败、主体角色歧义、证据撤回/反证、待证明事项缺口、程序事件/日历缺失、规则重叠/失效、处罚越界、文书缺项与虚构笔录攻击。
- 裁决：案件权限、双方相反材料、无历史权利状态、无效请求但无决定、缺权利要求、单篇新颖性/组合创造性、历史法过渡、报告重生成、人工退回和签发回执不确定。
- 横切：跨组织越权、来源撤回、外部模型禁发、Prompt 注入、服务重启/取消竞争、无人工接收系统、DM8/国产环境故障恢复。

## 发布门禁与实验

E0 纸面产品合同评审（原文/例外/禁止项）；E1 合成固定样例的组件/契约/负向回放；E2 获准数据、独立专家盲测与安全测试；E3 受控真实任务，与人工现行流程对照总工时和质量；E4 持续监控、漂移/撤回/事故复盘。E1 不替代 E2/E3，结构 checker 不证明专业正确；正式验收还需中心/合同约定的签收记录。每次发布冻结输入集、源/模型/规则/Prompt/Tool 版本、评分脚本和指标分母；试验前定义严重错误阻断项及数值通过线 **[待确认]**。

衡量真实价值的最小前置：观察获准的真实工作任务并记录人工基线、数据权属、专业标注和评审人；若无法取得这些输入，只能宣布“技术/交互验证通过，产品效果未验证”。过低预算或过多 ASK 造成的漏检须与效率指标成对审查。评测失败回到 Goal/Skill/检索/证据/规则定位，不靠单次 Prompt 改写宣称修复。
