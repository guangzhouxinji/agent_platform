# 法律法规管理需求文档

## 1. 功能概述

法律法规管理面向知识产权领域，统一收录和管理法律、行政法规、部门规章、司法解释等法规文件，支持外部数据导入、法规信息维护、分类检索、详情查看及修订记录管理，构建结构化法律法规库，为法律查询、业务办理和法规引用提供数据支持。

## 2. 数据来源

法律法规基本信息及修订记录的初始数据均由外部数据源导入。

系统应支持按照约定模板批量导入数据，并建立法规信息与修订记录之间的关联关系。

### 2.1 导入内容

- 法规基本信息
- 法规全文
- 法规修订记录
- 各修订版本对应的修订时原文

### 2.2 导入校验

导入时应校验：

- 必填字段是否完整；
- 日期格式是否正确；
- 法规编号是否重复；
- 法规类别及效力状态是否符合字典配置；
- 修订记录是否能够关联到对应法规；
- 修订时原文是否与修订记录正确匹配。

导入完成后，应反馈成功记录数、失败记录数及失败原因。对于重复法规，可选择新增、更新或跳过。

## 3. 法规信息管理

### 3.1 法规信息字段

| 字段名称 | 是否必填 | 说明 |
|---|---:|---|
| 法规编号 | 是 | 法规唯一标识，不允许重复 |
| 法规名称 | 是 | 法规正式名称 |
| 发布部门 | 是 | 法规发布部门或联合发布部门 |
| 发布时间 | 是 | 法规正式发布的日期 |
| 实施时间 | 否 | 法规开始施行的日期 |
| 法规类别 | 是 | 法律、行政法规、部门规章、司法解释等 |
| 业务领域 | 否 | 专利、商标、著作权、商业秘密等，可多选 |
| 法规全文 | 是 | 当前有效版本的完整正文 |
| 效力状态 | 是 | 尚未生效、现行有效、已失效、已废止等 |
| 创建人 | 系统生成 | 数据创建人员 |
| 创建时间 | 系统生成 | 数据创建时间 |
| 更新人 | 系统生成 | 最近更新人员 |
| 更新时间 | 系统生成 | 最近更新时间 |

### 3.2 法规录入与维护

系统支持：

- 新增法规信息；
- 编辑已存在的法规信息；
- 查看法规详情及法规全文；
- 更新法规效力状态；
- 对法规编号、必填项和日期格式进行校验。

法规正文更新时，不得覆盖修订记录中已保存的历史原文。

## 4. 法规列表

### 4.1 列表字段

列表展示以下信息：

- 法规编号；
- 法规名称；
- 发布部门；
- 法规类别；
- 业务领域；
- 发布时间；
- 实施时间；
- 效力状态；
- 更新时间；
- 操作项。

### 4.2 查询与筛选

支持：

- 按法规名称、法规编号进行关键词检索；
- 按发布部门筛选；
- 按法规类别筛选；
- 按业务领域筛选；
- 按效力状态筛选；
- 按发布时间范围筛选；
- 多条件组合查询。

### 4.3 列表操作

支持：

- 分页展示；
- 按发布时间、实施时间、更新时间排序；
- 查看法规详情；
- 编辑法规信息；
- 打开修订记录弹窗。

默认按更新时间倒序排列。

## 5. 修订记录管理

### 5.1 修订记录来源

修订记录初始数据由外部数据源导入，导入后与对应法规建立关联。

系统同时支持在法规详情中手动新增和编辑修订记录。

### 5.2 修订记录字段

| 字段名称 | 是否必填 | 说明 |
|---|---:|---|
| 修订时间 | 是 | 本次修订发生的日期 |
| 修订类型 | 是 | 修订、补充、部分修订、废止等 |
| 修订说明 | 是 | 本次修订内容摘要 |
| 修订依据 | 否 | 修订文件名称或文件编号 |
| 修订时原文 | 是 | 本次修订前的法规全文快照 |
| 记录来源 | 系统生成 | 外部导入或系统录入 |
| 记录人 | 系统生成 | 记录创建人员 |
| 录入时间 | 系统生成 | 记录创建时间 |
| 更新时间 | 系统生成 | 记录最近更新时间 |

### 5.3 修订记录弹窗

点击法规列表或详情中的“修订记录”后，以弹窗形式展示该法规的全部修订记录。

弹窗要求：

- 按修订时间倒序排列，最新记录置顶；
- 展示修订时间、修订类型、修订说明、修订依据及记录来源；
- 支持查看修订时原文；
- 支持新增修订记录；
- 支持编辑修订记录；
- 对错误记录提供删除功能；
- 新增或修改后自动刷新列表并重新排序。

### 5.4 修订时原文查看

点击修订记录中的“查看原文”，以详情弹窗展示该次修订对应的完整法规原文，并显示：

- 法规名称；
- 修订时间；
- 修订类型；
- 修订说明；
- 修订时原文内容。

修订时原文作为历史版本快照保存，法规当前正文发生变化时，不影响历史修订记录中的原文内容。

## 6. 验收要求

1. 支持批量导入法规基本信息和修订记录；
2. 导入数据能够正确建立法规与修订记录的关联；
3. 支持新增、编辑和查看法规信息；
4. 法规列表支持分页、检索、筛选和排序；
5. 修订记录以弹窗形式展示；
6. 修订记录按修订时间倒序排列；
7. 支持新增、编辑和删除修订记录；
8. 支持查看每次修订时对应的法规原文；
9. 法规正文更新后，历史修订原文保持不变；
10. 导入失败数据能够展示明确的错误原因。
