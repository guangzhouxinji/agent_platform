# 专利裁决报告模板配置需求文档

模块标识：ADJ-10；对应原需求：一.1.1.1.1.3.1。  
版本：V0.1 技术评审稿；日期：2026-09-12。  
建设条件：中心主要通过 API 提供数据；国产化部署，业务关系型数据库固定为达梦 DM8。  
交付边界：对外交付服务及接口、部署和验收资料；自研前端仅供内部验证，不交付对外页面。

本文与[需求总览与通用约定](00-需求总览与通用约定.md)共同构成开发要求。字段中文名为业务契约，接口路径和英文名由详细设计统一。涉及事实的字段缺失时返回缺口，不以模型推测满足必填。当前未完成中心 API、模型或 DM8 实测。

## 1. 功能概述

维护中心认可的专利裁决报告结构、必填章节、字段绑定及版式，为报告初稿生成提供不可变模板版本。不同案件类型和报告用途分别配置，不能把内部分析报告模板自动当作正式裁决文书模板。

首版采用结构化章节与变量配置，支持中心提供的版式文件；不要求通用可视化排版平台。

## 2. 模板字段

| 字段 | 说明 |
|---|---|
| 模板编号、名称、版本 | 编号唯一，发布版本不可原地修改 |
| 适用案件/专利类型、报告用途 | 按中心确认目录 |
| 报告结构、章节顺序、稳定章节 ID | 支持报告引用锚点 |
| 必填章节、条件必填规则 | 条件来自确认字段，不由模型随意决定 |
| 字段变量、来源映射 | 案件、引用、解析、证据、复核等稳定接口字段 |
| 内容方式 | 原文引用、确定性填充或辅助生成，分别指定 |
| 格式要求 | 标题层级、字体、字号、段落、页眉页脚、页码等 |
| 输出格式与样例 | 首版目标 DOCX、PDF；具体版式以中心样例为准 |
| 审核/发布状态 | 草稿、待审核、已发布、停用、归档 |
| 创建人/时间、更新人/时间、审核人 | 实际操作产生 |
| 模板文件、校验/测试记录 | 受控资源及内容版本 |

## 3. 配置和发布流程

1. 根据中心样例新建草稿，配置适用类型、章节、变量及格式。
2. 为变量定义类型、来源、是否必填、缺失处理；不得配置可执行脚本或任意数据库查询。
3. 校验章节 ID 唯一、变量已定义、来源存在、条件无死循环、必填可检查及引用位置可绑定。
4. 使用脱敏样例试生成，检查长文本、表格、图样、分页和缺项提示；测试不形成正式案件报告。
5. 模板审核通过后由授权人员发布不可变版本，新任务可选；已生成报告继续引用原版本。
6. 修改发布版本创建新草稿；普通停用限制新任务，紧急撤销阻止在途继续生成并将受影响草稿提示复核。
7. 历史模板可归档但不物理删除已被引用版本；回滚选择历史版本前重新检查依赖。

系统可提供“案件概况、事实与争议、权利基础、证据分析、法律依据、辅助意见、待核实事项”的草稿结构供配置，不能称为已获中心认可的法定模板。正式签发字段、签章图像和文号不得由模型自由生成。

## 4. 内部验证页面

列表显示编号、名称、类型、用途、版本、状态、更新时间，支持筛选和分页。编辑页包含章节树、变量表、来源映射、条件必填、格式设置及样例数据。

操作包括新建、复制版本、保存、校验、试生成、预览 DOCX/PDF、提交审核、发布、停用、归档和版本对比。预览失败显示具体章节或依赖错误，不把未渲染完成文件当作成功。

## 5. 服务契约

| 服务 | 输入 | 输出 |
|---|---|---|
| 模板查询/保存 | 条件或草稿、并发版本 | 模板或冲突 |
| 校验 | 模板版本 | 章节/变量/依赖错误清单 |
| 试生成/预览 | 模板、测试数据、输出格式 | 任务及受控预览文件 |
| 审核/发布/停用 | 版本、动作、意见 | 状态与版本记录 |
| 运行模板读取 | 固定版本、案件类型 | 已发布结构及变量契约 |

编辑、审核和发布权限由后端校验。无效变量、缺失字体、渲染器故障、模板不适用及撤销分别返回错误；不可执行模板附件中的宏或外链指令。

## 6. 国产化与 DM8 要求

DM8 保存模板结构、变量映射、版本和发布/审核记录，文件存批准存储。验证长模板、嵌套章节、版本事务及唯一约束。DOCX/PDF 转换和所需字体须在目标国产系统/JDK/CPU 上验证，不默认依赖 Windows Office 或外部转换 SaaS。

## 7. 验收要求

| 编号 | 场景与预期 |
|---|---|
| TPL-01 | 按类型和用途配置模板，内部报告与正式文书用途区分 |
| TPL-02 | 未定义变量、重复锚点、非法条件和缺依赖阻止发布 |
| TPL-03 | 长文本、表格、图片、分页及中文字体按样例预览 |
| TPL-04 | 发布版本不可直接改写，旧报告引用不受新版影响 |
| TPL-05 | 停用/紧急撤销/归档行为正确且留痕 |
| TPL-06 | 模板不能执行任意脚本或生成虚构签章/文号 |
| TPL-07 | DM8 与目标国产渲染环境验证，通过独立 API 可生成预览 |

## 8. 依赖与交付

依赖中心模板样例、字段目录、文件与渲染服务、审核权限。交付模板配置/发布服务、变量契约、版式样例对照及验收记录。确认首批模板、字体授权、DOCX/PDF 格式细节及预览规模；未完成格式不能以网页预览替代验收。
