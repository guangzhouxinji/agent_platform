# 咨询智能体专利任务实现准入评审

任务：`GOV-CONSULTATION-PATENT-IMPLEMENTATION-READINESS-01`  
日期：2026-09-22  
基线：`docs/35`、`docs/37`、`docs/38`、`docs/43`、相关正式咨询需求及 `docs/08`  
评审性质：Implementation Readiness，不是编码、真实集成或业务验收

## 1. Implementation Readiness 结论

第一条专利咨询任务闭环已经通过 R 门和 D 门，但实现准入必须按分支拆开：

- 8 个实现任务属于 **A / READY-CANDIDATE**，其业务语义不依赖未关闭 OQ，可使用受控 Fixture 完成 Component/Contract 级实现。
- 其中只有 2 个任务目前没有未完成的内部实现依赖，可以进入 READY：任务核心骨架、默认拒绝权限边界。
- 其余 6 个 A 类任务必须按结果集、纠正、证据、检索、对照和人工契约的依赖顺序推进，当前属于 A 类候选但不进入 READY。
- 6 个任务属于 **C / DEPENDENCY-BLOCKED**，要等待 A 类核心能力或独立物理 D 门完成。
- 7 个任务属于 **B / EVIDENCE-BLOCKED**，分别等待十项 OQ 中适用证据。
- 商标/案例/法规扩展、通用 Runtime/Workflow、三域统一运行时、未批准生产模型通道和未授权真实数据访问属于 **D / FORBIDDEN-NOW**，不建立实现任务。

本评审只允许首批两个任务进入 READY，不启动代码修改。Fixture 成功只能证明逻辑契约，不能证明生产可用、真实集成或业务验收。

## 2. 四类准入定义

| 分类 | 定义 | 计划处理 |
|---|---|---|
| A / READY-CANDIDATE | 当前业务语义完整，不依赖未关闭 OQ，可拆为只使用受控 Fixture 的实现任务 | 只有全部内部前置已完成者进入 READY；其余保持未开始/等待 |
| B / EVIDENCE-BLOCKED | 设计结构已明确，但具体实现必须使用尚未获得的外部数据、授权、专业标准、生产能力或验收输入 | 状态保持阻塞，写明 OQ、责任证据和解除条件 |
| C / DEPENDENCY-BLOCKED | 本身不需要新增业务决定，但依赖尚未实现的 A/B 能力 | 保持未开始/等待；不得绕过依赖用 Mock 冒充闭环 |
| D / FORBIDDEN-NOW | 当前阶段明确排除或未经授权的范围 | 不创建实现任务；后续必须重新经过相应 R/D/准入评审 |

四类是治理分类，不是产品状态，不增加第十种产品任务状态。

## 11. READY 判定规则与假 READY 检查

实现任务只有同时满足以下条件才可进入 READY：

1. 来源要求和当前契约可追溯到 `docs/35`、`docs/37`、`docs/38`。
2. 适用 R/D 门已经通过。
3. 所有计划内前置任务已完成。
4. 该实现实际需要的 OQ 已有合格外部证据；不需要的 OQ 不得被扩大为全项目阻塞。
5. 对应验证层在当前环境可执行，且结论不越过该层能证明的范围。
6. 任务没有把 V0、Synthetic、PUBLIC_LOCAL、Mock、本地 DM8、模型响应、候选数量、引用存在、HTTP 200 或 UI 点击当作正式能力证据。

| 假 READY 来源 | 本次处理 |
|---|---|
| 有 Mock / Fixture | 只允许 A 类逻辑和低层测试；不释放真实适配/验收 |
| 本地 DM8 可运行 | 只视为历史技术证据；物理持久化仍 B |
| 模型 API 成功 | 只证明技术链；生产模型仍 B |
| 检索有候选 | 不证明召回、排序、证据充分或任务完成 |
| UI 能点击 | 不证明 API 闭环、真实集成或业务验收 |
| 旧 V0 已实现 | 失效职责不得升级；仅可复用经新任务逐项验证的技术基础 |
