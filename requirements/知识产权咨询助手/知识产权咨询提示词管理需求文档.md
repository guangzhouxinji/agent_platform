# 知识产权咨询提示词管理需求文档

对应需求：一.1.1.1.1.3.2  
文档状态：技术评审初稿，中心 API 能力、授权范围及性能参数尚需联调确认。  
交付边界：后端服务及接口说明对外交付；前端页面用于内部开发、联调和验收，不属于对外交付内容。


## 国产化与达梦 DM8 适配要求

- 本模块面向国产化环境交付，业务关系型数据库固定使用达梦 DM8；开发联调及数据库兼容验收均须覆盖真实 DM8，不能以 MySQL、H2 等环境通过替代。
- 本模块需要持久化的业务内容包括：提示词正文、变量定义、版本、发布/撤销记录及使用事件。数据库采用 DM8；文件二进制可使用项目已批准的文件存储，DM8 保存受控引用及元数据，不要求把所有图片和附件存入数据库。
- 驱动、连接池、ORM/持久层、分页、建表及升级脚本按实际 DM8 小版本和实例参数适配；不得直接依赖其他数据库专有语法、JSON 类型或函数。长文本、结构化内容、编号、时间及分数应选用经目标实例验证的数据类型和访问方式。
- 本模块 DM8 专项验收覆盖：长模板与换行/特殊字符完整保存、变量映射、发布事务和使用事件去重。验证事务失败回滚、连接故障恢复和权限控制；接口故障不伪装成空结果。需要恢复的任务应识别中断状态，按幂等规则恢复或显式失败，不盲目重放。
- 全文、向量和图像检索能力不得因采用 DM8 就视为已经具备；优先调用中心 API，自建时按总目录的国产化与检索约束选型并验证。
- 交付本模块适用的 DM8 初始化/升级脚本、数据库配置说明和真实 DM8 验证记录；确无本地业务表时注明原因，仍须验证与共用 DM8 服务的集成。其他国产操作系统、CPU、JDK、模型及中间件的具体型号以中心环境清单为准，不预设已完成适配。

详细共用要求见[需求总目录](知识产权咨询助手需求文档总目录.md)“3.7 国产化部署与达梦 DM8 数据库”。

## 1. 功能概述

管理知识产权咨询提示词，分为两类：

- 用户提问引导：面向用户的示例问题、信息填写提示及追问文案，对应原需求的主要内容。
- 系统执行模板：供意图解析、检索准备、辅助比对和咨询回复调用的内部模板，作为支撑能力单独管理。

两类记录共用版本管理，但用途与可见范围分开。用户引导不能被直接拼接为高权限系统指令。首版人工维护与测试，不要求自动生成大量提示词或自动上线优化。

## 2. 信息字段

| 字段 | 说明 |
|---|---|
| 提示词编号、名称 | 编号唯一，创建后不可修改 |
| 类型 | 用户提问引导或系统执行模板 |
| 提示词内容 | 文本或模板正文 |
| 适用场景、关联问题/意图 | 关联稳定 ID，可多选 |
| 适用用户、语言 | 用于展示过滤和选择 |
| 模板变量 | 名称、类型、是否必填、来源及默认值规则 |
| 状态、版本 | 草稿、已发布、已停用、已归档 |
| 生成/创建时间、更新时间 | 区分人工创建与辅助生成来源 |
| 创建/修改/发布人 | 留痕 |
| 使用频率 | 分类型记录展示、点击或实际调用次数 |
| 变更说明、测试记录 | 关联具体版本 |

## 3. 管理规则

支持新增、查询、编辑草稿、预览、测试、发布、停用、复制新版本及归档。编号精确、名称/内容关键词包含查询，类型、场景及状态筛选；默认更新时间倒序，分页 20 条。

已发布正文不可原地修改。编辑生成新草稿，保存时检查版本冲突。发布前检查变量定义、场景关联及模板完整性；不得有未定义变量或缺失必填变量。无值且不允许默认的变量必须返回错误，不能残留占位符。

系统变量使用明确类型与转义/分隔规则；用户文本和检索文献始终作为数据输入，不能改变工具权限及系统规则。模板不能直接声明超出智能体授权的资源访问。

用户引导按场景、用户范围及配置顺序展示，点击后仅填入或发起普通用户问题，不执行管理动作。展示条数由调用方配置。

发布新版本不会自动替换已发布智能体引用；须由智能体配置发布完成升级。普通停用禁止新绑定和新展示，已有固定引用可继续；需要立即撤销的模板须显式执行紧急撤销，所有运行时调用即刻拒绝并进入配置的回退路径。界面区分两种操作。

草稿可删除；有历史引用的版本仅归档并保留审计。

## 4. 测试与统计

系统模板测试输入变量样例，显示渲染结果及校验错误；调用模型试运行时明确标为测试，记录模型和模板版本，不计入正式使用频率。

用户引导分别记录展示次数和点击次数，执行模板记录成功渲染/调用次数及失败次数；不得将展示和调用混为一个“使用次数”。相同事件 ID 重复上报不重复累计。统计注明时间范围和延迟。

## 5. 内部验证页面

- 列表：编号、名称、类型、场景、版本、状态、更新时间、分类使用统计。
- 编辑页：正文、关联场景/问题、变量表、适用范围、保存草稿。
- 预览区：用户引导卡片预览；系统模板变量输入、渲染预览及试运行。
- 版本页：变更对比、测试记录、发布、停用、紧急撤销、归档。
- 内部模板正文只对有管理权限的账号开放，普通调用方只能获取允许展示的用户引导。

## 6. 服务契约

| 服务 | 输入 | 输出 |
|---|---|---|
| 管理查询/保存 | 条件或草稿内容及版本 | 记录或冲突 |
| 模板校验/渲染测试 | 模板版本、样例变量 | 渲染内容或逐项错误 |
| 发布/停用/撤销 | 版本、动作及原因 | 状态与操作记录 |
| 用户引导查询 | 场景、语言、用户权限 | 可展示引导及版本 |
| 内部模板解析 | 固定版本、变量、服务身份 | 渲染结果及版本 |
| 使用事件/统计 | 事件 ID 或日期范围 | 接收结果或统计 |

普通咨询用户不能读取系统模板管理接口。错误包含变量缺失、版本冲突、模板不可用、关联无效和无权限，不返回密钥或内部堆栈。

## 7. 验收要求

| 编号 | 场景与预期 |
|---|---|
| PM-01 | 两类提示词独立用途、展示与权限正确 |
| PM-02 | 必填变量缺失、未定义变量阻止发布或调用 |
| PM-03 | 已发布版本不可直接改写，新版不自动替换智能体绑定 |
| PM-04 | 普通停用与紧急撤销对固定引用的影响符合规则 |
| PM-05 | 用户文本不能通过模板改变工具权限 |
| PM-06 | 展示、点击、执行次数分开，重复事件去重，测试调用排除 |
| PM-07 | 版本冲突与越权读取由服务拒绝 |
| PM-08 | 独立接口完成模板管理及用户引导查询 |

## 8. 依赖与交付

依赖场景/意图字典、智能体配置、权限及可选模型试运行。交付模板与版本服务、变量规范、统计口径和验收记录，页面内部使用。

确认首批引导问题、执行模板、可配置变量、发布权限、事件保留时间及紧急撤销操作角色。正文业务内容需由中心确认，不把未经评审的生成模板直接发布。
